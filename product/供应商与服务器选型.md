# 车源供应商与服务器选型记录

核验：服务器部分于2026-11-08补核；车源API仍为2026-11-07证据（Asia/Shanghai）。公开网页价格可能调整；未注册、购买、使用密钥、调用付费接口或测试目标国家真实线路。以下区分官网披露与本项目建议，不把供应商宣传当实测结果。

### 使用条件差异

- ChinaCarAPI 公开允许订阅期间存库，订阅结束须删除；详细图片使用／再托管、公开网站查询量和历史快照保留条件仍须明确。上轮已核验通用 600 次/分钟、单页最高 100、单查询最多可访问 10,000 条；它们不是无限总量或全库同步授权，详见[业务规划](路线图.md)。
- XAPI 条款说明为独立非官方来源，禁止转售原始 feed；未见充分明确的永久存储／图片再托管许可。其披露的搜索约 30 分钟、详情／图片约 1 小时、检测约 24 小时是服务商的响应缓存行为，上游故障可更旧，**不是我们可自行存储的授权期限**。[条款](https://xapichina.com/terms)
- Apiauto 条款允许数据和图片用于自有产品向客户展示，原始转售／批量导出需另约；这不等于已证实其取得全部上游版权。其条款披露运营者为俄罗斯自雇个人、实际卢布支付且不提供常规结算单据，需要核对自身采购条件。[条款](https://apiauto.space/en/offer/)

VehicleAPI.dev 的[懂车帝说明](https://vehicleapi.dev/api-dongchedi)可作为后续询价线索，但中国源需申请并书面确认范围，未核实可立即购买的中国固定套餐；不纳入首期已验证候选。AutoCango 本轮未找到足以验证的公开 API 套餐／开发文档，不能因为有车源网页就把它当可直接替换的数据接口。

### PM-02：选择前的样本验证

先做人工精选，所以供应商选择不阻塞 G0/G1。G3 前建议对 ChinaCarAPI 与 XAPI China 做同条件 30–50 条样本对照；需要第三候选时加入 Apiauto。取得测试权限后才执行，本轮未申请或发消息。

记录以下证据：

1. 相同品牌／车型／价位的结果，原始来源链接可核对；核查重点车型和可实际采购的来源，不只看宣传总量。
2. 在售状态、挂牌价格口径、照片可加载／有效期、制造日期与登记日期、动力／配置完整率、重复挂牌情况。
3. 列表和详情耗时、错误、限流、更新时间与撤车行为，至少跨两天观察；供应商报告时间不替代人工库存核验。
4. 分别计请求和返回车辆数。例如 100 次列表查询、每次 24 辆，可能对应 100 次请求或 2,400 条记录，不能把不同套餐额度直接比较。
5. 公开展示、图片引用／再托管、本地缓存／保留期、订阅终止处理、报价快照留存、计费超额、支付和支持方式。

建议准入：核心车型样本有可用来源和图片；字段映射不依赖猜值；失效／下架可处理；许可和计量足够明确；预计日常用量有余量。最终阈值按首批样本与业务需要确认，不虚构本轮通过率。

**默认选型策略：先测试更便宜的 XAPI China；若 Che168 覆盖和限流满足需求，可采用它。若需要懂车帝来源、更多覆盖及未来同步能力，继续评估 ChinaCarAPI。** 后端只实现一个选定适配器，保留替换边界；新车和精选现货仍优先来自有合作关系、可核实交付的供应商。

## 2. 地区与平台

本项目的客户主要在俄罗斯、白俄罗斯和中亚，后续欧洲；中国员工要登录后台。**建议先评估德国法兰克福或德国同区域机房**，是基于市场分布的部署起点，不是网络速度保证。采购前后对代表国家的真实网络测试首页、图片和后台上传，必要时调整地域／线路。

购买平台的国家和服务器机房位置是两件事。可在国内云厂商中国站购买海外机房；阿里云官方说明中国站账号可以买海外 ECS，无需另注册国际站。国际站注册对中国内地主体／手机号有单独限制，按真实身份及当前规则使用账号。[阿里云跨地域 FAQ](https://help.aliyun.com/zh/ecs/cross-region-usage-faqs)、[国际站注册规则](https://www.alibabacloud.com/help/en/account/step-1-register-an-alibaba-cloud-account)

| 平台 | 官方可验证事实 | 本项目建议 |
| --- | --- | --- |
| 阿里云中国站轻量应用服务器 | 当前规格表列法兰克福，含 2C4G/50GiB、4C8G/70GiB 等 x86 规格；具体可售按账号与购买页 | 中文管理与支付方便，可优先核价；初期先比较轻量，不必直接买复杂 ECS 组合 |

## 3. 建议购买规格和预算

| 项目 | 首期建议 |
| --- | --- |
| CPU／内存 | 2 vCPU／4GB 可开始低流量试运行；同预算优先 4 vCPU／8GB，为应用＋数据库留余量 |
| 磁盘 | SSD 建议70–100GB以上；2C4G的50GB档可先试运行，图片暂存在同机持久化目录。120GB档更宽裕。监控数据库、镜像和日志，不承诺固定可容纳车数 |
| 系统 | Ubuntu 24.04 LTS、x86_64/amd64，无需桌面；选择仍受支持的成熟 LTS，24.04 不是当前最新 LTS |
| 网络 | 公网 IPv4＋HTTPS，核对实际峰值／流量额度／超额单价；优先有明确流量规则的月付套餐 |
| 图片 | 首期同机私有目录＋API权限判断＋Nginx传图，随数据库联合备份；以后容量／出网增长时再迁移OSS，不直接暴露整目录 |
| 数据库 | 首期同机 PostgreSQL 私有容器，不先购买托管数据库；做好异地一致性备份和恢复演练 |
| 构建 | 本地匹配平台的容器或 CI 构建，生产机主要运行服务；避免低配机器边构建边接待 |
| AI | 后续调用外部模型 API，服务端查车和工具调用；无需 GPU |

Ubuntu 24.04 LTS 当前标准维护到 2029 年 5 月，26.04 LTS 也已存在；本项目选 24.04 是成熟性默认，而非声称最新。[Ubuntu 生命周期](https://ubuntu.com/about/release-cycle)

预算分配是本项目估算，不是厂商报价：服务器目标约 100–220 元／月，异地备份约 20–50 元／月（图片先占服务器磁盘，无单独OSS图片预算），预留 20–30 元流量等余量。小流量前提下争取总计 150–300 元；大量图片出网或更强恢复要求需重算。

具体比较起点：腾讯云法兰克福上述 4C8G 215 元公开档，加小规模存储／备份，有机会控制在 300 元内；若阿里云账号可买到相近全价的 4C8G，亦适合。阿里报价更高时可选 2C4G 起步或用腾讯候选，不必为品牌直接提高预算。先月付验证网络和运行，再考虑长周期；本轮没有拿到登录后的最终订单价，不生成虚构采购单。

扩容依据为实际内存、CPU、查询延迟、数据库连接与磁盘增长；目前没有真实访问量或压测，不能用配置换算“保证每日多少访客”。

## 4. 域名、CDN 与备案范围

已有域名可以继续使用，DNS 指向新服务器。**域名注册／解析不等于已启用 CDN**；CDN 需单独开通、配置源站、域名和 DNS，并验证实际生效。[阿里云 CDN 接入说明](https://help.aliyun.com/en/cdn/getting-started/quick-access-to-alibaba-cloud-cdn)

首期可用直连 HTTPS＋图片压缩／合理缓存运行；是否增加 CDN 根据目标国家的访问表现决定。若启用，后台／鉴权 API／私有图片不得误缓存，发布下架的失效机制要联测。

阿里云说明，部署中国内地机房的网站需要 ICP 备案；非中国内地源站的 ICP 条件不同。选择海外机房不是“所有合规事项均无需处理”的结论；实际主体／业务要求按适用规则核对。本计划不展开税务或其他法律判断。[阿里云 ICP 说明](https://help.aliyun.com/zh/icp-filing/not-for-the-record-dns-can-access-to-different-areas)

## 5. 选型完成的记录模板

- 日期、购买账号所属站点与主体、地域、SKU、CPU/内存/磁盘/架构/系统。

- RU/BY/KZ/UZ 等实际代表网络和中国员工访问测试结果；未测地区明确未测。

- 用户实际选择、当前部署任务范围、下一步。账号凭据与密钥不写入本文件。

## 2026-11-08：首轮实际采购建议

用户认可当前阶段版本，要求先本地Git保存，再采购服务器做公网联通验证。推荐阿里云中国站轻量应用服务器，德国（法兰克福），4 vCPU／8GiB，70GiB以上SSD，Ubuntu 24.04 LTS系统镜像、x86_64，先买1个月。服务器月费目标180–250元，为异地备份和额外流量保留预算；这是采购目标，不是已核实订单报价。若实际超预算，2 vCPU／4GiB／50GiB可用于低流量试运行，构建放本地或CI。

[中国站购买入口](https://www.aliyun.com/product/swas)。已复核[官方地域](https://help.aliyun.com/zh/simple-application-server/product-overview/regions-and-network-connectivity)、[规格](https://help.aliyun.com/zh/simple-application-server/product-overview/instance-families/)和[系统镜像](https://help.aliyun.com/zh/simple-application-server/product-overview/images)，包含法兰克福及Ubuntu24.04；库存、套餐价、续费和流量规则以登录后的购买页为准，不引用国际站美元套餐作人民币保证。通用型优先；国际型非中国优化，国内后台上传可能较慢，不能只凭200Mbps峰值判断体验。法兰克福是按目标市场作出的起点建议，RU/BY/中亚及国内员工线路尚未实测。

目前Linux/arm64已验证；购买x86后，OPS须构建linux/amd64镜像并重新做启动、媒体、备份恢复及HTTPS冒烟，不能把本机arm64成品直接照搬。首次上线需服务器访问方式、拟用域名／后台子域名与DNS控制权；秘密信息仅放忽略的私有位置。首期不购买GPU、托管数据库、CDN或OSS图片存储。
