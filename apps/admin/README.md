# 员工管理后台

独立 React／Vite／TypeScript 与 Ant Design 6 员工工作台，默认中文。本地工作台包含真实会话登录／退出、服务端关键词与分类筛选分页、车辆草稿、图片上传／封面／排序、三语人工审核、库存核验、独立发布／下架，以及公开目录与详情数据核验。支持可恢复删除、回收站只读详情、恢复未发布草稿及外部挂牌来源录入。本轮已补齐首页区块配置和Ant Design员工工作台，官网消费由FE独立实现与验证；客户资料与员工AI仍为后续规划。实际交付状态以角色摘要及本轮日志为准。

维护入口：[后台任务与进度](../../docs/协作/后台.md) · [后台架构](../../docs/开发/后台架构.md) · [后台专用规范](../../.agents/skills/hd-auto-admin/SKILL.md) · [车辆契约](../../docs/开发/车辆接口.md)。实际验证看角色日志，不以文档或 fixtures 代替真实接口联调。

## 本地启动

在仓库根执行：

```sh
pnpm install --frozen-lockfile
pnpm --filter @hd/contracts build
pnpm dev:admin
```

打开 `http://127.0.0.1:3318/admin/`。试用账号见本机私有访问资料，当前验收环境以总进度为准。登录支持员工短账号与已有工作邮箱。API 可依照 [API 运行说明](../api/README.md)另行启动，并通过其受控员工命令创建本机账号。`AUTH_BASE_URL` 与 `TRUSTED_ORIGINS` 使用后台 origin `http://127.0.0.1:3318`，不包含 `/admin`。无服务时显示连接错误，不填演示库存或提供绕过登录入口。

Vite 将同源 `/api` 代理到 `http://127.0.0.1:3320`，不改写浏览器 Origin；需要隔离测试时可由启动环境设置 `ADMIN_API_TARGET`。该参数仅供本机开发／测试代理，不把服务密钥或第三方地址写进客户端。Cookie 由 API 管理，不使用 localStorage token。

## 检查与成品

```sh
pnpm --filter @hd/admin check
pnpm --filter @hd/admin build
pnpm --filter @hd/admin test:e2e
# 先构建 API；本机 PostgreSQL 55432 需可用
pnpm --filter @hd/api build
pnpm --filter @hd/admin test:e2e:live
```

`test:e2e` 使用 Chrome 和最新 `dist/`，在 3319 启动预览，拦截 API 请求验证界面契约与故障场景；这不等于后端联调。`test:e2e:live` 用本机 `/postgres` 维护连接创建随机 `hd_admin_test_*` 数据库，运行迁移、创建合成测试员工，以 3322 API 与 3319 后台验证真实 Cookie、草稿持久化、公开隔离和退出，结束清理自己创建的数据库与临时媒体。它不读取业务数据库。真实浏览器场景覆盖基础草稿、manual完整发布、demo／首页／批量，以及external至少八图／删除／回收站／恢复闭环；实际通过情况以本轮日志为准，所有车辆与图片均为合成测试资料。测试连接可使用 `API_TEST_DATABASE_URL`，只允许本机 `/postgres`。端口占用时退出，不结束其他人的进程。

本机试用服务由BE维护3320，AD维护3318。PM在3318独立验收；自动化写测试仅在随机隔离库、3319后台和3322API执行，配置拒绝3318写测试入口。共享试用库中的两辆展示样例及首页由PM维护，截图只读，不覆盖他人记录或配置。

首次安装浏览器可执行 `pnpm --filter @hd/admin exec playwright install chrome`。浏览器测试需要先 build；不会把旧开发服务当成最新成品。根检查、构建与浏览器命令已纳入后台；共享锁文件仅由当轮集成人维护。

产物为 `apps/admin/dist/`。生产由 OPS 在 `/admin/` 提供静态文件，并把后台深层路由回退到 `/admin/index.html`；`/api/` 单独转发 API，不能回退为 HTML。后台入口和管理 API 不缓存敏感响应，生产 Cookie／可信 Origin／HTTPS 及安全响应头由 API 与代理共同配置验证。Vite preview 仅用于本机成品检查。当前未部署。

## 源码约定

- `src/main.tsx`：路由装配、权限入口与 React 挂载。
- `src/modules/auth/`：应用壳、员工会话、登录与退出；会话过期用弹层锁定编辑，同账号登录恢复输入，换账号清除旧页面。
- `src/modules/vehicles/`：草稿、服务端搜索分类、媒体恢复、三语审核、库存／发布和公开数据核验；不含 API 实现。
- `src/shared/api/`：同源 HTTP、schema 校验、统一错误；不自动重试写入。
- `tests/`：界面契约和真实隔离联调；合成数据不进入运行页面。

完整替换草稿时保留未编辑的图片和三语版本；金额使用字符串，未知事实保持 null。创建结果不明时保留原请求和幂等键，不让修改后的内容冒充原请求。409 比较最新草稿并保留本地输入；员工明确放弃后才载入最新版本。内存中的未保存内容在关闭页面后不恢复，不把内部资料写入浏览器持久存储。

图片上传任务在当前页面内可恢复；已加入草稿的图片刷新后从服务端读取。刷新会丢失未完成上传的本地File及任务上下文，许可响应丢失又拿不到mediaId时必须核对或等待后台清理，不能盲目重复申请。已移除且不再有草稿／发布引用的图片可单独回收；历史发布引用由API保护。原文变化需先保存，再基于新来源版本分别审核三语。

当前UI为Ant Design6.7/icons6.3统一黑金主题，后台使用与官网一致的Logo并独立提供静态资源：车辆表格含缩略图、名称／车号／价格和状态，窄屏按表格宽度横向滚动。车型下拉合并现有管理字典与按品牌整理的常用车型建议，可输入名称新增。录入按基础、价格内部资料、图片、三语发布分组，所有确认使用应用内Modal。批量库存／下架最多50辆、保留选择时版本和固定幂等意图，成功项移出选择、失败项保留，冲突须核对后新请求。首页区块在 `/admin/home-sections`，需要home:write权限。

选择真实车源后，新草稿预填中国、已登记，员工可以按实际情况修改。城市、所在地说明和费用条目退出基础录入表单，已有条目继续随记录保留。未核验实车草稿在库存操作中预选可售，员工确认库存后才记录状态与核验时间。

车辆详情的“预览官网公开内容”读取已发布的指定语言快照。草稿和已下架车辆直接说明状态。已发布车辆返回 `NOT_FOUND` 时可切换语言或刷新发布状态，代理返回非契约错误时页面显示服务读取失败。

删除与下架分别处理：下架保留普通档案，删除移入 `/admin/recycle-bin` 并撤销公开访问／首页引用，保留历史和图片。回收站只读且不加载图片；恢复仅回到未发布草稿、库存待核验，需要重新发布，不自动加回首页。删除／恢复结果未知时保留原版本和幂等键，成功或重放后再读取当前状态，不把历史回执当成最新状态。

外部挂牌使用完整source元数据，平台身份与原挂牌身份创建后不可改。价格仅为来源参考或待询价，库存未知，公开文字不会标成人工已审核。上传前逐行填写与本次文件顺序一一对应的原图URL，每张图均保存挂牌地址、原图地址和UTC采集时间；来源地址只记录，不自动下载。许可待核验只供本地资料整理，生产使用前核验。

## 外部车源管理

`/admin/external-sources` 用于批次导入、来源追溯和人工处理。它读取支持外部目录的同源 API。管理员可导入已规范化的 JSON（每批至多 250 行、8 MiB）、查看受保护原档和提交固定 100 条试译测算。编辑员可读取批次、已登记的原文与译文、试译报告和冲突原因。试译报告分别显示预估、账本尝试和实际调用，账号额度待核实。

挂牌修订使用当前管理版本。事实修订可以恢复跟随来源，译文修订绑定原文。品牌或车型事实改变时先提交事实，再重新核对车型译文。批次内可按本页选中记录预读挂牌版本并批量隐藏或取消隐藏，结果逐条展示。来源撤回状态由 API 判定。

隔离真实接口用例需要 BE 提供同版已构建的合成 API。先构建后台，再运行：

```sh
ADMIN_LIVE_EXTERNAL=synthetic-only ADMIN_LIVE_TRANSLATION_PROVIDER=disabled \
  pnpm --filter @hd/admin test:e2e:live --grep '(?:^| )real external catalog supports admin import, trial and override$'
```

该用例仅启动本机 3319／3322，使用独占随机 `hd_ext_ad_*` 数据库和合成管理员。默认浏览器真实联调模式跳过此例。

## 中文录入与机器译文

新录入默认使用中文标题和描述。先保存原文，再在“三语与发布”生成英俄建议；结果先进入本地未保存草稿，员工校对、保存、审核后再明确发布。已有人工或已审核文本保留；生成结果与当前源／人工版本不一致时拒绝采用。机器结果不自动标成人工已审核，也不自动发布。

翻译只经正式管理员API，浏览器没有供应商密钥或原始服务地址。服务端默认disabled，本轮用户最终选择现有阿里额度，实际配置和真实联调见AD-I18N-01日志。LibreTranslate真实合成评估质量未通过，只供研究，不得把3340评估服务启到业务默认。缺配置／超时／版本冲突均明确提示。

已发布记录通过服务端hasUnpublishedChanges判断是否有待发布修改；对外内容一致时按钮禁用，内部资料与库存更新不要求重复发布。首次旧回执未知状态须先核对；不确定原请求仍按原幂等键恢复。保存与批次图片上传、发布等操作同时显示toast与可见状态。

## 其他公开展示字段的多语资料

先保存基础、价格和图片原文，再打开“公开字段多语”。品牌使用共享静态中英俄词库并保留现有品牌ID；未命中的品牌和车型／配置／代系、地点、平台、费用条目、图片说明由正式localization接口返回，不在浏览器编造字段引用或按排序套用译文。已有来源语言未明确时保留und，员工确认后另行保存，不能把所有历史文字默认标成中文。

每次可选1至10个已保存中文字段生成英俄建议；结果先进入本地未保存状态，人工／已审核译文保留。填写与审核、保存展示资料、发布是独立动作；manual非空展示词条须三语当前且已审核。只改译文也会产生待发布修改，未发布前公开端保留原快照。未知代系／驱动可留空；只保存已知事实不要求猜测其他字段的语言。新代系保存后重新获取对应展示字段。

展示资料独立使用车辆版本和多语修订保存；版本冲突保留输入供比较，不静默升级版本。生成成功／历史重放后重新读取核对版本、来源hash和人工修订，拒绝采用过时建议。结果不明可重试原请求或明确放弃并重新读取；未保存、正在生成或结果未知时保护其他车辆写操作与离开。不同字段正式限长为名称／城市120、地点说明／费用200、图片说明500，不静默截断。

“公开车源核验”显式读取`view=localized`，按所选语言展开查看展示词条；缺译／未填写如实提示，不把原始中文当成英俄。功能与当前9车存量翻译覆盖分别记录，现有资料不会自动生成、保存、审核或重新发布。实际阶段验证见[AD-I18N-02日志](../../docs/日志/2026-11-08/后台-AD-I18N-02-展示字段多语言.md)。
