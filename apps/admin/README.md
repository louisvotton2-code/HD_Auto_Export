# 员工管理后台

独立 React／Vite／TypeScript 与 Ant Design 6 员工工作台，默认中文。本地工作台包含真实会话登录／退出、服务端关键词与分类筛选分页、车辆草稿、图片上传／封面／排序、三语人工审核、库存核验、独立发布／下架，以及公开目录与详情数据核验。支持可恢复删除、回收站只读详情、恢复未发布草稿及外部挂牌来源录入。本轮已补齐首页区块配置和Ant Design员工工作台，官网消费由FE独立实现与验证；客户资料与员工AI仍为后续规划。实际交付状态以角色摘要及本轮日志为准。

维护入口：[后台任务与进度](../../docs/协作/后台.md) · [后台架构](../../docs/开发/后台架构.md) · [后台专用规范](../../.agents/skills/hd-auto-admin/SKILL.md) · [车辆契约](../../docs/开发/车辆接口.md)。实际验证看角色日志，不以文档或 fixtures 代替真实接口联调。

## 本地启动

在仓库根执行：

```sh
pnpm install --frozen-lockfile
pnpm --filter @hd/contracts build
pnpm dev:admin
```

打开 `http://127.0.0.1:3318/admin/`。当前试用账号见本机私有文件 `docs/private/本地联调访问.md`，请勿复制到公开文档。API 依照 [API 运行说明](../api/README.md)另行启动在 3320，并通过其受控员工命令创建本机账号。`AUTH_BASE_URL` 与 `TRUSTED_ORIGINS` 使用后台 origin `http://127.0.0.1:3318`，不包含 `/admin`。无服务时显示连接错误，不填演示库存或提供绕过登录入口。

Vite 将同源 `/api` 代理到 `http://127.0.0.1:3320`，不改写浏览器 Origin；需要隔离测试时可由启动环境设置 `ADMIN_API_TARGET`。该参数仅供本机开发／测试代理，不把服务密钥或第三方地址写进客户端。Cookie 由 API 管理，不使用 localStorage token。

## 检查与成品

```sh
pnpm --filter @hd/admin check
pnpm --filter @hd/admin build
pnpm --filter @hd/admin test:e2e
# 先构建 API；本机 PostgreSQL 55432 需可用
pnpm --filter @hd/api build
pnpm --filter @hd/admin test:e2e:live
```

`test:e2e` 使用 Chrome 和最新 `dist/`，在 3319 启动预览，拦截 API 请求验证界面契约与故障场景；这不等于后端联调。`test:e2e:live` 用本机 `/postgres` 维护连接创建随机 `hd_admin_test_*` 数据库，运行迁移、创建合成测试员工，以 3322 API 与 3319 后台验证真实 Cookie、草稿持久化、公开隔离和退出，结束清理自己创建的数据库与临时媒体。它不读取业务数据库。真实浏览器场景覆盖基础草稿、manual完整发布、demo／首页／批量，以及external至少八图／删除／回收站／恢复闭环；实际通过情况以本轮日志为准，所有车辆与图片均为合成测试资料。测试连接可使用 `API_TEST_DATABASE_URL`，只允许本机 `/postgres`。端口占用时退出，不结束其他人的进程。

本机试用服务由BE维护3320，AD维护3318。PM在3318独立验收；自动化写测试仅在随机隔离库、3319后台和3322API执行，配置拒绝3318写测试入口。共享试用库中的两辆展示样例及首页由PM维护，截图只读，不覆盖他人记录或配置。

首次安装浏览器可执行 `pnpm --filter @hd/admin exec playwright install chrome`。浏览器测试需要先 build；不会把旧开发服务当成最新成品。根检查、构建与浏览器命令已纳入后台；共享锁文件仅由当轮集成人维护。

产物为 `apps/admin/dist/`。生产由 OPS 在 `/admin/` 提供静态文件，并把后台深层路由回退到 `/admin/index.html`；`/api/` 单独转发 API，不能回退为 HTML。后台入口和管理 API 不缓存敏感响应，生产 Cookie／可信 Origin／HTTPS 及安全响应头由 API 与代理共同配置验证。Vite preview 仅用于本机成品检查。当前未部署。

## 源码约定

- `src/main.tsx`：路由装配、权限入口与 React 挂载。
- `src/modules/auth/`：应用壳、员工会话、登录与退出；会话过期用弹层锁定编辑，同账号登录恢复输入，换账号清除旧页面。
- `src/modules/vehicles/`：草稿、服务端搜索分类、媒体恢复、三语审核、库存／发布和公开数据核验；不含 API 实现。
- `src/shared/api/`：同源 HTTP、schema 校验、统一错误；不自动重试写入。
- `tests/`：界面契约和真实隔离联调；合成数据不进入运行页面。

完整替换草稿时保留未编辑的图片和三语版本；金额使用字符串，未知事实保持 null。创建结果不明时保留原请求和幂等键，不让修改后的内容冒充原请求。409 比较最新草稿并保留本地输入；员工明确放弃后才载入最新版本。内存中的未保存内容在关闭页面后不恢复，不把内部资料写入浏览器持久存储。

图片上传任务在当前页面内可恢复；已加入草稿的图片刷新后从服务端读取。刷新会丢失未完成上传的本地File及任务上下文，许可响应丢失又拿不到mediaId时必须核对或等待后台清理，不能盲目重复申请。已移除且不再有草稿／发布引用的图片可单独回收；历史发布引用由API保护。原文变化需先保存，再基于新来源版本分别审核三语。

当前UI为Ant Design6.7/icons6.3统一主题：车辆表格含缩略图、名称／车号／价格和状态，品牌车型使用涵盖草稿的管理字典；可仅输入名称新增，无须手填ID。录入按基础、价格内部资料、图片、三语发布分组，所有确认使用应用内Modal。批量库存／下架最多50辆、保留选择时版本和固定幂等意图，成功项移出选择、失败项保留，冲突须核对后新请求。首页区块在 `/admin/home-sections`，需要home:write权限。

删除与下架分别处理：下架保留普通档案，删除移入 `/admin/recycle-bin` 并撤销公开访问／首页引用，保留历史和图片。回收站只读且不加载图片；恢复仅回到未发布草稿、库存待核验，需要重新发布，不自动加回首页。删除／恢复结果未知时保留原版本和幂等键，成功或重放后再读取当前状态，不把历史回执当成最新状态。

外部挂牌使用完整source元数据，平台身份与原挂牌身份创建后不可改。价格仅为来源参考或待询价，库存未知，公开文字不会标成人工已审核。上传前逐行填写与本次文件顺序一一对应的原图URL，每张图均保存挂牌地址、原图地址和UTC采集时间；来源地址只记录，不自动下载。许可待核验只供本地资料整理，生产使用前核验。
