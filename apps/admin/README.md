# 员工管理后台

独立 React／Vite／TypeScript 与 Ant Design 6 员工工作台，默认中文。包含员工会话、车辆草稿、图片、中文来源与英俄译文、库存、发布、首页配置、回收站和外部车源管理。AD-UX-11 在本轮工作树接入结构化详细配置、统一多语工作区、费用确认和来源报告入口；实际检查与交付状态以角色摘要及本轮日志为准，客户资料与员工 AI 仍为后续规划。

本机交付入口统一为 `http://127.0.0.1:3363`，后台位于 `/admin/`，官网、后台及 API 同源。本轮真实 API／FE 联调与 3363 切换尚未完成验收，当前入口仍以 OPS 记录的上一轮组合为准。阿里翻译尚未启用，本轮没有付费翻译调用；历史轮次的真实调用记录不代表当前服务可用。

维护入口：[后台任务与进度](../../docs/协作/后台.md) · [后台架构](../../docs/开发/后台架构.md) · [后台专用规范](../../.agents/skills/hd-auto-admin/SKILL.md) · [车辆契约](../../docs/开发/车辆接口.md)。实际验证看角色日志，不以文档或 fixtures 代替真实接口联调。

## 隔离开发与本机入口

在仓库根执行：

```sh
pnpm install --frozen-lockfile
pnpm --filter @hd/contracts build
pnpm dev:admin
```

以上是源码开发命令，不会把本轮版本切换到 3363。Vite 默认 3318 仅供隔离开发，旧 3318／3320 试用组合属于历史环境，不作为交付或验收入口。交付与切换由 OPS 协调，内部服务不另作用户入口。登录支持员工短账号与已有工作邮箱；账户见本机私有资料，API 受控员工工具见 [API 运行说明](../api/README.md)。`AUTH_BASE_URL` 与 `TRUSTED_ORIGINS` 必须匹配实际同源入口的 origin，不包含 `/admin`。无服务时显示连接错误，不填演示库存或提供绕过登录入口。

隔离源码开发时，Vite 默认将 `/api` 代理到内部 `http://127.0.0.1:3320`，不改写浏览器 Origin；需要隔离测试时可由启动环境设置 `ADMIN_API_TARGET`。隔离三端预览可同时设置 `ADMIN_WEB_TARGET`，仅将 `/staff` 和 `/_next` 代理到对应 FE 版本；正式同源入口由 OPS 配置。该参数仅供本机开发／测试代理，不把服务密钥或第三方地址写进客户端。Cookie 由 API 管理，不使用 localStorage token。

## 检查与成品

```sh
pnpm --filter @hd/admin check
pnpm --filter @hd/admin build
pnpm --filter @hd/admin test:e2e
# 先构建 API；本机 PostgreSQL 55432 需可用
pnpm --filter @hd/api build
pnpm --filter @hd/admin test:e2e:live
```

`test:e2e` 使用 Chrome 和最新 `dist/`，在 3319 启动预览，拦截 API 请求验证界面契约与故障场景；这不等于后端联调。`test:e2e:live` 用本机 `/postgres` 维护连接创建随机 `hd_admin_test_*` 数据库，运行迁移、创建合成测试员工，以 3322 API 与 3319 后台验证真实 Cookie、草稿持久化、公开隔离和退出，结束清理自己创建的数据库与临时媒体。它不读取业务数据库。真实浏览器场景覆盖基础草稿、manual完整发布、demo／首页／批量，以及external至少八图／删除／回收站／恢复闭环；实际通过情况以本轮日志为准，所有车辆与图片均为合成测试资料。测试连接可使用 `API_TEST_DATABASE_URL`，只允许本机 `/postgres`。端口占用时退出，不结束其他人的进程。

3319／3322 仅为自动化隔离测试端口，不作为试用入口；写测试不得指向 3363 或业务数据库。端口、构建和输出目录由本轮负责人协调，测试结束释放本次资源。历史共享试用库中的样例及首页由当轮负责人维护，不覆盖他人记录或配置。

首次安装浏览器可执行 `pnpm --filter @hd/admin exec playwright install chrome`。浏览器测试需要先 build；不会把旧开发服务当成最新成品。根检查、构建与浏览器命令已纳入后台；共享锁文件仅由当轮集成人维护。

产物为 `apps/admin/dist/`。生产由 OPS 在 `/admin/` 提供静态文件，并把后台深层路由回退到 `/admin/index.html`；`/api/` 单独转发 API，不能回退为 HTML。后台入口和管理 API 不缓存敏感响应，生产 Cookie／可信 Origin／HTTPS 及安全响应头由 API 与代理共同配置验证。Vite preview 仅用于本机成品检查。本轮 UX11 尚未部署，历史生产版本与本机运行版本分别由 OPS 记录。

## 源码约定

- `src/main.tsx`：路由装配、权限入口与 React 挂载。
- `src/modules/auth/`：应用壳、员工会话、登录与退出；会话过期用弹层锁定编辑，同账号登录恢复输入，换账号清除旧页面。
- `src/modules/vehicles/`：草稿、详细配置、统一多语工作区、媒体恢复、库存／发布和公开数据核验；不含 API 实现。
- `src/shared/api/`：同源 HTTP、schema 校验、统一错误；不自动重试写入。
- `tests/`：界面契约和真实隔离联调；合成数据不进入运行页面。

完整替换草稿时保留未编辑的图片和三语版本；金额使用字符串，未知事实保持 null。创建结果不明时保留原请求和幂等键，不让修改后的内容冒充原请求。409 比较最新草稿并保留本地输入；员工明确放弃后才载入最新版本。内存中的未保存内容在关闭页面后不恢复，不把内部资料写入浏览器持久存储。

图片上传任务在当前页面内可恢复；已加入草稿的图片刷新后从服务端读取。刷新会丢失未完成上传的本地 File 及任务上下文，许可响应丢失又拿不到 mediaId 时必须核对或等待后台清理，不能盲目重复申请。已移除且不再有草稿／发布引用的图片可单独回收；历史发布引用由 API 保护。原文变化需先保存，再在统一多语工作区处理当前版本译文。

当前 UI 为 Ant Design 6.7/icons 6.3 统一黑金主题，后台使用与官网一致的 Logo 并独立提供静态资源：车辆表格含缩略图、名称／车号／价格和状态，窄屏按表格宽度横向滚动。车型下拉合并现有管理字典与按品牌整理的常用车型建议，可输入名称新增。录入分为基础资料、车辆配置、价格与内部信息、图片管理、公开字段多语、发布预览六个分组，所有确认使用应用内 Modal。批量库存／下架最多 50 辆、保留选择时版本和固定幂等意图，成功项移出选择、失败项保留，冲突须核对后新请求。首页区块在 `/admin/home-sections`，需要 home:write 权限。排序支持拖动手柄、键盘（空格拿起，方向键／Home／End 移动，Enter 放下，Escape 取消）、上下移动、指定序号及置顶／置底。新选车辆可加入顶部；保存前顺序只在本地草稿，失败或冲突保留当前顺序。

新增 manual／external 草稿的登记状态默认为 `registered`（已登记），demo 保持 `unknown`，旧记录不批量改写。选择真实车源后预填中国及公开报价，城市留空，员工按实际情况修改。城市、所在地说明和费用条目退出基础录入表单，已有条目继续随记录保留。未核验实车草稿在库存操作中预选可售，员工确认库存后才记录状态与核验时间。

车辆详情的“预览官网公开内容”读取已发布的指定语言快照。草稿和已下架车辆直接说明状态。已发布车辆返回 `NOT_FOUND` 时可切换语言或刷新发布状态，代理返回非契约错误时页面显示服务读取失败。

删除与下架分别处理：下架保留普通档案，删除移入 `/admin/recycle-bin` 并撤销公开访问／首页引用，保留历史和图片。回收站只读且不加载图片；恢复仅回到未发布草稿、库存待核验，需要重新发布，不自动加回首页。删除／恢复结果未知时保留原版本和幂等键，成功或重放后再读取当前状态，不把历史回执当成最新状态。

外部挂牌使用完整source元数据，平台身份与原挂牌身份创建后不可改。价格仅为来源参考或待询价，库存未知，公开文字不会标成人工已审核。上传前逐行填写与本次文件顺序一一对应的原图URL，每张图均保存挂牌地址、原图地址和UTC采集时间；来源地址只记录，不自动下载。许可待核验只供本地资料整理，生产使用前核验。

## 三方 API 状态与车源管理

`/admin/external-sources` 展示 ChinaCarAPI 账户连接、探测时间、套餐、到期和覆盖平台，以及本地最近成功入库和已知来源时间。账户探测与入库记录分别显示，自动同步当前为未配置。未配置账户探测时，页面说明需要配置的连接。连接正常时，套餐或额度等缺项显示为供应商未返回。

`/admin/public-catalog` 显示全库挂牌、已展示、人工隐藏和来源撤回数量。出口资格显示待核验。关键词可与来源平台、挂牌状态、品牌、车型、动力、年款及里程组合，筛选与分页均由管理 API 执行。列表展示入库参数、修订标记和原站链接，详情返回时恢复筛选与页码。具备车辆写权限的员工可分别编辑车辆事实及公开文案，16 个事实字段和 9 项三语文案全部展开，核对原值、语言和版本后直接编辑保存。跟随来源、显式未知和各语种清除分别处理；来源撤回时不开放人工修订入口。

`/admin/external-sources/batches` 保留历史导入、来源追溯及试译测算。管理员可导入已规范化的 JSON（每批至多 250 行、8 MiB）、查看受保护原档和提交固定 100 条试译测算。挂牌修订使用当前管理版本。品牌或车型事实改变时先提交事实，再重新核对车型译文。批次内仍可批量隐藏或取消隐藏。访客视角的公开车源核验入口位于 `/admin/public-catalog/verification`。

隔离真实接口用例需要 BE 提供同版已构建的合成 API。先构建后台，再运行：

```sh
ADMIN_LIVE_EXTERNAL=synthetic-only ADMIN_LIVE_TRANSLATION_PROVIDER=disabled \
  pnpm --filter @hd/admin test:e2e:live --grep '(?:^| )real external catalog supports admin import, trial and override$'
```

该用例仅启动本机 3319／3322，使用独占随机 `hd_ext_ad_*` 数据库和合成管理员。默认浏览器真实联调模式跳过此例。

## 车辆详细配置（AD-UX-11）

基础资料的 `trim` 配置名称继续保留；“车辆配置”分组单独保存详细配置 JSON：`{"version":1,"items":[{"name":"排量(cc)","value":"1989"}]}`。名称和值均为字符串，保留单位、顺序和精确内容；复制 AI 提示词只复制整理说明，不调用模型或翻译服务。

校验复用 `@hd/contracts/admin` 的共享规则：最多 200 项，单个名称最多 100、值最多 500，名称和值合计最多 16000 个 UTF-16 单元；原始 JSON 最多 65536 UTF-8 字节。重复键、重复名称、非法 Unicode、额外属性或非严格 JSON 均拒绝，不静默修正或截断。留空表示缺配置，允许保存未完成草稿；非空且非法时不能保存。manual 和员工维护的 external 副本正式发布必须有有效详细配置，demo 不受此必填门槛约束；旧记录不自动填充。

## 统一多语工作区（AD-UX-11）

先保存中文基础、配置、价格及图片资料，再打开“公开字段多语”。中文原文与汇总只读：标题到基础资料编辑，车况描述到价格与内部信息编辑，配置到车辆配置编辑。品牌沿用共享词库，其他展示字段使用正式 ref；未知事实保持 null，来源语言未明保持 und，不按排序猜测字段身份。历史非 zh／und 来源必须由员工核对并通过整页中文来源确认后保存，不能静默改标中文。

正文及展示／配置译文通过单一 `GET /api/v1/admin/vehicles/:id/translation-bundle` 获取同版本工作区，再以一个 `PUT` 原子保存 `content`、`localization` 及必要的 `sourceLanguageConfirmations`。车辆版本与多语修订共同保护输入，冲突时保留本地内容供比较。新生成的中文结果保留 `original/pending`，英俄结果保留 `machine/pending`；界面不再提供逐字段审核或伪造 `approved`。已有人工编辑／approved 译文受保护，源版本或人工版本变化时拒绝过时建议。

生成顺序为：读取并保存工作区 → 创建正式 translation plan → 核对固定字段范围、字符／请求上限与费用 → 明确确认 → generate。计划绑定车辆、来源指纹、版本和供应商配置，有效期内确认同一不可变计划；最多 472 个字段，内部采购成本、备注和联系方式不进入输入。`cost.status=unknown` 时费用及免费额度未知，不能承诺免费，失败或中断也可能已计费；本轮阿里尚未启用，没有付费调用。

generate 的客户端等待上限为 150 秒。中断、超时或结果未知后只用 `GET /translation-plans/:planId` 读取状态，不自动重发 POST；结束本次计划不会取消已发生的调用，再试需要新计划与费用确认。完整／部分成功结果先进入本地未保存状态，员工编辑后一次保存全部多语资料，不自动发布。人工／approved 内容继续保留；缺少的目标语言如实显示。保存结果未知时先 GET bundle 比较；仅确认服务端仍为提交前完整快照后才提供显式重试原保存正文，不把这一保存恢复规则用于重试生成。

翻译只经员工鉴权 API，浏览器没有供应商密钥或原始服务地址。服务端私配、额度和预算由 PM／OPS 核对；历史阿里联调见 AD-I18N-01 日志，LibreTranslate 历史评估未通过，不作为业务默认。不同展示 ref 的现有长度限制仍由正式合同约束，不截断名称、费用或图片说明。“公开车源核验”显式读取 `view=localized`，缺译如实提示，不把中文当成英俄。

## 发布预览与明确发布

manual 和员工维护的 external 副本发布前需要品牌、车型、中文标题、配置名称、有效详细配置、年款、已知动力、里程（0 有效）、正数价格及币种、正数内部采购成本及币种、有效图片、车况描述和当前版本三语译文。manual 用公开报价，员工 external 副本保留来源参考价与库存未知；自动外部挂牌不进入该员工发布流程。可先保存未完成草稿，空报价保留报价意图与已选币种；不追溯改写旧已发布快照。采购成本、供应商和内部备注不进入公开预览。

年款、制造／登记日期和来源时间使用日期组件，保持实际精度；标明 UTC 的选择器按所选墙钟时间保存 UTC。服务端 `hasUnpublishedChanges` 决定是否有待发布修改，不能用更新时间猜测；内部资料与库存更新不要求重复发布。

只有当前激活“发布预览”分组才显示发布／确认操作；其他分组仅提供进入发布预览入口。“发布预览”从同源 `/staff/vehicles/:id/publication-preview/` 嵌入员工鉴权的 FE 白名单草稿投影。正式 frame schema 同时核对同源、来源窗口、loadId、车辆、语言及版本；只有 height 或 iframe load 不算就绪，旧实例及终态错误后的回包不解锁确认。ready 清初载期限，后续切图 loading 另起 40 秒，同阶段重复 loading／resize 不延期。

发布按钮以 `publish-readiness` 为准；缺项可导航，译文就绪与显式预览确认均必需。确认发送实际已呈现的 revision／fingerprint／locale／version，证明最多有效 10 分钟，内容变化或过期后重新核对。确认不等于发布，仍需员工明确提交，原幂等与结果未知保护保留。本轮真实 API／FE 联调及 3363 切换尚未验收，契约浏览器模拟不代表三端交付。

## 来源报告入口

员工车辆详情（含有真实来源关联的 external 副本）与第三方挂牌详情只读取正式鉴权字段 `report.url`。有合法安全 HTTPS 原始地址才显示“打开来源报告”，使用普通 `<a target="_blank" rel="noopener noreferrer">`，保留完整原始 href，不拼接、不归一化、不自动 fetch／prefetch。它不表示正文或链接可用性已核验，也不依赖公开 `reportAccess.available`。`hasReport:true` 但 `url:null` 合法，此时没有打开按钮；公开详情及鉴权预览只消费 `report.hasReport` 并提示联系销售，不暴露地址。

员工副本的绑定由 BE 按 platform、externalId 和原始 listingUrl 精确匹配，界面不从公开字段或候选数据猜 URL。来源身份有未保存修改时隐藏旧报告入口。历史 mutation 回执可能省略 report，成功后只 GET 详情并合并报告元数据；核对车辆、版本及来源绑定，不用迟到的详情覆盖新输入，也不继承旧来源链接。完整含参数地址不写入公共日志。相关组件为 `src/shared/ui/source-report-link.tsx`，没有报告探测请求。

## 发布前清理（AD-REL-03）
