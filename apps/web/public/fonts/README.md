# Inter local fonts

Inter variable normal, weights 100–900, Latin and Cyrillic subsets. Public font files captured from the reference site's self-hosted Inter resources on 2026-11-05. No runtime font request is made to that site or Google.

Copyright 2020 The Inter Project Authors (https://github.com/rsms/inter). SIL Open Font License 1.1, copied in `Inter-OFL.txt` from the [Google Fonts Inter license](https://github.com/google/fonts/blob/main/ofl/inter/OFL.txt). Font files were renamed only, not modified.

Original resources:

- `inter-latin.woff2`: https://www.kmotors.shop/_next/static/media/83afe278b6a6bb3c-s.p.3a6ba036.woff2
- `inter-cyrillic.woff2`: https://www.kmotors.shop/_next/static/media/9c72aa0f40e4eef8-s.p.18a48cbc.woff2

The Latin and Cyrillic unicode ranges are declared separately in `src/app/globals.css`; Chinese uses system fallbacks. Keep the OFL notice with any redistributed font copies.
