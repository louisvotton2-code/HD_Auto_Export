# 验证与交接入口

验证范围、独立审查、提交保护和报告格式统一维护在[测试与审查](../../../../docs/协作/测试与审查.md)，本文件不再复制规则。

- 日常开发、端口与联调：[本地开发分工](../../../../docs/README.md#本地开发与部署分工)。
- 当前任务与部署状态：[开发进度](../../../../docs/开发进度.md)。
- 交付仅记录版本、改动、实际检查、未完成项及下一步；复用本任务日志。
- 轻量自测和必要联调后给用户实际本地地址；用户验收后正式提交检查、PR/CI及授权发布。不把代码完成当作已上线。
- 未改变的已通过检查不重复；独立Reviewer看增量。权限、数据、金额和收费边界不得省略。
- 不用旧构建冒充当前版本，不并发写同一构建目录，不覆盖他人未提交改动。实际命令以现行提交保护脚本为准，不绕过hooks。
