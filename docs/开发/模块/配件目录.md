## 入口与模块边界

路由为`/{locale}/parts/`及`/{locale}/parts/{oem小写}/`，支持zh/en/ru。页面等待异步params/searchParams，校验locale并设置requestLocale；未知OEM返回真实404，不回退到其他商品。metadata提供三语canonical/hreflang，目前目录和详情都为noindex/follow=false，不因有SSR就开放搜索收录。导航与sitemap由当轮集成人维护。

| 位置（相对apps/web） | 职责 |
| --- | --- |
| `src/modules/parts/types.ts` | 配件、图片、查询及repository契约 |
| `src/modules/parts/server.ts`／`repository.ts` | 路由使用的异步数据入口；当前静态adapter |
| `src/modules/parts/data/` | 原始资料、三语名称、展示映射及来源/素材SHA清单 |
| `src/modules/parts/content/parts-content.ts` | 同形三语界面、联系及业务边界文案 |
| `src/modules/parts/query.ts` | 本地筛选、排序、URL与数量校验；不依赖React/网络 |
| `src/modules/parts/contact.ts` | HD账号、配件身份与数量一致的聊天草稿 |

外部装配只经`modules/parts`与`modules/parts/server`入口；UI不读取原始文件、第三方接口或数据库。未来接入配件API先替换repository，明确分页/价格/库存/适配契约后再改变UI查询边界，不能对一页API数据筛选后声称全目录结果。当前只对明确的44条静态资料本地筛选，无分页、无全量车辆API抓取。

## 查询、咨询与收藏

关键词按OEM、当前语言名称、英文名称和品牌字面匹配，品牌/类别/价格同时生效；可按参考价升降或名称排序，排序选择即应用当前表单。所有结果来自同一静态集合。JS在页面本地应用并更新URL，订阅Next的searchParams变化同步本地状态；header/footer再次进入目录、Back/Forward均以URL恢复，不能因组件复用而留旧筛选。无JS的原生GET可完成搜索和筛选。JS提交非法价格区间时保留整组已应用结果/URL并显示错误；无JS或直接URL初始解析则显示错误并忽略非法价格区间。不把解析失败当0价格。

受控本地URL更新使用`history.replaceState(null, '', href)`，交给Next复制内部路由状态并同步searchParams；不要把`window.history.state`中的`__NA`标记手传回去，Next会将其视为自身导航并绕过URL订阅更新。原生GET降级保留；本地应用筛选无需RSC/document/API请求，实际浏览器回归核对该边界。

详情只显示资料已有的OEM、品牌目录和类别；不补造产地、重量、尺寸、适配年份或可售库存。价格为USD参考单价，不含运费和进口费用，最终规格、数量及报价通过咨询确认。数量仅接受1–999整数；原生GET“更新数量”支持无JS，JS增强提供加减和实时草稿。无效数量不会保留可点击的旧草稿。

`buildPartContactLinks`校验slug与OEM一致，使用统一HD配置的Telegram/WhatsApp，不含竞品账号。三语草稿包含OEM、名称、数量、已知USD参考单价及对应详情URL；仅打开草稿，由客户自己发送。不要改成自动发送、机器人start参数或无关产品链接。

收藏key为`hd-auto:part-favorites:v1`，payload仅`{version:1,ids:[...]}`，仅接收当前repository提供的已知稳定ID，最多100个。目录和详情共用模块内store；同页订阅及其他标签的storage事件同步。坏JSON/旧版本作为空偏好，存储禁止/写失败时回退当前页面内存。目录的“已收藏”只筛选当前静态资料，可叠加普通筛选；无JS隐藏收藏增强并保留正常目录。汽车头部抽屉仍属于汽车，不混入配件。
