# 配件目录与详情维护

2026-11-08｜FE-UX-03。当前为用户授权的静态配件资料目录；官网仍使用Node／standalone，车辆继续调用独立API，七国计算器继续使用现有计算核心。本页不建立配件库存、订单、支付、货运或消息发送服务。具体同版验收状态见[本轮日志](../../日志/2026-11-08/前端-FE-UX-03-配件目录与详情.md)。

## 入口与模块边界

路由为`/{locale}/parts/`及`/{locale}/parts/{oem小写}/`，支持zh/en/ru。页面等待异步params/searchParams，校验locale并设置requestLocale；未知OEM返回真实404，不回退到其他商品。metadata提供三语canonical/hreflang，目前目录和详情都为noindex/follow=false，不因有SSR就开放搜索收录。导航与sitemap由当轮集成人维护。

| 位置（相对apps/web） | 职责 |
| --- | --- |
| `src/modules/parts/types.ts` | 配件、图片、查询及repository契约 |
| `src/modules/parts/server.ts`／`repository.ts` | 路由使用的异步数据入口；当前静态adapter |
| `src/modules/parts/data/` | 原始资料、三语名称、展示映射及来源/素材SHA清单 |
| `src/modules/parts/content/parts-content.ts` | 同形三语界面、联系及业务边界文案 |
| `src/modules/parts/query.ts` | 本地筛选、排序、URL与数量校验；不依赖React/网络 |
| `src/modules/parts/contact.ts` | HD账号、配件身份与数量一致的聊天草稿 |
| `src/modules/parts/favorites-store.ts`／`use-part-favorites.ts` | 配件独立浏览器偏好；不保存库存快照 |
| `src/modules/parts/ui/` | 目录、卡片、详情、图库与相邻CSS Module |
| `src/app/[locale]/parts/` | 参数/404/SEO与服务端装配 |
| `public/parts/` | 已复制的本地配件参考图片，图片不请求竞品域名 |

外部装配只经`modules/parts`与`modules/parts/server`入口；UI不读取原始文件、第三方接口或数据库。未来接入配件API先替换repository，明确分页/价格/库存/适配契约后再改变UI查询边界，不能对一页API数据筛选后声称全目录结果。当前静态资料库保留44条资料和对应详情，公开目录展示其中12条，无分页。

## 资料和视觉依据

本轮只读本地`/Users/whisky/work/ownbus/test`的React页面、数据与样式，没有执行其脚本：`src/pages/PartsPage.tsx`、`PartDetailPage.tsx`、`components/cards/PartCard.tsx`、`src/styles/original/pages.css`及`public/js/mock-data.js`。后者用JSON解析器提取`window.MOCK`的字面量，不执行JavaScript。此前集成人的公开页面观察只作历史佐证；后续调整以用户指定的本地React参考为准。

静态资料44条、唯一OEM44个、图片36个，共1,282,187字节；来源捕获时间和SHA见`data/source-manifest.json`。原始组别Engine混有ABS和连接件，展示归为机电与通用部件，保留原始资料但不推断发动机适配。三语名称去掉未经核实的“原厂正品”保证；不复制参考中的48,689库存、10年、固定运输费/时效、购物车、支付或虚假发送成功。44条数量只称配件资料，不称现货库存。

每条原始资料仅有1张图；部分是OEM编号参考封面，不是实物照片。页面标注配件参考图，不拿车辆图片替代，也不复制参考的broken image。图库契约接收多图，当前不靠重复同一图片伪造多图资料。新增真实多图应提供稳定image ID并复核缩略、弹层、键盘及手机行为。

响应式以本地`pages.css`的pn布局为准：容器最大1280px，左右留白默认16px、640px起24px；目录768px以下2列、768px起3列、1280px起4列。筛选在1024px以下全宽置顶，1024px起才使用260px侧栏。两列手机卡片正文padding14px，名称14px/1.4行高最多两行，OEM和价格允许断行；图片保留本地参考的正方形比例，详情堆叠不改变图片比例。不能沿用此前公开参考页面观察的手机单列作为本地React还原依据。

## 查询、咨询与收藏

2026-11-09｜FE-UX-05。首屏和目录内的两个查询入口均使用原生 GET，点击查询后浏览器重新加载整页，并通过 URL 保留关键词和类别。侧栏提交和排序选择也使用同一表单流程。资料区保持当前12条静态条目，计数使用实际展示的条目，收藏按实际收藏条目显示。三语清理查询示例、提示文案及占位卡，并移除模拟页码。接入配件查询服务时，再按实际契约恢复结果过滤与分页。

价格区间仍由服务端解析。非法区间在刷新后提示，价格字段保持为空。页面使用新 URL 的服务端参数回显条件，原生导航和浏览器前进／返回均走同一逻辑。

详情只显示资料已有的OEM、品牌目录和类别；不补造产地、重量、尺寸、适配年份或可售库存。价格为USD参考单价，不含运费和进口费用，最终规格、数量及报价通过咨询确认。数量仅接受1–999整数；原生GET“更新数量”支持无JS，JS增强提供加减和实时草稿。无效数量不会保留可点击的旧草稿。

`buildPartContactLinks`校验slug与OEM一致，使用统一HD配置的Telegram/WhatsApp，不含竞品账号。三语草稿包含OEM、名称、数量、已知USD参考单价及对应详情URL；仅打开草稿，由客户自己发送。不要改成自动发送、机器人start参数或无关产品链接。

收藏key为`hd-auto:part-favorites:v1`，payload仅`{version:1,ids:[...]}`，仅接收当前repository提供的已知稳定ID，最多100个。目录和详情共用模块内store；同页订阅及其他标签的storage事件同步。坏JSON/旧版本作为空偏好，存储禁止/写失败时回退当前页面内存。目录的“已收藏”只显示当前静态资料中的收藏项；无JS隐藏收藏增强并保留正常目录。汽车头部抽屉仍属于汽车，不混入配件。
