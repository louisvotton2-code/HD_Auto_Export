# 配件目录与详情维护

2026-11-12｜FE-UX-09。目录和详情使用静态配件资料，在官网 Node／standalone 运行时内渲染。当前查询覆盖 44 条资料，报价和运输通过咨询沟通。本轮补充筛选目录，历史还原版证据见 [FE-PARTS-08 日志](../../日志/2026-11-11/前端-FE-PARTS-08-配件目录还原.md)。

## 入口与模块边界

路由为`/{locale}/parts/`及`/{locale}/parts/{oem小写}/`，支持zh/en/ru。页面等待异步params/searchParams，校验locale并设置requestLocale；未知OEM返回真实404，不回退到其他商品。metadata提供三语canonical/hreflang，目前目录和详情都为noindex/follow=false，不因有SSR就开放搜索收录。导航与sitemap由当轮集成人维护。

## 资料和视觉依据

以本地 `/Users/whisky/work/ownbus/test` 的 React 项目为准。目录布局来自 `src/pages/PartsPage.tsx`、`src/components/cards/PartCard.tsx` 和 `src/styles/original/pages.css`。使用 JSON 解析器从 `public/js/mock-data.js` 提取数据字面量并逐条核对 OEM、名称、分组、品牌、价格、图片路径和顺序。

静态资料44条、唯一OEM44个、图片36个，共1,282,187字节；来源捕获时间和SHA见`data/source-manifest.json`。原始组别Engine混有ABS和连接件，展示归为机电与通用部件，保留原始资料但不推断发动机适配。44 条为当前可浏览的资料。48,689 是本地参考项目的目录规模，另列为参考值。热门车型沿用参考页面的 13 个入口，均跳到目录区域；当前资料缺少完整车型适配字段，需按 OEM 和车型咨询确认。咨询面板使用 HD 的电话、Telegram 和 WhatsApp。

每条原始资料仅有1张图；部分是OEM编号参考封面，不是实物照片。页面标注配件参考图，不拿车辆图片替代，也不复制参考的broken image。图库契约接收多图，当前不靠重复同一图片伪造多图资料。新增真实多图应提供稳定image ID并复核缩略、弹层、键盘及手机行为。

响应式以本地`pages.css`的pn布局为准：容器最大1280px，左右留白默认16px、640px起24px；目录768px以下2列、768px起3列、1280px起4列。筛选在1024px以下全宽置顶，1024px起才使用260px侧栏。两列手机卡片正文padding14px，名称14px/1.4行高最多两行，OEM和价格允许断行；图片保留本地参考的正方形比例，详情堆叠不改变图片比例。不能沿用此前公开参考页面观察的手机单列作为本地React还原依据。

## 查询、咨询与收藏

首屏搜索和目录表单均使用原生 GET，整页刷新后定位到目录。搜索、侧栏提交和排序从第 1 页开始。关键词、品牌、类别、参考价区间和排序对全部 44 条资料生效，结果栏显示本次匹配范围。收藏页单独按保存的资料计数。

FE-UX-09 的筛选框按用户截图显示 Hyundai 48,655、Kia 32、Genesis 2，以及发动机 14,168、传动 3,590、底盘 9,943、车身 1,174、内饰 19,814、紧固件与五金 0。零数量项禁用。以上为用户授权的静态展示数量，与当前 44 条可查询资料分开维护；资料和查询命中数保持真实计数。后续用配件 API facets 替换 `mock/parts-filters.ts` 的选项和计数，再由服务查询返回实际逐页结果。

品牌和大类复选框在同组内按 OR 合并，组间以及关键词和价格条件按 AND。原生 GET 提交重复的 `brand`／`category` 参数，解析后以去重的逗号分隔字符串保留在 `PartsQuery`，首屏隐藏条件、分页和细分类链接均兼容此形式。旧单选链接仍可访问，旧 `category=components` 转为 `engine`，底层仍查既有机电通用资料。内饰和五金目前没有对应本地条目，选择后显示空态。

侧栏细分类按截图分发动机、传动和底盘三组。链接带白名单 `subcategory` 参数，根据已记录的英文配件名称匹配关键词，保留品牌、价格和排序并清除大类与全文关键词。由于原始参考分组存在 ABS 列在 Engine 等不一致，细分类独立按名称检索。词表仅服务目录查找，不能作为车型适配、物理规格或已核验件类的证据。无命中时保持空态。

参考项目按每页 24 条计算目录页码，上限为 2,029。当前各页共用 44 条静态资料及其筛选结果。页码按钮提交当前筛选条件，`page` 缺失或格式异常时显示第 1 页，高于上限时显示末页。收藏模式和空结果收起页码。接入配件查询服务后以服务返回的逐页数据和总数为准。

价格区间仍由服务端解析。非法区间在刷新后提示，价格字段保持为空。页面使用新 URL 的服务端参数回显条件，原生导航和浏览器前进／返回均走同一逻辑。

详情只显示资料已有的OEM、品牌目录和类别；不补造产地、重量、尺寸、适配年份或可售库存。价格为USD参考单价，不含运费和进口费用，最终规格、数量及报价通过咨询确认。数量仅接受1–999整数；原生GET“更新数量”支持无JS，JS增强提供加减和实时草稿。无效数量不会保留可点击的旧草稿。

`buildPartContactLinks`校验slug与OEM一致，使用统一HD配置的Telegram/WhatsApp，不含竞品账号。三语草稿包含OEM、名称、数量、已知USD参考单价及对应详情URL；仅打开草稿，由客户自己发送。不要改成自动发送、机器人start参数或无关产品链接。

收藏key为`hd-auto:part-favorites:v1`，payload仅`{version:1,ids:[...]}`，仅接收当前repository提供的已知稳定ID，最多100个。目录和详情共用模块内store；同页订阅及其他标签的storage事件同步。坏JSON/旧版本作为空偏好，存储禁止/写失败时回退当前页面内存。目录的“已收藏”只显示当前静态资料中的收藏项；无JS隐藏收藏增强并保留正常目录。汽车头部抽屉仍属于汽车，不混入配件。
