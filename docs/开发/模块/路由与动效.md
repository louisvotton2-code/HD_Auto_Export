# 路由性能与交互动效

> 路径约定（2026-11-08）：本文既有实现中的 `src/`、`public/`、`tests/`、应用 `scripts/`、`out/` 与 `.next/` 均相对 `apps/web/`；文档与研究仍相对仓库根。工作区迁移没有改变这些业务实现。

本文保留 P1.13（2026-10-25）旧 IP 试运行站点的切页与交互研究，并记录后续模块变化。当时的最终检查及发布证据见[历史阶段记录](../../归档/开发进度-2026-11-07.md)，当前状态看[开发进度](../../开发进度.md)。统一任务入口为[文档导航](../../README.md)；P1.13 没有修改税费规则，也没有增加运行时服务器、动画依赖或第三方服务。

## 定位依据

在独立Chrome浏览器读取公网请求瀑布，不能把本地开发编译耗时当线上指标：

- 购车页进入计算器原先链接`/calculator/`，`StaticRedirect`调用`window.location.replace()`再整页加载俄罗斯页。两轮点击至目标约1900／1907毫秒。
- 国家页预加载完成后切换正常：俄罗斯→乌兹别克斯坦94毫秒、乌兹别克斯坦→哈萨克斯坦53毫秒；并无新文档请求。另一轮尚未预加载完成时国家切换613毫秒，说明网络和预加载状态会影响结果。
- 冷语言切换需下载约60KB未压缩RSC文本，测得940／946毫秒。首次JS、CSS、RSC也没有gzip，HTML已有压缩；单个请求的延迟约570毫秒。未发现金额计算本身造成普遍阻塞。
- 时间是当时网络下的样本，非所有设备／地区的承诺；后续比较必须使用同样路径、等待时长与新浏览器上下文，并区分冷／热缓存。

## 实现与维护位置

`src/shared/ui/navigation-link.tsx`保留next-intl／Next原生Link、真实href和默认预加载；站内计算器入口直接指向`/calculator/russia/`，国家和语言URL带结尾斜杠。保留静态入口页供旧地址及无JS访问，不再用它承接站内栏目导航。

等待状态使用Next的`useLinkStatus`，仅在请求未完成时显示金色细线、链接提示点和本语言状态文本，不显示虚假百分比、不挡住当前表单，也不延迟导航。语言链接默认不做视口预加载（next-intl防止语言cookie副作用）；仅在悬停／键盘聚焦／触摸意图时，通过Next原生router预取明确语言前缀的静态URL，不修改语言cookie。未来启用语言检测或Proxy时必须重新评估。

`src/i18n/client-messages.ts`按实际客户端消费范围装配翻译：官网外壳只含品牌／导航／联系；计算器共享词汇位于`/[locale]/calculator/layout.tsx`，各国家只携带本国计算说明和政策。`ScopedMessagesProvider`通过`useMessages`合并已缓存的父词汇，必须显式传`useLocale()`给客户端`NextIntlClientProvider`。不要在每个国家重新序列化全部共享消息，也不要在外壳重新传入整站491项。服务端SEO及购车正文仍可读取完整消息。

`src/shared/ui/interaction-motion.{tsx,css}`统一160～240毫秒的交互反馈：输入聚焦、按钮悬停／按下、费用单项及全部开合、原生details、流程进入视口和结果变化。结果金额立即更新，只淡入新值；未下载JS时内容仍可见。进入视口用一个IntersectionObserver，导航／卸载时清理；不持续监听滚动或逐帧运行计时器。导航样式单独在`navigation.css`。

费用面板保持`hidden`状态，关闭同时设置`aria-hidden`与`inert`，快速反向开合由浏览器过渡处理。现代浏览器以`interpolate-size`、离散display／content-visibility过渡提供双向高度动画；不支持这些CSS能力时正常即时开合。`prefers-reduced-motion: reduce`禁用CSS与Web Animations过渡，并取消正在执行的入场／金额动画。没有将未测试的Safari／真机行为写成已验收。

现有静态 Nginx snippet 明确 gzip JS／CSS／text/plain RSC 等文本，保持 HTML／RSC 重新验证及哈希资源 immutable。配置仅作用于本站 server；历史静态目标采用先备份、`nginx -t` 再平滑 reload 的方式，不为此改动无关服务。后续部署从[运维职责](../../协作/运维.md)与用户提供的新环境进入，先核对实际产物、配置和端口，不推定新机已有 Nginx 或旧 VPN。静态参考见[历史部署指南](../../归档/部署/静态服务器部署.md)与[Nginx gzip说明](https://nginx.org/en/docs/http/ngx_http_gzip_module.html)。

## 成品与独立网络模拟

匹配旧公网与新成品同一路由：中文购车HTML105,746→60,983字节（减少42%）、完整RSC75,992→31,201（减少59%）；中文俄罗斯HTML83,629→56,648（减少32%）、完整RSC55,218→26,460（减少52%）。这些是未压缩体积；本站gzip发布后的真实传输量另按公网响应核对。整体新成品213文件、5,269,154字节，旧版218文件、10,404,910字节；保留在release中的旧哈希资源不计入新成品体积。

独立预览固定300毫秒延迟、256KB/s（尚无Nginx压缩）：预加载后的国家切换59～77毫秒；无悬停准备的语言切换482毫秒，悬停1.5秒预加载后46毫秒。三语×七国切换并展开费用，未见运行错误、缺失翻译或新增文档导航。这些与旧公网条件不同，不能据此计算公网提速百分比。

## P1.16 固定头部与辅助入口

共享头部在`brand.css`使用sticky/top0，默认近不透明深色背景；支持backdrop-filter时改为80%背景和16px模糊，保留内容对比。无scroll事件、无新增JS状态／动画库，静态和无JS页面也能固定。层级80在正文及手机底栏之上、skip-link100与导航进度200之下。

“关于我们”和“联系我们”在header用`nav-utility`标识，不创建金色下划线或模拟页面选中。真实栏目继续用nav-active和aria-current；hover金色仅适用于支持hover的精细指针，避免触屏悬停粘连。键盘focus-visible轮廓保留，不主动blur焦点。

`--site-header-offset`按desktop／双行／手机设104／132／122px，1500px以上108px；P1.17页眉增加车源入口，双行断点由1180px调整为1350px，窄屏导航可横向滚动；globals的scroll-padding及桌面results-column sticky top共用它，避免#contact/#main/#buy-process与结果卡被头部挡住。修改导航高度时同时更新该变量。新增桌面／触屏验收在`tests/navigation-motion.spec.ts`，真实Safari验证仍待后续。

## P1.17.2 真实水波与指针倾斜修正

上一版“移动同心圆＋图片缩放”没有实现参考站交互。当前首屏由独立 `ripple-scene.ts` 维护随机／点击波纹及粒子，Canvas封装仅处理尺寸、原生click、pointermove、暂停、可见性与偏好；运动按60Hz时间归一，后台／视口外／暂停／减弱动效时不推进，也不补发积压波纹。Canvas使用CSS坐标，DPR上限2；纹理固定，避免原站每帧随机笔触的闪烁。原始参数和本站差异见[动效还原记录](../../research/首页动效研究.md)。车辆卡片按实测透视／指针相对中心角度交互，触屏与系统减弱动效时静态回退。该阶段测试通过范围见[历史记录](../../归档/开发进度-2026-11-07.md)，后续验证另记角色日志。

## P1.17.3 详情按钮 hover 命中稳定性

详情按钮旧hover向上3px，使鼠标停留底边时反复离开／进入命中区域；真实旧成品约900ms观测到28次pointerleave。该按钮取消位移，以原铜色渐变加伪元素透明度过渡提亮，保留焦点轮廓、按压与卡片3D。倾斜坐标从静态vehicleSlot取，键盘focus-visible回正，鼠标点击不额外flatten。新增浏览器测试实际检查边缘hover事件和鼠标／键盘切换，当时结果见[历史记录](../../归档/开发进度-2026-11-07.md)；当前进展以总进度和角色日志为准。


## FE-UX-02 局部数据与参考排版

本轮导航保留Next内部切换、共享68px头部和原生无JS链接；目录筛选／关键词／页码使用Next支持的原生history API更新URL，再只读同源JSON。focus／visibility／Back不再router.refresh，也不再设置inventoryRefreshing隐藏正文。失效代次即时撤下旧可售与聊天href，40ms只合并网络，延迟订阅不会丢核对事件；已失效资料仍可阅读，局部状态与重试解释其未确认性质。

首页Canvas与轮播不随数据检查重新挂载；详情450ms图片横移只保留已浏览上一图，减少动态效果时关闭运动，图库dialog清理滚动锁并返回触发焦点。购车指南FAQ静态可见。计算器新增`reference-calculator.css`，所有规则限定`calculator-reference.calculator-simple`，在refinement之后导入；红页签／浅纸结果／92px红印章只改表现，不改变税费规则、双币、公式说明、折叠、复制和水印。

## 最新用户纠偏（2026-11-08）

覆盖上文旧FE-UX-02激活核对方案：focus／visibility／普通pageshow不发业务请求。只有用户明确Back／Forward由PublicNavigationFreshness发导航信号，URL查询和手动重试仍取正确数据；不使用router.refresh或整块main遮罩。旧“激活1JSON”性能表为历史，不是当前验收目标。

流程与咨询横轨为-4px悬停抬升预留12px上下padding，以负margin抵消布局；不能让overflow-x:auto同时裁掉卡片上沿。服务问答与WhatsApp草稿使用正式文案，不展示虚构聊天证据。限流UI只更新等待倒计时，不在到期自动请求。
