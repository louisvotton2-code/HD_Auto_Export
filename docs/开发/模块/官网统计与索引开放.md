# 官网统计与索引开放

官网只向同源 `POST /api/v1/analytics/events` 发送低量公开事件，接口类型来自 `@hd/contracts/analytics`，后台聚合和存储由 API 维护。页面渲染成功后记 `page_view`；站内软导航、浏览器前进后退返回页面按一次真实展示计数。相同地址的查询参数、锚点、重新聚焦、预取、员工预览、演示详情、弹窗自动出现都不作为新访问。官网首页、目录、收藏真实卡片进入详情的操作记 `vehicle_click`；用户实际点击 WhatsApp 或 Telegram 记 `contact_click`。点击是意向，不代表消息发送、线索确认或成交。

事件只包含随机事件 ID、固定事件类型、页面分类、语言，以及需要时的公开车辆 ID 或渠道。浏览器不传 Cookie、Referer、完整地址、查询参数或电话号码；不设追踪 Cookie、不建访客标识、不写浏览器持久存储。最多 10 条一批，短时间聚合，失败不重试、不影响导航；关页发送为尽力而为。后台指标是事件量，不能据此推断独立访客。

## 开放索引时

当前继续以 `SITE_INDEXABLE=false` 和真实 `SITE_ORIGIN=https://cars.hongdingauto.com` 构建官网；公开 `robots.txt` 为 `Disallow: /`，首页 HTML 为 `noindex, nofollow`，站点地图为空。公开备案和搜索结果状态不由 robots.txt 保证。它限制抓取，可能让搜索引擎也看不到页面的 noindex；若现实中需要下掉已出现结果，按 [Google 的 noindex 指引](https://developers.google.com/search/docs/crawling-indexing/block-indexing)另行处理。

1. 在决定开始运营索引后，先用生产域名语义在隔离成品验证 `SITE_INDEXABLE=true`：三语 canonical／hreflang 互指真实域、页面状态和公开商品真实；可浏览页面为 200；缺失或撤回车辆为 404。复核移动端文本、alt、键盘／焦点及不执行 JS 时核心信息。
2. sitemap 只列返回 200、可索引的规范 URL。当前代码允许静态业务页及已发布可售自录车辆，不列过滤 URL、演示、员工预览和供应商全量。先核对目录或新收录范围、更新时间和边界，再决定是否扩展。后台、预览及 API 保留独立路由限制；测试环境保持不收录。
3. 经 OPS 正常构建切换后，实测三语 HTML 与响应头没有相互抵触的 robots 指令；`robots.txt` 放行拟收录页面、sitemap 可读取。使用 [Search Console 的 URL 检查和站点地图](https://developers.google.com/search/docs/fundamentals/get-started)小批观察，再扩大范围。需要回退时重建之前的禁爬配置，同时检查公开与后台响应。

## 以后接 Meta

当前没有 Pixel SDK、广告域预连接、像素 ID、转发接口、CAPI、同意 Cookie 或第三方发送。当有单独上线决定与可撤销的营销同意后，再把真实提交的页面访问映射为 `PageView`，真实车辆详情呈现映射为 `ViewContent`，用户主动点 WhatsApp／Telegram 映射为 `Contact`，采用 [Meta 官方事件参考](https://developers.facebook.com/documentation/meta-pixel/reference)；联系仍是意向。没有同意时不加载 SDK、不发送、不缓存待回传事件，也不补发同意前的事件。避免默认自动匹配个人资料；顾客标识、手机号、完整查询、输入内容和后台数据不进入映射。测试模式验证拒绝、接受、撤回、软导航不重发和零外呼场景；若未来采用 Pixel + CAPI，同次动作共用事件 ID 做去重。
