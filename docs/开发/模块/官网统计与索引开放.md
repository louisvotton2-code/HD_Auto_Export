# 官网统计与索引开放

## 页面及联系汇总

网关按北京时间小时、语言和页面类型汇总符合条件的成功 HTML 文档请求，排除预取、RSC、后台、静态资源和已知爬虫。本轮新增访问量口径由 BE 和 OPS 联调。符合条件的请求按可信来源 IP 跨语言、跨页面滚动去重，首次访问计入所在小时，随后 60 分钟内的重复请求不延长窗口。同一来源在 10:59、11:01、11:59 访问依次计 1、0、1，共用网络出口时多个访客可能合为一次。访问量独立于 Cookie、隐私告知和会话同意，页面浏览量仍是单独指标。

用户接受统计后，主动点击公开车辆的 WhatsApp 或 Telegram 时，官网向同源 `POST /api/v1/analytics/contact-count` 单独提交一次严格 JSON `{vehicleId,channel}`。省略 Cookie 和 Referer，后台按启用范围决定是否保存汇总。请求在后台发送，失败不重试。全站通用联系、演示车、预取和自动弹窗均排除。此汇总不保存会话或事件标识、原始 IP、来源 URL 或聊天内容。点击代表联系操作，实际询盘和成交另以业务回执统计。

## 可选会话统计

部署范围启用且访客明确接受后，官网才向同源 `POST /api/v1/analytics/events` 发送事件，接口类型来自 `@hd/contracts/analytics`。页面渲染成功后记 `page_view`，站内软导航及前进后退按真实展示计数。相同地址的查询参数、锚点、重新聚焦、预取、员工预览、演示详情及自动弹窗排除。真实车辆入口激活记 `vehicle_click`，经同意的车辆联系另可进入会话漏斗。联系汇总与漏斗分别显示。

v2 新增 `filter_submit`、`search_zero_results` 和 `calculator_complete`。筛选只有合法提交才记一次，零结果要求该次提交成功且精确为零，费用事件要求用户操作后产生有效结果。分析同意生效后，浏览器在当前标签页的 sessionStorage 保留会话随机 ID、顺序、固定入场页／来源／活动／设备枚举及最后事件时间，事件间隔满 30 分钟开始新会话。每条事件入队前附加 ISO 格式的 `occurredAt` 和会话固定的 `entry`，服务端再按时间范围校验。仅把白名单内的活动值发送到同源。撤回后取消队列和在途发送、清除分析会话，已送达的事件按服务端保留期处理。

事件体不携带 Cookie、Referer、完整地址、查询参数、自由搜索词、聊天或手机号。最多 10 条一批，失败不重试、不影响导航；关页发送为尽力而为。采集协议兼容旧版官网，v2 官网应在接受扩展字段的 API 后切换。报表区分事件量、会话与独立 IP 估算。

## 开放索引时

正式官网为 `https://hongdingauto.com`，生产构建和运行使用 `NEXT_PUBLIC_SITE_URL=https://hongdingauto.com`。当前为 `SITE_INDEXABLE=static`，`robots.txt` 放行三语「关于我们」和「如何购车」及所需静态资源，站点地图仅列这六个页面。首页、目录和车辆详情继续使用 `noindex`。抓取限制可能让搜索引擎也看不到页面的 noindex；需要下掉已出现结果时，按 [Google 的 noindex 指引](https://developers.google.com/search/docs/crawling-indexing/block-indexing)处理。

1. 在决定开始运营索引后，先用生产域名语义在隔离成品验证 `SITE_INDEXABLE=true`：三语 canonical／hreflang 互指真实域、页面状态和公开商品真实；可浏览页面为 200；缺失或撤回车辆为 404。复核移动端文本、alt、键盘／焦点及不执行 JS 时核心信息。
2. sitemap 只列返回 200、可索引的规范 URL。v2 的目录、首页、关于、购车指南和国家计算器使用三语元数据，车辆由 BE 的逐语言资格和名单决定，第三方最多选 1,000 个身份。索引开启的车辆详情在现有本地化内嵌查询里加 `seoView=eligible`，普通和旧详情请求保留原形状；`data.seo` 缺失按无车辆索引资格处理。组合筛选、搜索、演示、配件、隐私说明和员工预览不收录。官网本地 sitemap 读取完整有界名单；生产由 OPS 发布同一资格的数据分片并原子切换。后台、预览及 API 保留独立路由限制，测试环境默认关闭收录。
3. 经 OPS 正常构建切换后，实测三语 HTML 与响应头没有相互抵触的 robots 指令；`robots.txt` 放行拟收录页面、sitemap 可读取。使用 [Search Console 的 URL 检查和站点地图](https://developers.google.com/search/docs/fundamentals/get-started)小批观察，再扩大范围。需要回退时重建之前的禁爬配置，同时检查公开与后台响应。

## 访客隐私设置

三语首访横条提供「接受」和「拒绝」。接受一并允许站内会话统计、车辆联系计数和合资格的 Meta Pixel 投递。拒绝、尚未选择或隐私页撤回时，当前官网停止这三条浏览器上报。浏览、查车、计算和联系可按原方式使用。网关访问汇总依照服务端口径采集。

两把既有浏览器存储键继续用于复访和跨标签撤回。原先同时允许会话与官方 SDK 的选择继续有效。任意一项已有明确拒绝时整组关闭。仅有旧单项许可、只读记录或旧轻量 Pixel 许可的访客需选择一次。仍打开旧版网页的访客刷新后采用本轮联系计数规则。

非环回官网默认关闭会话分析。正式启用要为官网构建和运行配置 `ANALYTICS_V2_ENABLED=true`，并与 BE 的实际开放范围、允许来源同步。部分页面预生成，切换开关时应同时重建官网并更新整页缓存，核对预生成和动态页面文案与请求一致。当前本地环回可直接验证启用流程，显式 `false` 可验证关闭流程。

## Facebook Pixel

Meta 域名验证值由 `siteConfig.domainVerification` 统一提供，输出到官网公开 HTML 的 `<head>`。域名验证使用 Meta 后台登记的公开域名，应先检查该域名上线后返回的首页源码。验证标签不参与 Pixel 发送。

Facebook Pixel 仅用于后台开启的公开车辆详情，默认关闭。上线时在官网构建和运行配置 `HD_META_PIXEL_ENABLED=true` 与公司授权的 `HD_META_PIXEL_ID`，并先启用兼容的 BE。旧版按环境变量维护的车辆名单由后台单车开关取代。后台按稳定车辆标识保存，人工车 UUID 和 `ext-` 外部车 UUID 使用各自的管理入口。

网站开启 Pixel 时，在原有公开详情请求上协商 `view=localized&projection=detail-inline-v1&pixelView=eligible`，沿用 SSR、详情路由检查和已有的浏览器恢复路径。允许上报的唯一布尔值是 `data.pixelEnabled === true`。旧版请求保留原形状，未配置 Pixel 时官网沿用普通详情投影。配置公司 Pixel ID 后，后台按车切换只更新数据，不必重新发布官网。广告落地页使用开启车辆的详情 URL，多辆车可复用同一个 Pixel ID。

详情协商参数进入现有数据缓存键。SSR、官网公开代理和已打开浏览器恢复均允许在带可选资格的请求被返回 400 后，去掉资格参数按相同详情投影重试一次。兼容结果保留详情展示，资格缺失时该页无车辆索引资格、Pixel 关闭。正式切换与回退仍使用同版 Web／API 和各自发布版本的缓存。

详情当前使用随公共目录版本生效的数据缓存。保存开关后，版本更新使新打开或刷新的三语详情读取新状态。已有页面可以保存打开时的状态，浏览器从后退/前进缓存恢复时通过既有详情请求重新确认再启用 Pixel。普通聚焦或切回标签页仍不刷新。

官网在访客允许广告衡量、车辆详情显示最新公开资格时，才异步加载官方 `fbevents.js`。每次有效详情访问发送一次 `PageView` 和一次 `ViewContent`，其中 `ViewContent` 带公开车辆编号 `content_ids`。点击本车 WhatsApp 或 Telegram 链接发送 `Contact`，另带 `contact_channel`。两个带车辆参数的事件都使用 `content_type=product`。客户发出消息、达成交易需另凭业务记录确认。[Meta 标准事件](https://developers.facebook.com/documentation/meta-pixel/implementation/conversion-tracking)

官网在 SDK 初始化前关闭自动配置，在初始化后只允许 `trackSingle` 投递。这个顺序防止浏览器从历史记录恢复页面时出现重复计数。SDK 会在脚本加载后另行拉取像素配置。官网等待对应配置就绪、SDK 解锁，再检查当前页面、车辆与广告许可。遇到广告拦截、SDK 接口不兼容或加载失败时，联系链接照常打开。换页、车源失效或撤回时清除官网待发事件。审核 SDK 升级时应使用当期官方脚本验证延迟配置、前进后退及跨标签撤回。SDK 可能向 Meta 提供页面与来源网址、广告和浏览器标识及网络信息，公开说明见三语隐私页。[Meta 官方高级配置](https://developers.facebook.com/documentation/meta-pixel/advanced)

业务验收使用「事件管理工具 → 测试事件 → 确认你的网站事件设置正确」。从此入口打开试点详情页，允许广告衡量，核对两个浏览事件、两个渠道各一次点击及其参数。普通未推广车作为零事件对照。分别记录本地拦截结果、Meta 后台实收结果及正式投放后的归因指标。
