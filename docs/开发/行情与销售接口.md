# 行情与销售查询接口

## 公开市场价格

`GET /api/v1/public/market-prices?locale=zh&make=toyota&model=rav4`。`make`、`model` 使用官网筛选返回的 ID，必须同时提供。`locale` 支持 `zh`、`en`、`ru`，缺省为 `ru`。可选 `trim`、`yearMin`、`yearMax`、`mileageMin`、`mileageMax` 和 `powertrain`。年份与里程上下界均包含端点。

共享契约从 `@hd/contracts/public` 导出 `MarketPriceQuerySchema`、`MarketPriceResponseSchema` 及其对应类型。成功信封的 `data` 包含以下字段。

| 字段 | 内容 |
| --- | --- |
| `sampleCount` | 去重并满足本次筛选的可比报价总数 |
| `asOf` | 汇总取样时间，ISO UTC |
| `fx` | 同一有效汇率的 `asOf` 和 `source`。缺少可用汇率时为 `null` |
| `statistics` | `min`、`max`、`mean`、`median`、`p25` 和 `p75`。每项为 `{usd,cny}` 或 `null`。金额使用十进制字符串，`usd` 可为 `null` |
| `extremes` | `min` 和 `max` 各为实际 `{vehicle,detailPath}` 或 `null`。`vehicle` 是官网现有单封面卡片 |

自录车须有公开的中国所在地、在售状态和无附加项目的裸车报价。已公开的懂车帝和车168来源是中国国内车源，缺省城市仍可纳入，已撤回、隐藏和无法比价的挂牌排除。三方用供应商已确认的代表关系和稳定来源身份去重。自录与三方之间须有正式关联才可合并，接口保留各自独立的公开身份。面议、预订、售出和含运税等附加项目的报价均不参与。历史纯美元自录价须用同一有效汇率折算成人民币才能纳入。

空样本的统计和极值均为 `null`。第 25 和第 75 百分位只在样本至少为 10 条时返回。同语言、品牌和车型的筛选可复用已有完整车型取样及其 `asOf`。冷查询带筛选时可直接从数据库读取完整的筛选范围，并报告实际取样时间。查询结果最多沿用首次取样 10 分钟。每次返回时重新核对极值符合筛选、当前公开且报价相同。极值资格或汇率变化时重新取样。可能超过样本缓存行数的查询由数据库对完整范围计算精确统计。查询超出时间或资源预算时返回可重试的 503，公开接口不会返回部分样本。

## 销售系统查询

两个销售接口只供服务端读取。请在 `Authorization: Bearer …` 内传专用凭据。两条路径共用独立预算，未配置时返回 404，凭据无效返回 401，预算不足返回 429 和 `Retry-After`。响应包含 `Cache-Control: no-store`。

两条路径和轮换中的凭据共用每进程每分钟 60 次的凭据预算，同时保留每 IP 限额。校验通过的查询最多同时读库 2 条，额外最多 24 条先到先服务排队，等位上限为 2 秒。队列满或等位过期返回可重试的 429 和 `Retry-After: 1`。

- `GET /api/v1/integrations/sales/vehicles` 允许只筛预算、动力或驱动，无须选品牌、车型。支持与行情相同的结构化范围，另支持 `drivetrain`、`priceMin`、`priceMax` 和 `priceCurrency`。预算按明示的 `CNY` 或 `USD` 比较，`drivetrain=four_wheel` 匹配明确记录为 `awd` 或 `four_wd` 的车。`limit` 缺省 5，最多 20。`data` 为 `{items,nextCursor,asOf}`。下页保持原筛选并原样传 `cursor=nextCursor`，游标为 `null` 表示末页。
- `GET /api/v1/integrations/sales/vehicles/lookup` 接受一个 `stockCode` 或 `detailUrl`。`stockCode` 为 `HD-` 自录车号或 `HX` 第三方公开咨询号。`detailUrl` 是配置的受信官网 origin 上的完整车辆详情链接，且须去除 query 和 fragment。解析仅取精确公开身份。仍保持公开的已售或已预订自录车可查。`data` 为 `{vehicle,asOf,configuration}`，配置项使用现有公开配置白名单，按 `configurationLimit`（缺省 20，最多 50）及 `configurationCursor` 分页。配置版本变化时旧游标返回 409，请从第一页重新读取。

`SalesVehicleSchema` 只返回公开车号、标题、详情路径、来源类型、所选车辆事实、报价、币种、公开可用性及时间。销售响应无图片、采购成本、私有联系方式或供应商原始记录。共享导出 `SalesVehicleQuerySchema`、`SalesVehicleListResponseSchema`、`SalesVehicleLookupQuerySchema`、`SalesVehicleLookupResponseSchema`。

同平台、同挂牌身份的正式来源一旦接管，旧样本编号和旧详情链接在客服单车查询中均返回 404。正式挂牌隐藏或撤回后仍沿用这条规则。对正在展示的第三方车源，供应商的有效挂牌证明可用于筛选，本站公开 `availability` 仍为 `unknown`，客服应告知客户实物库存待核实。

## 本机受控请求

令 `SALES_API_TOKEN_FILE` 指向仅文件所有者可读取的本机绝对路径。服务端开启此文件后需要重启。换钥时可同时配置 `SALES_API_PREVIOUS_TOKEN_FILE`，让客户端切到新钥匙后移除旧配置。详情链接使用 `SALES_API_SITE_ORIGIN` 配置的精确 origin，本机为 `http://127.0.0.1:3363`，默认官网为 `https://hongdingauto.com`。

从仓库根运行下列命令。脚本只访问回环 3363，不跟随重定向，从私有文件读取请求凭据。

```sh
pnpm --filter @hd/api exec node --import tsx src/sales/local-request.ts feed locale=zh drivetrain=four_wheel priceCurrency=USD priceMax=25000
pnpm --filter @hd/api exec node --import tsx src/sales/local-request.ts lookup locale=ru stockCode=HD-000001 configurationLimit=10
```
