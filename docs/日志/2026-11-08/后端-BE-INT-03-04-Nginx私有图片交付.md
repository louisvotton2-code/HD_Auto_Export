## 方案

- 唯一协议见[车辆接口第12节](../../开发/车辆接口.md)：`MEDIA_DELIVERY=direct|nginx` 默认 direct；nginx 仅返回固定 `X-Accel-Redirect: /_hd_media/<UUID>.webp` 或 `<UUID>.thumb.webp`。外部 URL 与媒体 ID 保持原约定，不返回磁盘绝对路径。
- API 每次先核对公开当前发布引用或员工预览权限，再检查私有文件的存在、常规类型、单链接、大小和权限。原图／缓存 thumb 不读正文进 API；缺失 thumb 才生成固定衍生文件。未授权／软删／下架不返回内部跳转。
- 0700／0600 不放宽，Nginx 同 APP_UID 只读挂载；internal 目录只接受固定文件白名单，外部直达 404。no-store、关闭 ETag／修改时间缓存／Range／文件缓存；特殊条件头可在授权后产生 304／412。已授权响应可能完成，之后的新请求仍重新授权。检查与发送之间缺文件返回 Nginx 404，不回退其他文件。
- 对象存储是后续适配边界，不作为首期服务器上线前提。更换介质不改变业务引用和授权；签名链接／CDN 的过期撤销须另行验证。
