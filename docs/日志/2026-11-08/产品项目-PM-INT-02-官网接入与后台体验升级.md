## 本轮产品决定

- 公开车型样例使用结构化 `source.kind=demo` 区分；保留 `availability=unknown`、无库存核验时间、价格待询，不伪造实车的地点、制造日期、里程或 VIN。BE 实施契约与发布规则后方可录入发布。
- 样例仍需图片来源依据与当前版本的完整三语内容；允许进入本地展示区块，卡片、详情、库存标签与询盘草稿均明确样例／非库存，不进入 sitemap，详情 noindex。样例文案由 Agent 草拟与复核，尚未用户人审，译文保留 machine 来源与 pending，公共 reviewed=false；demo 可凭非空且非 stale 的三语展示，manual 仍必须人工 approved。
- 真实 `manual` 记录的发布核验门槛不变。样例不能通过批量操作变为真实在售库存。
- 两条样例验证的是后台→API→官网数据流程与展示效果；G1 真实内容与 G2 首批实车验收仍需要用户提供实际车源。
