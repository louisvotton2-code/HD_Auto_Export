## 限流与身份边界

- 限流键来自服务端匹配后的固定路由类别与 `normalizeIP(request.ip)`。公开 JSON、公开媒体、管理业务、健康检查各为 120 次／60 秒，鉴权路由仍为原 30 次／60 秒；各类独立。这里保持的是每桶额度，不是将拆分后的总额度仍声称为全局 120。
- 所有媒体 ID、原图／thumb、GET／HEAD 共用媒体桶，JSON 各路由及查询变化共用 JSON 桶；客户端无法通过 ID、参数或专用头选择新桶。IPv4 映射地址与默认 IPv6 /64 归一规则保留。
- API 只使用 Fastify 按明确可信对端解析的 request.ip，不消费 X-HD-Visitor-IP 作为身份；调用者的 X-HD-Client-IP 也不会控制 Better Auth 的来源。测试覆盖可信 proxy／web 的同访客共额度、不同访客分开、不可信对端伪造头、伪造左侧链、缺访客上下文及 IPv4／IPv6 归一。
- 全局 onRequest 先设置安全响应头并拒绝畸形／zone 地址；路由限流随后执行。管理身份／Origin 检查移至 preParsing 并返回原 payload，因此超额请求不再访问会话／员工查询，未登录或 Origin 错误的上传也不会先进入正文解析。
- 既有 Retry-After 修复保留：429 使用插件实际剩余秒数，未设置时才补 60 秒；503 保持 5 秒。限流错误继续匹配公共错误契约。

## 已修复 P2

初版管理鉴权位于应用全局 onRequest，而限流插件使用路由 onRequest。401／403 会在计数前结束，且超额合法请求仍先执行会话与员工 SQL；这使“管理桶有界”的承诺不完整。

实现者已按上述顺序拆分。新增独立执行的回归证明：120 次未登录请求后第 121 次为 429；换管理路由或补有效 Cookie 不能绕过耗尽的桶；超额后 getSession／员工查询次数不再增加。大于 10MiB 的上传在无会话时先返回 401，缺失／错误 Origin 时先返回 403，仅身份与 Origin 合法时才触发解析器 413，媒体上传方法未执行。P2 关闭。

## 媒体授权与交付

- MEDIA_DELIVERY 仅允许 direct／nginx，默认 direct。publicRead／publicFile 共用同一当前发布引用、ready、发布状态及未软删检查；preview／previewFile 共用 ready 与活动车辆检查，HTTP 预览仍先验证员工身份。每次授权均重新查询，失败或数据库异常不会准备文件名或回退读取正文。
- nginx 模式仅返回经过文件检查的固定小写 UUID 原图／thumb basename，HTTP 层再次用白名单校验后构造 `/_hd_media/…`。成功上游响应为空正文、image/webp、no-store、nosniff、X-Accel-Expires: 0；无任意目录、URL、查询串或换行进入重定向头。失败没有内部重定向头，存储异常信息不泄漏私有路径。
- LocalMediaStore 通过 O_NOFOLLOW 打开的句柄与 fstat 检查常规文件、单链接、私有权限及大小。原图和已缓存 thumb 的 prepareDelivery 只读取元数据；首次 thumb 才读取已有处理图并生成固定衍生图。缓存存在也必须保留有效原图，原图在生成过程中消失会失败关闭，不以孤立缓存替代。
- 并发修正经过最终静态复核：同进程实例通过共享未完成任务合并生成，生成前再检查已完成缓存；临时完整文件原子发布。句柄打开后文件被删除／替换导致 nlink=0 时映射为缺失，仍不读取该句柄，不放宽 nlink>1 拒绝规则。确定性 stat 钩子测试覆盖这种替换／删除，不把它描述为多进程永远不会短暂返回 404。
- direct 模式仍返回已授权正文，无内部跳转头；新路径不修改公开图片 URL、媒体所有权或删除规则。服务授权抽取的 SQL 条件与旧 Buffer 路径一致，本轮未改变持久化业务 SQL。

## 文档与 OPS 边界

唯一接口第 11／12 节、API README、无密钥示例和架构与本轮实现一致，明确源码完成不等于运行启用。Nginx 的 internal 白名单、同 UID 的只读媒体卷、禁止外部直达／符号链接／缓存、请求撤销与特殊条件头行为是 OPS 待验证的实际运行条件。

API 注入能够确认授权后才发内部 URI、空正文与安全响应头；它不能证明 Nginx 已正确发送文件、隐藏内部头、处理 Range／304／412、权限故障或删除竞态，也不能证明 Web 入口已封闭并传递可信访客身份。文档没有承诺追回已经发出的字节；在途已授权交付和撤销后的新请求分别处理。FE／OPS 实际链路须单独留证。
