# AD-CONFIG-COMPAT 车辆配置兼容与导入提示

- 固定 AD 工作树 `websit-worktrees/ad`，本地分支 `codex/ad-config-browser-compat`，基线 `7624502fb4bebe81129fa6a329dc9d3935e13f6b`。改动范围为车辆配置导入和相应的后台 HTTP 调用及测试。
- 基线构建产出与报告同名的脚本 `index-Bl7UcNzu.js`。模拟浏览器缺少 `AbortSignal.any()` 后，点击下一步成功创建隔离草稿，进入车辆配置时在 `526:6650` 复现同一 TypeError。后台在读取该草稿的三语资料前会调用此方法。
- 配置页面的读取、预览和保存现使用 `AbortController` 与定时器。离开时取消当前读取，保留原来的 20／25／35 秒超时。超时清理监听与定时器。保存结果不明时继续提示读取当前草稿核对。
- 只读实际导入文件。108 个配置中有 29 个把语言代号 `zh`、`en`、`ru` 填成实际值，触发 58 条相同值校验。其余 79 项通过 JSON 校验。校验提示现在按配置项合并两条语言提示，并提示填写实际值。AI 提示词也明确要求缺少可靠数值或型号时省略整项。共用校验、草稿和原始 JSON 保持不变。
- 公共契约构建、后台构建及类型检查、128 项后台单元测试、6 项隔离限制检查及 28 项边界工具测试通过。6 项定向 Chrome 模拟通过，包含去掉 `any` 后从新建进入第二步、去掉 `any` 和 `timeout` 后上传／预览／确认保存，以及错误重试和不明保存结果的恢复。
- 独审发现单语言值错误丢失具体路径，已修复并复核。单条保留具体语言，多条才合并。增量 Chrome 用例确认占位值只报一次且预览请求为零。复现与验证记录在本机 `docs/private/ad-config-browser-compat/`。
- 当前为本地修复候选。实际受影响的浏览器版本和上线后的同一车辆录入待验。
