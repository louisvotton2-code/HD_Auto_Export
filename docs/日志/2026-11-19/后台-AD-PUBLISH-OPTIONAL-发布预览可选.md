# AD-PUBLISH-OPTIONAL 发布预览可选

- 用户决定网页预览只作辅助。后台固定工作树 `../websit-worktrees/ad`，分支 `codex/ad-optional-publication-preview`，已核对并切到远端主线 `e05e3732038a78c8007c060b846d0c88b0627a01`（本地 `v1.0.17` 标签）。保留既有交接记录，钩子检查通过。
- 最后一步先显示发布检查、库存核验和发布按钮。官网三语预览默认收起，员工主动打开时才创建 iframe，收起则关闭当前实例。失败和预览独有的 401 只影响卡片，可重新载入。缺项恢复后可在当前页重新检查。
- 有发布权限的员工可在资料保存且服务端检查通过后，直接「确认并发布」。后台用同一份中文 `publish-readiness` 的草稿版本、公开修订、指纹和语言调用既有确认接口，再按同一草稿版本发布。无须等网页渲染，实际确认和发布仍执行会话、权限、版本、库存、有效图片、必填和三语校验。保留显式点击、幂等及结果未知恢复。审计页面显示「确认发布资料」。
- 最终后台类型、128 项单元、6 项隔离限制检查及构建通过。初次 35 项定向 Chrome 模拟通过。独立审查指出预览 401 会锁住工作台及同版本缺项恢复无法刷新，两项已修并复查。增量 5 项模拟通过，包括不打开预览、预览 503／401、真实确认请求 401 和恢复后重新检查。
- 隔离真实 API／FE 和一次性 PostgreSQL 的两条 Chrome 用例通过。合成 editor 在未打开预览的情况下完成库存核验、发布和三语公开验证，缺库存时直接请求仍返回 422。另一用例让私有封面或选中图片返回 401／403／500 或请求中断，核对错误、重试恢复及发布按钮。最终在封面 500 尚未恢复时点击，收到发布 200。本车只发出一次确认、一次发布及零翻译请求。证据在本机 `docs/private/ad-publish-optional/`。
- 应用说明和 AD 架构已更新。联合发布时同步共享合同中「确认使用已呈现 proof」的描述，确认取自同版本 `publish-readiness`，预览消息仍用于显示状态。服务端接口和 FE 隐私策略维持现有行为。员工设备和线上同版行为待验。
