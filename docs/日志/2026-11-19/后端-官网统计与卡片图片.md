# 官网统计与卡片图片后端交付

固定 BE 工作树 `codex/be-analytics-card`，基线 v1.0.19 `754655c3412aa9086e7c1ee9d13c8357c77d81b3`。生产核对时官网为 v1.0.19，API 为 v1.0.18。

- 官网同源匿名采集经 Origin、体积、限流和公开车辆校验。重复事件七日去重，原子更新北京时间日表。管理员可查看 7／30 天总数、趋势与车辆排行。首批有效采集时间单独记录，清理过期聚合后仍可用于区分未采集的日期。详情浏览也计入总页面浏览，联系点击仅计链接点击。采集默认关闭，启用需要明确的 `ANALYTICS_ORIGINS`。
- 车辆公开图片新增 `variant=card`，私有 WebP 宽高均不超过 800px，新旧图片按需生成。单进程合并重复请求，并限制同时进行的不同图片生成。临时回退显示原图时用 `no-store`，稳定卡片图每次先校验公开权限再处理 ETag。原图、缩略图和员工预览保持原路径。
- 隔离 PostgreSQL 与 Fastify 定向测试 95 项，共享契约测试 97 项通过。覆盖账号权限、日期和采集起点、统计去重、撤下车辆、限流、迁移缺失就绪 503、旧图并发、图片 `304` 和访问撤销。API 类型检查与 OpenAPI 生成通过。
- 发布组合由 OPS 验证。先应用 `0034_public_analytics`，按实际环境开启同源采集，核对新网关媒体路径、卷扫描、归档恢复及旧镜像回退。旧权限扫描不识别卡片文件，回退前须演练兼容入口或暂存可再生卡片文件。BE 本轮证据不覆盖正式网关部署、真实车源写入或生产压测。
