# FE-HOME-EXACT-COUNT 首页真实目录总数

- 固定 FE 工作区 `../websit-worktrees/fe`，分支 `codex/fe-home-daily-count`，基线 `6bffd14bd444e05526c6b36f549c734003754480`。本轮恢复首页真实总数，移除日期生成逻辑，接续已有三语标题与公司数字动画。
- 首页复用现有服务端筛选读取及其短时缓存，正常响应中的 `data.total` 是当前语言公开目录的精确总数。仅在筛选请求成功、缺少总数且未限流时，服务端以每页一辆的目录请求读取精确元数据。拿不到精确值显示 `—`，明确的零显示 `0`。
- 首页 HTML 直接输出本地化总数。车源数字无动画，首屏浏览器无需请求业务接口来补这个数字。满意客户和 23 年经营年限从零计数，关闭脚本或启用减少动效时显示终值。
- 故障恢复沿用显式重试。混合目录在筛选请求恢复时可直接更新精确总数。仅自录车源环境的筛选契约没有总数字段，首次失败后若重试只恢复了筛选项，完整刷新首页可通过服务端兼容路径补齐总数。
- 验证：隔离路由类型生成及 TypeScript 检查通过，11 项单测和 8 项浏览器检查通过。覆盖三语 320px 首页、目录真实总数与首屏浏览器零车源数据请求、动画、无脚本、限流与手动恢复。开发服务器的升级提示曾中断浏览器测试，在一次性测试目录关闭提示后完整复测通过。独立只读审查与差异检查通过。3363 未监听，真实本地后端及生产环境未实测。
