# BE-V220 英俄短词校验与详情物化

基线为 v2.0.19 `4ee3bbd51f5d382ae3c4bb74791c6c2df740b298`。BE 候选分支 `codex/be-v220` 只包含 API、共享契约、定向回归及本轮文档。中文搜索草稿维持原范围。

英俄目录的短词门槛由共享契约判断。`make` 或 `model` 为规范 ID 时继续按原条件搜索。公开列表、筛选及内部 SSR 对应请求查缓存和数据库前返回 400 `CATALOG_SEARCH_TERM_TOO_SHORT`。旧链接保留输入并显示提示由官网接入。[接口约定](../../开发/车辆接口.md#公开关键词查询)

详情先归档，再以 5 秒内可启动的单车事务物化。已经开始的事务沿用原数据库设置。首次 PostgreSQL 语句取消结束本轮详情写入，后续 tick 先处理撤回和增量，还可在容量门禁允许时补一个报告槽。只对实际失败且仍匹配的代次登记一次退避；容量或租约拒绝不消耗车源重试。已归档语言可跨进程复用。

物化阶段记录包含 worker fence、匿名车辆标识、任务代次、查询分支、耗时和数据库分类。每片汇总一次，另外采一条较慢或失败事务，语句取消始终记录。OPS 按同一负载比较每百辆提交的读块、WAL 和耗时，依赖独立隔离对照。既有引用晋升和只写图库差异仍需确认收益和来源、签名、人工覆盖等语义；候选维持这些写入规则和现有迁移状态。
