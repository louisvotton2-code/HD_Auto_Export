# 推广车联系转化

基线为 v2.0.22（5117a52），官网固定树 codex/fe-meta-pixel-config。试点为海狮 06 DMi，公开车辆标识 1d923218-db7d-4bdd-b4c6-0b28a1d86953。公司 Pixel ID 1157698626957136。首次核对正式车辆详情时，页面配置为 pixelId=null，公开接口返回 pixelEnabled=false。

## 官网行为

- 只有访客已允许广告衡量、当前详情属于真实公开车且后端明确打开了单车开关时，官网才加载一次官方 SDK。三语隐私说明已更新。旧版轻量请求的许可需要重新确认，旧拒绝继续生效。两个待选用途可单独选，也可直接接受或拒绝。
- PageView 与 ViewContent 各一次，ViewContent 的 content_ids 使用公开车辆 ID。真实 WhatsApp 或 Telegram 联系点击发送 Contact，带 content_ids 及 contact_channel。推广详情里打开普通咨询弹框不发事件，实际点击其中的渠道会发送；全站通用弹框点击不会计入既有第一方车辆联系汇总。
- Meta 初始化前关闭自动配置，初始化后仅允许显式 trackSingle 事件。浏览器历史恢复时重新核对资格，避免 SDK 的自动 PageView。
- 在真实 SDK 上复现了两条不同的内部等待队列。换车时仍等待像素配置可能导致旧点击带上新车的网址；浏览器设备信息迟到可能导致撤回后仍向外发送。官网现在在本地暂存点击，等待对应像素配置解锁及设备信息就绪，发送前重新核对车辆和访客选择。离开、撤回、失效及设备信息等待超时会清理待发事件。

## 验证与交接

- 两组定向单测合计 20 项通过。官网 TypeScript、standalone 构建及模块边界检查通过。三种配置分别构建通过。Chrome 在像素与站内分析均开启的配置下通过 25 项，关闭像素通过 2 项，仅开启像素通过 1 项。覆盖三语、旧选择迁移、分用途、关闭及缺失资格、多次导航、真实和合成点击、员工预览、历史恢复，以及脚本和配置延迟。
- 首次浏览器用例沿用旧授权的注入方法，每次打开新文档都把已更新的访客选择覆盖回旧值。修正为仅在本站缺少记录时模拟旧版访客，保留原有事件断言，重跑通过。
- 独立审查用当期真实 fbevents.js（SHA256 a7f5ba25376d266859cb23a855f58fc451cf650999d886871fe38ba4c3934629）和隔离 Chrome 核对 7 次，常规、慢配置、慢设备信息、撤回与切车无重复和旧车回放。相关网络收据保存在本机 docs/private/fe-meta-pixel-sdk/。
- 本机 3363 已接入当前官网构建。OPS 核对 11 个源码及测试变更文件与候选一致，构建及运行均配置 HD_META_PIXEL_ENABLED=true、HD_META_PIXEL_ID=1157698626957136。中文[开启样车](http://127.0.0.1:3363/zh/cars/5569d9bd-f90a-4809-9241-20bbae97ffdf/)和[关闭对照车](http://127.0.0.1:3363/zh/cars/02f1079d-b761-49f1-9a88-f36d8a767ace/)均返回 200。隔离浏览器记录到一次 SDK 加载、一次 PageView、一次 ViewContent、两次 Contact（WhatsApp 与 Telegram 各一次）。对照车及撤回后均无新增事件。
- 正式海狮不在本机样本库，本机网关限制向外部投递。生产仍使用原配置。本轮授权仅合并到 main。正式试点需要另行授权，届时由运维按发布门禁接入正式像素并仅启用指定海狮。在 Meta「测试事件 → 确认你的网站事件设置正确」中打开正式海狮并按上述步骤测试，以账户事件明细核对真实收件。以后切换推广车只需保存后台单车开关，刷新详情读取新资格。
- 已在登录的 Meta 测试事件页面通过「网站」入口打开 3363 开启样车。该浏览器保留初始隐私选择，没有触发联系点击，平台未展示事件回执。两次 Contact 的证据来自 3363 独立浏览器的拦截记录。
- 访客选择位于 apps/web/src/shared/lib/tracking-consent.ts，公开详情及真实点击判定位于 apps/web/src/modules/analytics/site-analytics.tsx，SDK 加载、清理和手动投递位于 apps/web/src/modules/analytics/pixel.ts。维护指南见[官网统计与索引开放](../../开发/模块/官网统计与索引开放.md#facebook-pixel)。
