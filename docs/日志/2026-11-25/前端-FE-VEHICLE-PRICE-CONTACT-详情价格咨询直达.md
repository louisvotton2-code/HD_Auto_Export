# 详情价格咨询直达

用户要求修复手机和中等宽度详情页价格旁的「咨询这辆车」并发版。此候选从 `main` 的 `2202d20` 切出 `codex/fe-vehicle-contact-hotfix`，保护官网固定工作树尚未提交的统一隐私选择编辑。

- 生产 v2.0.22（`5117a52`）上，车号 HD-000046 的落地页 HTTP 200，价格按钮输出 `#vehicle-contact-…`。本机旧版浏览器复现了锚点触发详情新鲜度检查、额外详情 GET 和无聊天窗口。原页面未真正重新载入文档。
- 价格区按钮改为直接打开 WhatsApp，复用原有三语车辆草稿，带公开车号和详情地址。只有详情数据可用时才提供跳转，沿用真实联系点击的统计标记。详情页联系区继续提供 WhatsApp 与 Telegram。
- 使用关闭 Meta 的配置完成独立构建。9 项隔离 Chrome 用例通过，包括中文 390px 与俄文 900px 触控点击。预填内容、接收号码、原页 URL、详情请求数和页面状态均检查通过。既有三语卡片和桌面联系、无 JavaScript 联系仍通过。外部跳转在测试里拦截。
- 正式版本以最终主线构建。主线已有此前合并的 Meta SDK 源码，发布沿用现行运行开关。本候选只提交咨询按钮、针对性用例及交付记录。
