- [负载记录器](../../../deploy/runtime/ops-ext/bench.py) 仅访问本机 HTTPS 公开接口，支持 20／50／100 并发，报告每条路由成功请求 P95、非 2xx 比例和各 HTTP 状态。

## 验证与限制

- 开工 hooks、Compose 配置解析和脚本语法检查通过。首次导出受私有 umask 影响，PostgreSQL 无权读取初始化 SQL，迁移登录失败；修正归档权限、保留失败的隔离目录后重建，增加数据库及应用角色就绪条件。重跑迁移成功。
- 五个隔离服务健康，HTTPS 代理健康、中文官网、后台入口及公开目录读取通过；除代理外均无宿主端口，应用网标记为内部。八次伪造不同转发地址的会话读取中五次 200、三次 429。Redis 通过内网地址拒绝未认证请求，指定用户可写读删测试键，越界读取和 CONFIG 被拒绝。
- 空目录状态一次资源观察：代理约 11 MiB、官网 71 MiB、API 96 MiB、数据库 33 MiB、Redis 9 MiB；这些值仅用于空载基线。使用一条合成数据库记录和一张生成 WebP 完成联合备份、全新项目恢复、记录和图片字节比对。
- 负载记录器在空目录各跑 1 秒的 20／50／100 并发，列表和筛选均记录到 200 与 429。该检查验证负载采集和状态区分，未计入容量结果。
- 独立审查 `/root/ops_ext_review` 发现压测路径守卫可被点段绕过，明文非 ASCII 查询还会在发送前导致异常。修正为公开路径白名单和 ASCII 查询约束，中文、俄文关键词需百分号编码。独立复查 5 个有效及 11 个拒绝项通过，范围内无未处置 P0–P2；作者复测编码中文搜索和筛选经 HTTPS 返回预期 200／429。
- 10 万／50 万合成装载、外部车源查询与缓存冷热、正式容量门槛尚待 BE 确认接口和装载器。基线 API 单访客保护与代理保护继续生效，单来源 429 单列，不得用于推断数据库容量。未配置持续告警或异地备份。
