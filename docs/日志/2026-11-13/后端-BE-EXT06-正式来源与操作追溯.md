## 实际变更

### 固定名单与可靠接入

- 独立 CLI 提供 prepare / once / catch-up / status / recover；一次任务最多 300 个 canonical 车辆及 1000 个关联来源身份。没有定时器、持续运行 daemon 或可触发导入的公开／管理 HTTP 写入口。
- PostgreSQL 保存任务、固定成员、完整接收页、事件、lease/fence、接收游标与连续应用检查点。整页保存后推进接收游标，业务入库与应用检查点同事务；优先撤回、过期事件只归档、失败身份有限重试，不能用网络错误或 CSV 缺失推断撤车。
- 完整 CSV 流式验证 header、列数、来源、hash、字节数、行数及正常结束，并保存供应商生成时间。恢复绑定新快照时间与 hash；固定成员在新快照缺失时保留待核验，不能误标完成。410 恢复次数有界，显式追平可重开终页，范围不能被新事件扩大。
- 固定服务身份禁用且没有登录凭据／会话，人工触发管理员另记。网络目标固定、禁止带密钥重定向；网络并发 1、连接池 2、入库每批最多 200，单响应和待处理文档有容量上限。0.5 CPU / 512 MiB 容器与磁盘、资源阈值属于 OPS 运行约束，尚未作为生产实测结果。

### 完整原档、多语言与公开读取

- 按来源身份、文档类型、locale、内容 hash 保存完整 CSV/详情/specs/report/event 资料，未知字段保留。原始 JSON 字节可用时保留 exact rawText；bulk 完整外壳共用私有 blob，各车关联原响应引用，shared trim 去重。
- 字段存在性与 null 分开，稀疏更新不清除缺失字段；来源顺序、观察时间与内容 hash 分开处理。canonical 代表首次绑定后稳定，关联来源不重复进入公开目录，后续重新关联须核查，来源刷新不覆盖人工修订。
- 供应商 zh/en/ru 内容分别保存，配置要求身份及事实版本匹配；缺目标语言自由文本保持 missing，不伪装已翻译或人工审核。已知年款／配置争议保留原档，相关确认字段、标题片段及整张争议配置不公开，其他车源继续处理。自动翻译未开启。
- 全量照片和配置不受首屏 30 张图及旧 500 配置投影上限截断；列表保持轻量，公开 gallery/configuration 按车辆、语言与 revision 分页，每页重新验证当前可见性。过期或停用媒体退出公开结果，版本变化返回冲突，撤车立即不可读。
- 员工 source-documents 接口提供此车完整 payload 与可用原文；共享 bulk 仅返回 hash/shared 引用，不泄露同批其他车辆正文。会话、Origin、vehicles:read 与 no-store 沿用管理边界，原档只作文本／JSON 展示，不执行来源指令或 HTML。

### 员工操作追溯与汇率

- 复用 audit_events / external_override_events 记录操作时员工姓名、稳定 ID、数据库 UTC 时间、版本及服务端白名单字段差异，与业务修改同事务。历史无证据的姓名或 diff 保持未知，禁止修改或删除既有事件。
- 创建、保存、多语、发布、库存、覆盖、图片增删／排序／封面、删除与恢复进入追溯；图片使用稳定 ID，内部备注及任意来源 URL 只记安全的变动标识。missing、null、空串及 0 区分；失败、409、无变化保存与幂等回放不新增虚假成功历史。
- 轻量 activity 区分创建、最近人工修改、首次系统导入与最近同步；分页默认 20、最多 100，游标绑定资源与时间／UUID。公开 DTO 和 SSR 不携带员工记录。
- 正式美元报价只接受真实 exchange_rate_api 来源；缺失或过期仍待询。新增运维显式 formal-refresh / formal-health，校验正式模式、准确数据库名、发布身份和网络开关；每天最多一次受控尝试，失败保留仍有效快照但不延长有效期。GET 和导入 worker 不自动调用汇率服务。
- 迁移依次为 0018 审计、0019 任务与检查点、0020 原档与分段、0021 canonical 代表。启动不自动迁移。运行命令、恢复和回退限制集中维护在 [API README](../../../apps/api/README.md#ext06-固定名单正式导入与员工追溯)，接口以[车辆接口第 20 节](../../开发/车辆接口.md#20-be-ext06-员工追溯与完整车源分段实施中)为准。
