## 十万挂牌同步

上线后的初始读数：累计准入 16,244 条，已处理 10,297 条，公开去重 8,201 辆，数据盘 9%。准入包括尚待补齐的车源，不能当作已完成。PM 依据用户本轮原始授权执行一次正式 resume，控制版本 3→4；没有手写 allow 或清除容量等待。新容量实测随后自动放行，服务器唯一 worker 开始扩量。只读观察器按实际详情处理数记录 25k／50k 节点，公开数沿用正式 API 的可见性口径，最终分列已撤回但未取详情的身份。

运行发现：轮巡刷新首万样本会改变证据 hash，25k 前触发重复的两次串行压缩，每轮约 5 分钟。BE 核对代码、OPS 核对两次生产证据，确认普通非样本详情增长本身不使 hash 变化。局部修正仅让显式有界、样本充分的任务提前使用已有物理占用模型；未配置有界目标仍要求压缩证据。固定 CSV、历史资料、现存备份及恢复开销继续计入，100,000 硬上限、当前证据绑定、实时和预计 70% 暂停均不变。

同一份生产证据的压缩预算峰值约 100.4 GiB，物理预算约 181.5 GiB（46.2%），后者更保守且低于 70%。隔离 Linux 20 项容量测试通过，同一 Reviewer 两文件增量审查通过。该修正仅涉及宿主容量脚本，不改已发布的三端应用和 `v1.0.2` 标签；脚本的实际发布及后续数量在下一次交付结果中更新。
