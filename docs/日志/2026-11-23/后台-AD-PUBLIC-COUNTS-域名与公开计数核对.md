# AD-PUBLIC-COUNTS 域名与公开计数核对

固定后台工作树，分支 `codex/ad-public-count-scope`，基线 `2ce683ec69c52a6bb54190e52beb2ffbcf870476`。

- 后台公开车源核验和「查看公开接口」读取同源公开 API。发布预览继续从后台同源读取受保护的 `/staff/vehicles/:id/publication-preview/`。分析读取同源接口，热门车辆进入后台对应车源。后台源码、成品和后台技术文档均无旧官网域名的固定引用。
- 三方概览、筛选和状态标签将「已展示」改为「活跃且未隐藏」。`listings/overview.published` 统计来源挂牌，其中可能包含重复来源和未进入官网的挂牌。公开车源核验直接使用所选语言及筛选条件下的公开目录总数。
- 同步卡片区分已登记来源记录、去重车辆和当前公开三方车辆。公开数为至少有一种语言可展示的公开代表车辆数。累计准入席位和批准上限仍以实际数据为准，缺失时显示暂无。
- 构建、类型检查、独立只读审查及七项隔离浏览器用例通过。覆盖概览和状态筛选、批量回执、同步计数、公开核验、可选预览、网站分析排行。隔离请求不读取真实车源。

共享[官网统计与索引开放](../../开发/模块/官网统计与索引开放.md#开放索引时)仍把旧域名列为当前构建 origin，交官网及运维集成时核对。生产切换和正式同步对账使用各自验收收据。
