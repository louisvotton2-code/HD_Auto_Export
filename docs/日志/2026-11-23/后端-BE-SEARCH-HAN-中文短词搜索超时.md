# BE-SEARCH-HAN 中文短词搜索超时

v2.0.16 `2ce683ec69c52a6bb54190e52beb2ffbcf870476` 生产在北京时间 13:17 复现 `make=byd`、`q=海狮`、中文、美元、最新卡片首屏的 503。公网完整耗时 4,641 ms，建立连接到 TLS 完成为 1,275 ms。Fastify 实际处理 3,002 ms，其中供应商精确计数阶段 2,972 ms，无回源队列或数据库连接池等待。生产只读预估计划显示，已经使用品牌索引缩小候选，但仍逐条点查中文搜索文本。昨晚矩阵没有带 `q` 的关键词请求。

## 本地实现

- 中文两字关键词继续按字面包含匹配。迁移 0050 在中文公开搜索投影集中索引同一文本里的连续汉字对，查找时保留现有字面检查。常见宽词或缺表达式索引统计时选择原精确路径。较少见的品牌短词先交叉匹配窄 ID，再读取命中车源。三字及以上查询、精确总数、字面分隔符、分页、公开标识、语言和撤车等规则按原契约处理。
- 3 秒是 API 内部的目录读取期限，包含排队、版本确认及 SQL。公网 TLS 和下载耗时单独计算。官网浏览器异步读取的现有截止为 8 秒。关键词查询共享单次后端预算，重读及 SQL 使用剩余时长，限制 HTTP 返回超时后查库仍继续占用连接的时间。超时仍返回可重试 503，保留现有限流、回源并发和撤车保护。

## 验证

- 后端 TypeScript 已通过，PostgreSQL 18.6 隔离定向测试 66 项通过。服务层和缓存回归覆盖中文标题与车型包含匹配、跨字段排除、精确总量、卡片分页、筛选、撤车、同一绝对期限和 PostgreSQL 主动终止超时 SQL。并发预建接管保留同一索引，强制预建缺失时拒绝迁移。独立只读审查未发现 P0 或 P1。
- 40 万条合成挂牌和 425,506 条多语言搜索投影下，中文 `海狮` 共 791 条，精确计数从 97.76 ms 降到 62.64 ms，计数加首屏读取从 105.12 ms 降到 74.50 ms，共享块访问量从 15,977 降到 13,464。`海豹` 共 458 条，精确计数从 114.49 ms 降到 13.28 ms。`电动`和`秦岭`走原精确路径，结果数和主要块访问量与基线一致。隔离的中文部分索引约 8 MiB，实际生产体积、维护 I/O 和访问时延需上线前后核实。
- 限定 2 核及 1,152 MiB 的 PostgreSQL 中，4 并发混合查询等权发送 `海狮`、`海豹`、`电动`。新旧各 144 请求均成功，按两轮合计 SQL P95 为 264 ms 与 204 ms（基线、候选），单轮尾延迟区间有重叠。基准使用应用生成的查询并包含候选选择和 24 张卡片的 SQL；公网传输、图片、API 序列化以及同步写入并行仍待验证。

## 上线依赖与验收

需要数据库迁移。原 OPS 按已有磁盘、同步和备份护栏安排并发预建。先在同一事务执行迁移 0050 的第一块来安装并核对函数。然后在自动提交下用当前迁移中的确切定义执行 `CREATE INDEX CONCURRENTLY external_catalog_search_zh_han_pairs_idx ON public.external_catalog_search USING gin (public.external_catalog_han_pairs(search_document)) WHERE locale='zh'`。上线迁移过程要求 `hd.require_prebuilt_search_zh_han_pairs_index=on`，登记前校验函数定义与索引有效状态。中文投影超过 10,000 行也会阻止迁移事务里新建索引。索引建好后收集 `ANALYZE external_catalog_search` 统计，使用实际应用角色核对可见的词频及短词路径。只读取证确认现网四个 API 数据库连接都持有搜索投影的表所有者权限。旧 API 可以沿用已增加的索引和函数。

候选接流前用生产统计预估 `海狮`、另一精选车型短词、宽词及筛选聚合的访问路径。接流后用少量正常只读 GET 和自然同步做定向复测，记录实际源站 `supplier_count` 或 `supplier_page` 耗时、准确总数以及撤车后的可见性。现网还未加载本轮代码或索引。
