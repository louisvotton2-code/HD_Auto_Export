## 首页命中与版本

通过当前网关私网链路对三语首页共发起 12 次 GET，均返回 200，当窗无 HIT。目录和筛选版本在约 13 秒中各前进 59，汇率版本保持一致。额外一个中文私有渲染采样得到 HTML 200、约 447 ms、316,531 字节，其中没有可接纳的双版本渲染证明，前后实时报出的两份版本也均改变。一前一后两次实时报价和目录版本检查耗时 219 ms 与 11 ms。证据说明当前活跃行情下有渲染因版本窗口不一致而无法入缓存。不能从一次采样推断版本检查成本分布，也不能用更长存活期限跨越已知版本变化。

本次仍在生产协议 2 下观察到明确的 300 秒版本证明。OPS 候选增加必须由 Web 确认的私有协议 3，默认保持协议 2。600 秒为匿名三语首页 HTML 的最大存活期限，仍取真实版本证明、渲染证明和最早有效期限，每次命中仍做实时车源及筛选版本核验。600 秒与 Web／API 能力配合后才能发布启用。公网继续 `no-store`，RSC、带查询及员工／私有请求继续旁路。隔离验证包含 300 秒后、599.999 秒、600 秒整，及混版、提前期限和版本变化。

## 根域发布衔接

候选纳入独立根域／www 与后台证书部署钩子、根域网关渲染与运行手册。切流必须使用与生产同一根域的 Web 构建、API 来源白名单及已验证的真实回退入口。现有运行版本保持原样，待联合候选、CI、合并与标签核对后执行发布。

私有收据位于主目录 `docs/private/ops-v2/root-perf-20261123/`。其中 `cache-sync-observation.json` 记录同步、版本和资源原始观测，`cache-single-render.json` 记录一次旁路检查的耗时与确认。
