## 生产观察

本机桌面 Chrome 做一次低频顺序抽样，拦截分析请求。根域 `/` 返回 307 至 `/ru/`，浏览器记录跳转约 1.36 秒，最终文档首字节 2.56 秒，最大内容绘制（LCP）3.46 秒。直达俄语首页的普通复访与刷新首字节约 0.81／0.84 秒，LCP 约 1.20／1.23 秒。三次最终 HTML 都传输了约 50 KiB（含响应头），均无整页命中标记。普通复访、刷新时首图记录约 300 字节传输，冷访问约 94 KiB。首图冷请求在文档首字节约 8 毫秒后开始。站内目录与 Logo 返回均走 RSC，无整页跳转，也未见与成功首页 SSR 重复的 JSON 首读。未把预取、图片或 RSC 计入 HTML 命中。

同轮 OPS 独立收据中，复用连接请求根路径的首字节公网约 380 毫秒、源站约 4 毫秒。正确的筛选 JSON 请求公网首字节约 383 毫秒、源站约 26 毫秒；公网新连接约 1.41 秒。初次探测筛选回 400 的 URL 缺少有效参数，使用纠正后的 200 样本。单机、小样本和不同时段只用于区分跳转、连接、服务响应和传输，无法推出客户地区的 P95。

根域切换收据中三语整页缓存各有两次命中。后续同步观察中约 13 秒内 catalog 和 filters 的 revision 各推进 59，与同期 12 次整页未命中相符，即使同语言 HTML 正文摘要一致。网关每次复用前比较当前目录、筛选和汇率版本，因此版本变化会提前使 HTML 失效。命中仍会向浏览器传输 HTML，响应保留 `Cache-Control: no-store`。当前主线整页缓存和验证凭证上限为 300 秒。若将上限改为 600 秒，OPS 与 BE 需核对网关正文保留、渲染凭证有效期和实时核验契约；撤回、改价和汇率变化继续即时失效。增加上限仅延长版本稳定时的复用窗口。

证据在本机 FE `docs/private/fe-root-perf/public-baseline.json` 及主工作区 OPS `docs/private/ops-v2/root-perf-20261123/`、`docs/private/ops-v2/domain-20261123/`。根域到 `/ru/` 的跳转保留，站内 Logo 已直达当前语言。普通复访记录的两条后台预取约 1 KiB，本轮保留既有预取。

## 前端修订

- 首页精选及两组筛选复用目录页已有的成对版本读取，首读由两个请求降为一个。任一资源发生版本冲突时单独重查当前版本。旧 API 对成对请求返回 400 时沿用按范围读取的兼容路径。目录版本或汇率变化仍按既有机制使缓存失效。
- App Router 离开已回退的路径后清理该次浏览器历史信号。真实 Back／Forward 继续核对实时车源，普通 Logo 返回首页只消费本次页面数据，避免再拉精选和车型接口。
- 官网配置示例、运行说明与现行 SEO 说明使用 `https://hongdingauto.com`。保留当前三语六页静态 Sitemap，开放范围与生产域名切换分别核对。

## 600 秒缓存与精准失效增量

基于 `a357c50`，官网两个受保护的整页端点协商协议 2 或 3。协议 3 私有票据只用于首页的精选车源、无筛选 `overview` 和 `home-models`。按当前语言读取实时版本，三条资源通过 `X-HD-Catalog-Homepage: exact-v1` 协商精准范围。实时版本和三个资源都须确认该范围。两个筛选结果须对应同一有效版本。冲突时重新读取本语言的协议 3 版本对。整页证明上限 600 秒，取实际 DTO、汇率及签名图片有效期的最早值。混版、旧 API、缺戳和过期均不能复用 HTML。普通路由及公开 API 沿用原协议。

首页总量、品牌标签和数量取全目录投影，车型标签和数量取精选车型对应的目录计数。非精选车辆退市时也可能改变首页。只有对三个实际 DTO 和版本期限均无影响的更新才可保留命中。API 精准版本区分这两种情况，官网与 OPS 网关使用同一版本对。已冻结的 BE `7a5f59c` 提供协议 3 基础能力，精准范围还需 BE 本轮增量。语言切换的浏览器 Cookie 也会影响缓存资格，验收要区分 Cookie 绕过和业务版本失效。

Node 24.19.0 下使用 BE 精准范围合同构建。官网生产构建、类型、7 项边界、1,332 项单测和 11 项普通页面／旧 API Chrome 回归通过。官网成品、OPS `19c6d35` 网关与合成 API 的 16 项回环试验通过。中英俄均首次返回正文、复访命中，模拟经过 330 秒仍命中，610 秒后重新渲染。仅全局标记变化且首页版本对不变时保留命中；精选、筛选或汇率版本变更时即时失效。核对了 429、错误协商、缺少精准范围确认、无戳数据与未授权协议头。独立只读审查无前端阻断。

回环试验使用合成 API 和模拟时钟。真实 API 生成精准版本的行为与网关一秒校验预算、实际 301 秒以上的复访、同步期三语命中与撤回时效仍需由 PM／OPS 在真实组合候选上验收。官网增量需与 BE 精准范围合同及 OPS 网关配套集成。生产未改动。
