# 已验收税则测试对齐

v2.0.17 集成候选 `e38880b` 与固定官网工作树 `59f812d` 的 `apps/web` Git 树一致。原官网发布门禁的首败和重试均停在 `fee-details.spec.ts`。用例查找撤回版的亚美尼亚 `AM.dutyMiddle`。当前个人自用统一税分支为 `AM.unifiedYoung` 和 `AM.unifiedUsed`。

以 OPS 提供的复现场景更新用例。在门槛内，固定 100 cc 和两项汇率均为 1，车价 100 USD 时取排量下限 250 AMD，车价 8,000 USD 时取比例 4,320 AMD。独立核对说明、代入公式和行内金额，保留关闭、再次打开、剔除旧值及切换生产年月的断言。2022-01 生产的样本切到按排量计征，公式为 100 × 1.5 × 1 = 150 AMD。

逐文件核对其余计算器测试的 DOM、方法键、过期文案、固定税额和字段。另在 `runtime-pages.spec.ts` 将格鲁吉亚左舵纯电的固定金额从撤回版 480 GEL 对齐到已验收的 150 GEL。原用例关于客户端计算、无额外汇率请求和不依赖图片优化接口的断言继续运行。本轮修改范围为浏览器测试及记录。

## 续跑与闭合

上次门禁已通过前 213 项。本轮从费用明细开始运行后半段 31 个测试文件，331 个场景全部走到结束。首轮报告 321 通过、5 失败、5 按配置跳过。五个跳过均为需测试 Pixel ID 的用例。报告的通过数含既有无脚本动态 404 的预期失败，原有 P2 标记和所有状态及隐私断言保留。

五处未预期失败均是旧测试对当前候选导航行为的假设。首页 Back 实际分别请求车源、概览、车型数据，各一次。目录 Back 实际请求当前页与搜索、品牌、车型三种筛选资源，各一次。修订断言保留精确请求数、查询及投影。两个详情历史用例现在检查实际文档、已售 200 和 no-store、下架 404、无旧详情／检测／联系方式、无相关 RSC 或额外 JSON。BFCache 恢复期屏蔽旧内容及局部 503 的原用例继续验证。首页卡片布局样本由隔离 API 提供给 SSR，使长俄语标题、超长价格、已售与未知状态保留，1440、390、320 像素布局断言不变。

同一已构建官网对最终两条计算器测试、五处旧断言与 BFCache 保护共 8 项全部通过。核对与 `e38880b` 同版的 437 个官网源码文件、28 个共享契约源码，以及构建和实际浏览器响应。独立审查绑定本地提交。PM 在最终集成 SHA 上复跑发布门禁，本地证据不替代整合门禁。
