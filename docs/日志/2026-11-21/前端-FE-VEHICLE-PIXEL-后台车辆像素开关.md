- 用户确认改为后台单车开关，并授权通知 PM、BE、AD 和 OPS。FE 使用固定 `codex/fe-v2-release` 工作树，基线 `11fd1b1b9f0ed5bc07c3bd18b5189d6576583350`，保留既有 v2、三语详细隐私页和域名验证。
- 官网在全站 Pixel ID 已配置时，从现有公开详情读取 `pixelView=eligible` 选择的 `data.pixelEnabled`。SSR、页面状态检查和既有浏览器恢复使用相同选择，旧请求和缺失字段兼容。公开、响应当前有效、按车为 `true` 且访客一键同意时才发事件，无额外开关读请求，无环境名单回退。Meta 请求保持只有 Pixel ID 与事件名，第一方统计事件契约不变。
- SSR 与 API 复用目录版本缓存。实时切换让新打开或刷新的三语详情读到新值。恢复浏览器后退／前进缓存时，公开详情用原有恢复请求确认数据，在核对前不发 Pixel。普通标签页聚焦无额外请求；已经打开的页面按下一次有效加载更新。

- 上报均拦截，未验证实际 Meta 收件和原生浏览器后退缓存。后台持久化、权限、真实数据缓存联动和备份恢复由 BE／AD／OPS 提供证据，PM 负责完整同版验收。正式 Pixel ID 待配置，本轮不发布或写共享车辆。
