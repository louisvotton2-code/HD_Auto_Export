- 基线：`d3c92b01cbafb58f29fcd01fd9886106398a65df`，固定 FE 工作树 `../websit-worktrees/fe`，分支 `codex/fe-rel-103`。开工核对 hooks 与既有 `apps/web/next-env.d.ts` 差异；该生成文件不属于交付。
- 首页动画数字首屏显示 0；静态备用值在样式未加载时也不会和零一起露出，启动后下一帧才递增。减少动效或禁用脚本直接显示终值；辅助技术仍可读终值。经营年限保持静态。
- 首页发给浏览器的筛选数据只保留目录总数、品牌、车型和兼容旧接口的动力分类汇总，去掉首页未使用的配置等字典。保持同语言 API 总量、未知／已知零区分、原有 429 处理和重试，不增加请求。

- 本地 3363 Chrome 只读测试：中英俄三语在阻止样式和脚本加载时仍显示 `0+` 和 `0`；正常加载中英俄以及俄语刷新均从零递增至 `660+`，目录终值为本地样本 188。减少动效和禁用脚本分别确认可读终值。补充的 Playwright 用例收录首屏可见回归场景；本轮实际浏览器证据来自 3363 的等价定向脚本，没有使用共享数据模拟限流。

## 生产只读诊断与交接

- 英文首页一笔成功 SSR 返回目录总量 79,912；中文和俄文的另两笔返回未知，同时直读三语公开筛选接口均出现 HTTP 503。样本跨时点，仅说明此次故障不支持归因于英俄数字格式，也不能确定生产已恢复。前端保留真实失败显示，待 PM 协调 BE／OPS 核对筛选服务、限制、缓存及可用的轻量计数来源。
- 俄语首页到汽车目录实测只有一次大的导航 RSC 请求，两个预取合计约 1.4 KB。一次点击 gzip 约 305 KB，首字节约 372 ms，下载约 871 ms。另一次读取解压后约 3.01 MB，其中筛选字典约 2.91 MB，24 辆车卡约 87 KB。OPS 在同类导航测得首字节 363 ms、下载 2.83 s，主机未见饱和。

## 汽车目录筛选传输优化

- 与 BE 核对后沿用公开筛选接口。目录首屏发送总量、品牌、动力、驱动和年款等基本数据，直接打开已筛选链接时同时发送所需的品牌、车型选项。仅车型的旧链接保留切换至其他车型的能力。其余选项在选择品牌或品牌与车型后，经官网 `/catalog-facets.json` 获取对应范围。公开 API 的调用方继续使用原契约。
- 草稿选择与已应用 URL 分离。应用筛选、刷新、返回、分页以及原生 GET 仍以已应用 URL 为准。请求使用当前语言和已应用的关键词及美元价格范围，上级变化取消过时读取。新请求等待时保留之前已返回的选项，快速退回原选择可直接复用；单独的加载及失败状态保留显式重试和公共限流等待。
- 两份隔离 Next 开发实例使用同一合成数据，各额外生成 23,375 个配置筛选项。相同俄语目录 RSC 从 **4,401,755 降至 104,765 B**（解压体积下降 97.6%），同方式 gzip 从 **280,330 降至 11,524 B**（下降 95.9%）。新路由的概览、单品牌、单车型响应分别为 875、461、599 B（解压）。响应确认仍有车辆卡片且不含无关合成配置。体积是隔离对照数据，不代表生产延迟。
- 13 项定向 Chrome 用例通过，覆盖三语、组合筛选、刷新、返回、分页、无脚本 GET、仅车型链接、快速切换取消、语言变化及 429 冷却。首次新用例在已取消请求上继续拦截操作，修正为主动断言取消后复测通过。42 项定向单测及官网类型检查通过。3363 俄语目录和精简概览均为 200，现行本地样本 188 辆、64 个品牌。
- 独立只读审查无 P0／P1。仅车型链接的其他车型选项和可见加载提示两项 P2 已修复并复审。待 PM 集中联调及发布检查。
- 本轮缩减浏览器收到的内容，SSR 与筛选概览仍使用 BE 的无范围聚合。发布联调应核对新官网路径默认走 Nginx SSR 限流桶（8/s，burst 16），后端公开限流仍生效。生产未压测。
