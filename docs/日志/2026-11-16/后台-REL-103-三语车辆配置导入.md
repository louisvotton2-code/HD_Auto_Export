# REL-103 后台三语车辆配置导入

固定后台工作区为 `../websit-worktrees/ad`，分支 `codex/ad-rel-103`，起点 `d3c92b01`。本轮范围为 `apps/admin`、应用说明与本角色记录。

车辆配置使用 BE 共用契约校验中英俄 JSON，支持上传、粘贴、逐项编辑、字段路径报错和变更预览。确认使用同一份文件、车辆版本、多语修订及预览令牌原子保存。版本冲突保留输入，写入结果未知时可先读取当前版本核对。提供配置项目时替换整份项目，省略段落保留。动力类型可由有效枚举随文件保存，也可在车辆配置页直接选择。

标题及车况原文仍在基础资料维护，公开中英俄内容与其他可编辑的展示资料都在车辆配置页。发布检查可定位必填项，发布预览仍要求实际显示、显式确认及幂等发布。后台在线生成及恢复机器译文的操作已移除。

后台类型、隔离构建、43 项定向单元和 46 项模拟浏览器检查通过。浏览器验证包括保留已有译文、上传与粘贴、精确错误路径、编辑后旧预览作废、双击仅保存一次、409、保存结果未知，以及发布确认保护。未修改共享车源或调用翻译服务。

3363 的后台入口和就绪接口只读返回 200，匿名会话返回 401。本地后台已重新生成 Vite 依赖，3363 实际加载的新模块可解析预览、保存和严格 JSON 校验导出。官网和 API 进程保持运行。

真实三端联调通过 1 项。一次性 PostgreSQL 和合成员工、车辆、封面覆盖了基础资料创建、图片上传、JSON 上传与粘贴、导入预览、事务保存及刷新。错误展示字段返回 400，草稿并发修改导致旧预览保存返回 409，读回确认两次均无导入写入。重新读取预览后一次保存成功，车辆版本及多语修订各增加 1，并发写入的内部备注保留。发布前公开接口为 404，随后一次预览确认和一次发布均成功。匿名官网中英俄详情为 200 且车况正确，公开接口的标题和配置值与对应语言一致。本次翻译供应商调用为 0，测试库、媒体和独占服务均已释放。独立审查和发布归 PM 留档。

组合审查发现外部车源的动力类型缺项还会跳转基础资料。修正后，该缺项打开车辆配置，字段在三语资料读取完、解除锁定后获得焦点。隔离构建、类型检查及 4 项受影响的发布缺项浏览器用例通过，覆盖延迟读取、普通字段定位和历史中文定位。
