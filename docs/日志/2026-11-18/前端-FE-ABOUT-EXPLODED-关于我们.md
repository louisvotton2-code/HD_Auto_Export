# FE-ABOUT-EXPLODED 官网关于我们

- 工作区 `../websit-worktrees/fe`，基线 `1951967`。`/{zh,en,ru}/about/` 由 Next.js 在构建时预渲染，公司正文及 3D 备用图无需业务接口。共享头尾导航保留当前语言，页面包含 canonical、语言备选链接及 sitemap 项。此前未提交的首页入口、Skill 和发布记录分别保留。
- 视觉采用全宽成都展厅实拍首屏、铜金配色和逐层分解的汽车展台。滚动在固定展台内控制轻量 Canvas 三维模型，并支持从四个阶段按钮直接定位。窄屏将控制区放在模型下方，减少动态效果和低高度横屏采用直接点选。图像在画布未加载时保留。使用仓内 MotionSites 的首屏构图、3D 渐进增强和浏览器视觉验收方法。
- 公司内容来自 [宏鼎汽车旧站首页](https://www.hongdingauto.com/) 和[旧站关于我们](https://www.hongdingauto.com/about-us)，行业年限沿用用户确认的 23 年。沿用项目联系方式和 FOB／CIF 交付口径。视频为[旧站实拍](https://shopcdnalpha.grainajz.com/1760/upload/video/7ce9fc2119913cf285e8acf3a1e61b4cb80d0737003380e2fb526cc2d0e6496d.mp4)的 35 秒无声版，展示展厅、车场、检测线和登记大厅。素材均本地托管，视频由用户主动播放。
- 生产成品从主线归档叠加本任务文件构建，TypeScript 通过，三语路由均为 SSG。`pnpm --filter @hd/web check:boundaries` 的 7 项单测和模块检查通过。独立只读审查未发现阻断项。预览验证和限制见后续记录。
- 隔离静态成品在桌面 Chrome 与 iPhone 13 模式 WebKit 验证三语直达、窄屏无横向溢出、滚动拆解、四阶段点选、视频播放、减少动态效果与无 JavaScript 备用图。浏览器检查发现固定展台在末段提前移出视窗，改用实际文档占位后复测通过。iPhone 模式还验证了语言切换。实体手机由用户验收。
- 公网验收使用独立的静态输出和只允许关于页、必要资源的 HTTPS 隧道。对 `/admin/`、业务 API 和车源列表抽样返回 404，视频分段响应 206。iPhone 13 模式由公网首次入口进入后，展厅图、四阶段拆解和实拍播放均通过。预览约于北京时间 15:40 到期，正式版本待用户验收。

## 验收后修订

- 按用户反馈移除拆车展台、画布、模型、备用图和三语拆车文案。采用实拍叙事，首屏照片随滚动收成圆角画框并产生景深位移，后续三段展厅选车、现场检测、手续与交运使用照片揭幕。照片从旧官网原始影片截取并保留拍摄标识，三张 WebP 共约 209 KiB。产品展示节奏参考 [Apple AirPods Pro 页面](https://www.apple.com/airpods-pro/) 的大图与分段信息。
- 滚动增强只写入附近区块的样式，离开视口后停止更新。窄屏使用连续上下滚动，减少动态效果或无 JavaScript 时直接展示照片和正文。原实拍短片、三语路由及站内入口沿用。
- 隔离生产构建及 TypeScript 通过，三语仍为 SSG。模块边界检查通过，独立只读审查无阻断项。桌面 Chrome 和 iPhone 13 模式 WebKit 均验证首屏变换、分段揭幕、三张照片解码、视频播放、减少动态效果、无 JavaScript 内容，320px 俄语无横向溢出。
- 新版独立 HTTPS 预览于北京时间约 15:20 开通，有效约一小时。公网 iPhone 模式实际验证揭幕、图片及短片播放，后台、业务 API、车源列表和旧模型图片均返回 404。已关闭旧拆车预览。新版待实体手机和视觉验收。
