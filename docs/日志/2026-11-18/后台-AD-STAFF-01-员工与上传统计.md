## 线上复现和后端交接

已在现有管理员浏览器会话只读查看。报错出现在「全量与持续同步」，参考编号 `0c77b87c-511f-4c1b-a8dd-9e256013655e`。供应商账户和历史入库卡片当时能正常返回，其中账户探测标记为未配置。后台同步卡读取 `GET /api/v1/admin/external/sync-status`；需要服务端按参考编号确认错误原因。状态查询在一次事务里对同步工作表和公开挂牌做汇总，应先以服务端日志确认实际失败点。

下列为首次交接时提交的请求形状。最终统计口径和按需返回上传人字段的约定见 REL-116 记录。

| 接口 | 请求和返回 |
| --- | --- |
| `GET /api/v1/admin/me/upload-stats` | 返回 `{staffId,today,total}`，从服务端会话取得身份，`staffId` 用于防止跨标签页切换账号时错配统计。 |
| `GET /api/v1/admin/vehicles` | 增加 `mine=true`，管理员可另用 `uploader=<staffId>`。先过滤再分页，每行增加 `uploaderLogin`，无可确定的账号返回 `null`。 |
| `GET /api/v1/admin/staff` | 管理员员工列表，`{items: StaffRecord[]}`。资料字段为 `id,login,name,role,disabled,createdAt,updatedAt,uploads:{today,total}`。 |
| `POST /api/v1/admin/staff` | 管理员以 `{login,name,password}` 创建编辑员，返回 `StaffRecord`。 |
| `POST /api/v1/admin/staff/:id/password` | 管理员以 `{password}` 重置编辑员密码并撤销其已有会话，返回 `{id}`。 |
| `DELETE /api/v1/admin/staff/:id` | 管理员撤销编辑员访问并保留历史归属，返回 `{id}`。 |
| `GET /api/v1/admin/external/provider-status` 与 `GET /api/v1/admin/external/sync-status` | 接口校验管理员权限，编辑员直接请求返回 403。挂牌浏览与原有历史读取权限单独保留。 |

上传者和上传时间建议取首条 `vehicle.create` 审计事件，同一车辆只计一次。累计范围和回收站口径由 BE 在联调中明确。员工信息响应不包含登录凭据或会话数据。
