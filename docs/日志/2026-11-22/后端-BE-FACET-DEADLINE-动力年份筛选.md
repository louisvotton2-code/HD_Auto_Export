0045 增加按动力、语言掩码与年份定位的部分覆盖索引。可见性、计数、无报价、车型可用性标记及标签胜出逻辑保持原现行查询。一个等待回源的筛选请求如果读到更新后的快照，且读完仍是当前版本，可按实际读到的版本填充缓存。真正读取中又提交变更时仍只返回当次快照，省略可复用戳。增加概览的版本校验、缓存查询、排队、同键共享、员工与三方聚合、标签回补和返回阶段，失败和慢响应日志不带实际查询参数。回源并发／排队、读取期限、版本和跨部署校验维持既有保护。

## OPS 上线前置

在批准的运维窗口，核对数据库、可恢复备份、磁盘及写入负载。对超过 10,000 行的库，先按下方定义在线预建，单独执行，移交迁移时核对索引定义和 `indisvalid`、`indisready`、`indislive`。0045 拒绝接管同名错误索引，或在大表上自行事务内创建。中断后按既有在线索引恢复流程处理。隔离环境的构建耗时仅反映该样本条件。

```sql
CREATE INDEX CONCURRENTLY external_catalog_filter_power_year_facets_idx ON public.external_catalog_filter
  (powertrain, locale_mask, model_year)
  INCLUDE (make_id, model_id, trim_id, generation_id, drivetrain, label_order)
  WHERE active AND locale_mask<>0 AND powertrain IS NOT NULL;
```

线上复测按同步并行的相同端点、档位及停止线收集 503、429、API 进程及客户端 P95。优先复核生产纯电年份的实际执行计划及缓存版本重用，保留撤回和统计一致性。此候选尚未在生产建索引、部署或复测。
