# BE-FACET-ROLLUP 动力年份精确汇总

基线是 v2.0.4 的筛选小修 `c934b7b24e97fd3be03aa12affe0bde8f5f8290e`，两项增量随同一候选集成。前次生产中文纯电、2020 年起概览实际匹配 44,363 个供应商挂牌，常规查询仍读取全匹配，源站同请求曾触发 3 秒读取期限。

0047 在已有公开筛选投影上按动力、语言遮罩、年份、品牌和驱动维护精确分组。缺品牌或驱动的行仍参与总量。每桶保存完整款型／代系事实计数和最新发布／UUID 的标签获选顺序。标签文本仍从当前公开快照读取，保留人工优先、旧标签回退和公开字段规则。该路径适用于有已知动力和至少一个年份边界的 `overview`，还可加品牌、驱动方式。只展示 USD、但没有价格范围时仍可使用；无报价车辆计入。搜索、价格区间、里程、出口状态和车型款型限制走原精确查询，`overview-models` 与完整投影保留原能力。

组表和车源投影同事务更新。价格和来源时间等不改变分组贡献的更新经过比较后跳过组表写入。只有当前标签获选车辆离开才重选。空桶清除，隐藏、撤回、语言变化和事务回滚与公开版本生效边界一致。保留一个同步 worker、原限流和 3 秒期限。

迁移跟随现有供应商写锁，并用投影表写锁建立一次初始一致快照。普通读可继续。锁等待 3 秒、每条语句 5 秒，失败整体回滚。生产先部署认识新派生表的第一方备份工具，与应用同次发布。第一方备份保持新表定义但排除供应商分组数据，全量备份同快照保留分组和原表。0047 迁移后的清查及线上复测以 OPS 记录为准。

375,000 条合成投影中，原参数命中 43,561 条，旧新返回的 73 行逐项相同。旧路径的筛选原表读取 43,561 行，聚合节点从共享缓存外读入 9,082 个块；新路径原表读取为零，按索引读取 826 个组，组节点从共享缓存外读入 22 块。整条 SQL 所需读块 9,235 降至 175，三次串行对照的中位数 27.13 降至 1.86 毫秒。合成初始化约 0.79 秒，建成 10,620 个组、含索引约 1.84 MB；模拟供应商锁被占用时约 3.04 秒退出并回滚。上述数字不代表生产 P95 或磁盘直接读量。

写入对照以同一隔离库 WAL 位置差计入触发器。50 条语言遮罩更改由 0.73 毫秒／33.8 kB 变为 15.24 毫秒／72.0 kB，同一范围撤回 20 个标签获选者由 0.50 毫秒／7.0 kB 变为 8.57 毫秒／18.4 kB。重选同范围多个标签时只扫描该范围一次，每个桶只写一次。50 条仅改价验证不触碰汇总行；其触发器仍要比较旧新贡献。结果仅供评估写入代价。

隔离 PostgreSQL 定向回归 46 项、缓存测试 27 项通过，备份相关 Python 检查 25 项通过、1 项因需 root 权限跳过。真实隔离 `pg_dump`／`pg_restore` 复核了全量汇总完全一致，以及第一方恢复留下空组与触发器。API 类型检查、构建、OpenAPI、hooks 和差异检查通过。未推送、部署、写生产或执行整站压测。
