# 车辆发动机功率预填与页脚联系方式

- 指定公开车辆接口 `13a19022-b7ff-47f2-91e3-9a51c91a1f7f` 是 PHEV，原始 `facts.powerHp` 为空。详情有已验证的 `engineKw=265` 和单独的 `systemKw=395`。预算以可用的已发布 hp 为先，其次使用同口径的发动机 hp 或发动机 kW。换算按 `1 kW = 1.35962` 公制马力，265 kW 的实际预填为 `360.2993`。保留分档所需精度，资料更新会重新生成预算。用 117.68 kW 核对换算结果高于 160 hp。纯电字段不会自动接收发动机的换算值。[俄罗斯税务机关换算依据](https://www.nalog.gov.ru/rn20/news/activities_fts/16393705/)
- 页脚移除两条电话拨打入口。同一联系栏依次显示 Telegram、WhatsApp 和两个微信号，其他社交链接继续分组显示。
- 隔离成品构建、40 项相关单测和 8 项 Chrome 检查通过，包括对应 265 kW 工况的详情和完整计算器、三语旧预填以及手机页脚。独立只读审查无 P0／P1。现有共享样本库没有该正式车辆，本地实际输入检验使用其已核对的字段构造。线上仅只读核对接口，尚未上传本次改动。
