# FE-IOS-HOME-MOTION iPhone 首页刷新与滚动动效

固定 FE 工作树 `codex/fe-ios-home-motion`，主线基线 `d631571eb26948725ff2db378f4820beef86ab03`。用户在 iPhone 反馈刷新首页时统计从 0 直跳到终值，从站内其他页面返回正常，首页车图滚动光影有异常。

- 在旧计数脚本用受控时序复现了两条直跳路径。首刷时 800 ms 的 CSS 兜底可能先于脚本启动显示终值。前台动画帧迟迟未到时，独立的 1 秒定时器也会写入终值。现在脚本接管时先停掉静态兜底，动画按可见前台实际到达的帧累计，并限制卡顿造成的跨帧跳跃。未加载脚本的静态兜底延长到 2.4 秒，已经显示的终值保持稳定，无脚本和系统减少动效仍展示终值。目录、配件和经营年限的数据口径未改。[计数脚本](../../../apps/web/public/media/home/hero-counts.js)
- 支持原生滚动时间轴的触屏浏览器使用根文档滚动距离驱动车图与光带，区间按屏幕宽度固定。旧浏览器沿用 JavaScript 并在竖向手势先到、滚动位置尚未更新时最多提前 96 px，随后与实际位置对齐。减少动效继续关闭光带。旧版滚动事件迟到能让光带错过可见区间，具体真机症状仍待复验。[光影实现](../../../apps/web/src/modules/home/ui/home-hero.tsx) · [WebKit 滚动动画支持](https://webkit.org/blog/17333/webkit-features-in-safari-26-0/)
- 隔离成品构建和 7 项统计单测通过。WebKit 使用 iPhone 13 视口跑过 8 项，Chromium 跑过 10 项，覆盖慢刷新、0 到中间值再到终值、站内返回、脚本迟到兜底、减少动效、双向滚动、工具栏高度变化和旧版触摸预判。初次 WebKit 运行在故意拦截样式之后用同一上下文检查减少动效，改用干净资源上下文复跑通过。计数和光影均经过独立只读复核。
- 本机 3363 中文首页 HTTP 200，已核实该入口返回更新后的计数脚本。本轮 WebKit 是桌面引擎及 iPhone 视口，苹果真机的触摸惯性和浏览器工具栏行为待复验。
