## 官网实现

- 固定 FE 分支 `codex/fe-public-asset-cache`，基线 `a935ea9`。字体、国旗、Logo 和图标由 Turbopack 以真实内容生成 `/_next/static/media/` 文件名。保留旧公开文件供旧文档使用。页眉、页脚、计算器水印和可用的 SEO 图片引用共用 Logo 指纹地址。新图标由布局显式引用，无需从旧 `/icon.svg` 路由协商版本。
- 首页字体预载在服务端输出，和 `@font-face` 使用同一地址。站点仍使用 `swap`，首页仍使用 `optional`，沿用拉丁与西里尔范围。指纹资源使用现有静态资源保留机制。Next 的部署标识、HTML、RSC、公开 API 及员工预览缓存策略均沿用现状。
- 自有图片继续使用 API 的 `image.url` 和 `cover.url`。BE 以 `{uuid}_{43位base64url}` 标识绑定原图及两种衍生图的版本，列表 srcset、主图、缩略图和全屏均沿用完整标识。宽度由 `variant=thumb` 或 `variant=card` 区分。前端接受旧 API 返回的裸 UUID 地址，继续在衍生图失败时尝试同一版本原图。第三方仍使用原链接，员工预览仍使用权限路径。已版本化地址失败时保留该版本的失败状态，避免把旧页面的版本请求变成当前版本取图。

## 本地验收

- Standalone 成品构建、18 项定向单测、7 项边界测试和独立只读审查通过。14 项 Chrome 验证覆盖预载、Logo 和图标、320／414／1440 px 站内语言切换、慢字体时首页计数、无 JavaScript 目的国国旗、旧图回退和版本车图。早期发现客户端资源导入与预载会多出 `dpl` 请求，修正后严格按完整 URL 复测通过。
- 同一匿名 Chrome 上下文首访俄语首页读取 13 个指纹资源，下一次普通刷新 13 个资源总传输 0 字节，站内换页返回记录到的 7 个资源也为 0 字节。两次均无 304。独立构建更换部署标识后 13 个文件路径和摘要一致，只改隔离版俄国旗字节会生成新地址，旧新文件在现有保留工具下均可读。
- 隔离模拟 API 验证自有车图目录、详情、缩略和全屏沿用同一个版本段，换内容后各地址更新，旧地址按模拟接口规则返回 404。真实 BE／网关缓存、生产普通刷新和撤车后服务器行为仍待同版复核。私有收据、审查和补丁在 FE 工作区 `docs/private/fe-public-asset-cache/`。

## 生产浏览器收据

使用同一个匿名 Chrome 上下文，启用 HTTP 缓存并关闭 DevTools 的 Disable cache。在一个正常的公开首页和真实已公开自录车样本上记录首访、普通刷新、离开后经实际站内链接返回。不使用硬刷新、自动请求拦截、响应改写或并发测量。用文档导航类型、`pageshow.persisted` 和站内路由区分刷新、完整复访、浏览器前后页缓存与站内切换。

各阶段记录实际发行版本、资源完整 URL、资源类型、缓存命中来源、实际 HTTP 状态、传输字节、`Cache-Control` 和 `ETag`。CDP 需同时保存 `Network.requestServedFromCache`、`response.fromDiskCache` 及 `responseReceivedExtraInfo` 的状态，包含图标常见的 `Other` 类型。单独统计 `304` 往返、强缓存零传输和有实体的 `200`。自录图片观察默认卡片、缩略图和手动打开全屏后的版本及尺寸；RSC、HTML、第三方和无版本图片作为策略对照。

内容变化比较两份隔离构建或已经授权的真实图片更新前后收据。相同字节跨发行版本保持相同静态 URL，内容变化产生新 URL。旧静态文件和新文件须同时可读且内容各自正确。已公开车图版本变化时新文件路径和摘要须一致，旧版本网络请求继续通过 BE 的公开引用校验。已有浏览器按收到的强缓存期限复用内容，生产记录应独立注明这一行为。不通过修改现有正式车辆来造验证样本。
