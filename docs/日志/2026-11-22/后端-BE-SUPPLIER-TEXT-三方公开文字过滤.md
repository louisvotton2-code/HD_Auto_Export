# BE-SUPPLIER-TEXT 三方公开文字过滤

运营前用合成挂牌复现旧版会在供应商自由描述和原文中带出明确标记的采购成本及卖家联系方式。已核对结构化内部成本、供应商联系字段和原始检测报告链接只走对应私有路径。合法的供应商铭牌 VIN 仍按现行契约提供，员工草稿中的内部 VIN 仍按原规则隔离。

加强新增/更新的来源投影，并在公开读取边界保护旧存储。范围覆盖公开和 SSR 详情、卡片、首页、筛选标签、图片说明、配置和检测摘要、内嵌及分页条目。被拒绝的必填标题使用既有本地化兜底，留空字段沿用现行 `null`、空说明或 `missing`。同条配置或检测的私有标签及其值一起遮盖，分页、身份、栏目计数与公开价格照旧。过期缓存由新的正式发布身份隔离。

历史索引可能仍包含旧标题或车型标签的搜索词。正文和标签的读取保护不更新历史索引，候选发布后应使用现有受控重投影流程审计和修复命中记录，避免在公网搜索请求中额外扫描库存。合成案例用于复现过滤缺口，未抽取正式车源的敏感值。

隔离数据库中，卡片、报告与同步相关的 24 项针对性检查通过。针对旧投影的替身回归覆盖仅由标签标注的裸值、内嵌报告、游标分页及合法结构化参数。共同候选通过 308 项 API 单测、38 项隔离数据库测试以及类型、构建、OpenAPI、工作区边界与 hooks 检查。
