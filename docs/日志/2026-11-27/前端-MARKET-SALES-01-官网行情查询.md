# MARKET-SALES-01 官网行情查询

基线 `8ad1de861d922ef2f5c53146932cb1158352c459`。固定前端树保留已有编辑。本轮候选在独立工作树 `/private/tmp/hd-market-sales-fe-8ad1de8` 的 `codex/fe-market-sales-01`。沿用现有黑金样式、三语和手机布局，仅用于本地验收。

## 官网范围

- 三语 `/market-prices/`，顶部原联系位置换成行情。页脚公开联系渠道、手动打开联系弹窗及车辆咨询入口继续可用。
- 品牌及车型必选，读取已有本站车辆筛选的品牌、车型和款型 ID。年款、款型、公里数和动力可选。明确提交才发起查询，结果对应地址栏参数。已提交条件可复制、切换语言、打开极值车或后退时复用。无效条件不发送行情请求。
- 读取唯一公开行情接口并以 BE 的 `MarketPriceQuerySchema`、`MarketPriceResponseSchema` 校验，展示合并样本量、采样时间、中位价、均价、最低与最高。样本至少 10 条才显示 P25–P75。美元报价缺失时保留实际人民币金额。极值车卡带年款、里程和款型，走公开详情链接。封面沿用目录的公开图片组件，允许本站媒体及来源规则允许且未过期的 CDN 地址。行情页只展示现存图片，失败时占位，且不触发供应商刷新。
- SEO 页面标题、描述、canonical 与三语 hreflang 独立于查询，分享过滤参数不进入 canonical。现有有限开放模式保留，行情进入全站开放模式的 sitemap。行情查询不触发供应商数据查询。本地自动验收拦截外部图片和联系，不访问生产。

## 接入与复建

同版本地 API 监听 3320，官网监听 3317，统一网关 3363。真实验收打开 `/zh/market-prices/`，其他语言为 `/en/market-prices/` 与 `/ru/market-prices/`。FE 候选依赖 BE 所有的共享契约与接口。联调基线先纳入同一 BE 候选或共享契约补丁，再以仓库锁文件安装依赖、构建 `@hd/contracts` 与 `@hd/web`。没有单独维护一份共享 schema。

## 当前验证与限制

- 使用 Node 24.19.0、锁定依赖和 BE 的生成共享契约完成模块边界、类型检查、生产模式构建，以及 6 项查询／金额单测。Chromium 在隔离 API 桩下验证明确提交、条件分享与恢复、503 重试、三语与窄屏、0／1／3／13 条样本、人民币精度和图片详情路径。回归覆盖既有导航、页脚联系以及计算器入口。测试使用的极值照片是站内合成媒体；未向真实联系人和供应商请求。
- 统一网关 3363 首测 API 为 502，已用真实故障回执核对 360px 重试入口。BE 接线后，实际理想 ONE `li-auto / cca-model-3059` 三语均 4 辆。人民币最低 87,900、中位 94,300、均价 99,125、最高 120,000，美元中位 14,127.42。已打开两个真实极值详情并逐车比对原币报价，浏览器返回保留查询。样本使用本地离线还原库。
- BE 来源配置仍是照片授权依据，范围未从 BE 应用跨端导入。行情渲染以共享 HTTPS schema 校验语法，并镜像当前生产所准许的具体 CDN 域名及签名参数格式，拒绝过期和不受信地址。复用目录图片的站内缩略图、错误回退和无 Referer 行为。自动验收中可信的 CDN URL 也使用隔离响应，不以此声称远端 CDN 当次实通。
