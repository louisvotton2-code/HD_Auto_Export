# 当前技术架构（P1.12：纯静态计算器、购车指南与IP发布）

更新日期：2026-10-25（Asia/Shanghai）。本文描述实际实现，不代表长期规划已全部完成。

P1.12已将购车指南正常合入main，并按实际IP／noindex重建及发布到现有Nginx。此阶段不改变运行架构或税费内核，网站仍只托管静态成品；服务器当前版本、保护检查和回滚见[实际部署记录](./VPS-IP部署记录.md)。

## 层次与调用方向

```text
Next.js 页面 / calculator-page.tsx
  → modules/calculator/index.ts
    → core/calculate.ts
      → policies/{ru,kz,uz,ge,am,kg,al}/reference.ts

源码内可选 server/handler.ts（未注册HTTP路由）
  → 同一公共出口及同一纯函数
```

核心不依赖 React、Next.js、语言、网络和系统时钟。应用层准备默认车辆、日期及构建快照/手动参考汇率，再显式传入核心；UI 只消费费用，不复制公式。金额使用 Decimal.js。展示使用稳定费用 ID 和翻译 key。

`pnpm check:boundaries` 检查公共入口实际运行时依赖闭包（当前 12 个源文件），禁止框架、UI、翻译、网络、时钟、浏览器状态、随机源及无法解析的动态导入；外部依赖仅允许 Decimal。未来车辆／配件等业务模块必须经 `modules/calculator/index.ts`，连类型也不直接导入内部文件。App／i18n 属于装配入口，可连接模块 UI 和消息；不需要为当前规模拆微服务或另立 SDK 仓库。国家配置复用核心 `CountryCode`，不重复维护国家类型。

`core/types.ts` 是当前参考预览契约，比长期规划的正式报价契约精简。P1.4 兼容扩展了 UZ `condition` 与 `usdRate`、结果 `additionalCosts` 与 `assumptions`；P1.5 为费用行增加可选 `method`，不改变原有金额和原始公式。七国金额分支均已接通，仍只有 2026 参考快照。尚未有正式法规/法定计税汇率快照、完整车辆事实、进口用途/资格、成本账目、落地成本组合与报价历史；不能把参考算式回归通过写为官方税法已核验。

## 输入与草稿

- UI 空字符串是未知值，不转换为 0。当前输入只接受数字与小数点，不接受逗号或千分位分隔符；非法格式会显示说明并清除结果，避免 `25,000` 被误算成 `25`。显示金额按中英俄本地格式输出。
- 默认预填 180000 CNY、1998cc、150hp、2021-01、个人汽油、浏览器初始化的当前清关日期和构建汇率快照；运保费未知仍为空，不虚构中国运输报价。`application/defaults.ts` 集中维护默认事实与币种转换。
- 草稿只存浏览器 `sessionStorage`，不上传服务器；浏览器拒绝存储时仍能使用。新版 key 为 `hd-auto.calculator.draft.v2`，可迁移旧 AUREX 草稿的非空内容。
- 语言切换保留草稿与手工汇率。国家切换保留车辆事实并改为新目的国快照汇率；切换交易币种使用同一市场快照换算车价与汇率。非法/未完成金额保留并报错，不静默丢弃。
- 更多设置默认展开，允许手动收起；首次打开、切国家/语言与“恢复默认”时均展开。“恢复默认”重置参考车辆及构建快照汇率；不再要求先点击“载入示例”。
- 主表三类动力对应燃油/混动/纯电，细分汽油/柴油/HEV/PHEV/EREV/BEV 在更多设置中保留。清关日、汇率、舵位与运保字段也在更多设置中。RU 纯电仍显示并要求功率以选回收费档，隐藏排量；KG 串联增程同样不需要排量；AL 不显示或验证制造日期。
- UZ 主界面提供新／二手状态，新车明确为从未登记，默认二手。按参考站仅 KG 提供个人／企业选项；RU/AM/AL 标明个人参考范围，KZ/UZ/GE 不虚构身份摘要。
- `CountryRecord.hasImporterChoice` 只控制参考工具的身份交互，不声明法律覆盖。`application/page-input.ts` 清理无选择器国家的旧 company 值和跨国身份，避免不可见字段造成待确认状态；KG 同国语言切换保留选择。v0.1 内部 `individual` 是页面参考适配值，不能解释为统一适用于个人／企业。
- `application/draft.ts` 的 `restoreCalculatorDraft()` 仅接收原始 JSON、当前国家／日期／汇率；读取和写入 sessionStorage 留在 UI。纯恢复函数覆盖损坏／数组形状／非字符串／超长草稿、旧币种迁移和手工汇率。只有 KG 同国才恢复身份；`normalizePageInput()` 再次防止隐藏旧身份。API 和独立内核不走此页面适配；KG company 接企业策略，其他国家显式 company 仍返回待核验。
- 切换交易币种同时换算车价、运费和保险，不能仅改金额标签。UZ 单独保留目的币/USD；手工汇率同国/语言草稿保留，切国家或恢复默认重新导出该构建快照的汇率。
- 核心只校验当前适用字段，隐藏字段不会影响结果。空串代表运保未知，空白会先规范化；非字符串、负数、千分位等非法输入不会进入政策函数。
- P1.6 修复直接函数调用的非字符串日期 `.trim()` 崩溃：适用日期改为结构化 invalid 诊断；AL 不使用的制造日期仍不参与校验。不把 TypeScript 类型当成外部车辆数据的实际类型保证。

## 可选后端适配器（静态站不提供HTTP API）

旧POST路由已搬至 `modules/calculator/server/handler.ts` 的 `handleCalculationRequest(request)`，仅保留源码与单元测试，供未来独立后端复用。`out/` 不包含此端点，静态主机的该地址返回404／405；不能调用过去的 `/api/v1/calculations`。适配器的JSON对象包含初版 `CalculationInput` 的全部必需字段；即使未使用，文本字段也传空字符串。新增 `condition`、`usdRate` 可选以兼容已有调用。参见 `tests/calculator.spec.ts` 的七国固定输入。

```json
{
  "country": "RU",
  "importerType": "individual",
  "powertrain": "petrol",
  "price": "25000",
  "currency": "USD",
  "displacementCc": "1998",
  "powerHp": "150",
  "manufactureDate": "2021-01",
  "customsDate": "2026-10-22",
  "freight": "",
  "insurance": "",
  "steering": "left",
  "transactionRate": "81.969182",
  "euroRate": "94.7"
}
```

固定样例返回 `status: reference`、`total: "926952"`、`currency: RUB`、`quality: reference_only` 及明细/排除项。样例汇率不表示当前汇率。

状态：`reference` 可展示参考数字；`incomplete` 缺必要字段；`invalid` 数据不合法；`needs_review` 当前场景未实现或不在 2026 参考范围。非 reference 结果均没有总额。HTTP 200 表示返回参考或能力状态，422 表示缺字段，400 表示非法请求/字段；大请求返回 413。接口显式 `Cache-Control: no-store` 与 `X-Calculation-Mode: reference-only`。

该可选适配器接受用户输入的手工汇率，仅适合参考工具。P1.6 的 `request-body.ts` 先检查声明长度，再在流式读取过程中累计真实 UTF-8 字节，最多 10,000 字节；不信任 Content-Length，不等整包读取后才限制。提前取消超限流，拒绝无效 UTF-8；包括错误在内均返回 no-store 和 reference-only 标识。当前静态部署模板不注册或代理此端点；未来独立服务需自行添加入口、限流及运行策略。正式规则仍需可信快照和资格模型，不能将当前端点当正式报价或开放批量服务。

### 输入单位与兼容字段

- `price`、`freight`、`insurance` 统一使用 `currency`（CNY/USD），与参考站 UZ 固定美元运费输入不同。
- `transactionRate`：每一单位交易币兑多少目的国币；`euroRate`：每 EUR 兑多少目的国币。KG 通过本币/交易币除本币/EUR 得到 EUR 估值，先保留两位 EUR，再逐项换本币。
- UZ `usdRate`：每 USD 兑多少 UZS，CNY 输入时必需；交易币 USD 时始终使用 `transactionRate`，避免两个同方向汇率相互冲突。`condition` 缺省视为 `used`，`new` 必须表示从未登记，非低里程代理判断。
- RU、KZ、KG、AM 有可编辑 EUR 汇率；UZ CNY 有额外 USD 汇率；GE 汇率仅作展示。

### 输出及费用范围

- `lines` 只含本次合计的费用；`total` 是这些行的和，KGS 保留两位，其余币保留整数，舍入先按各国参考步骤执行。
- `additionalCosts`：KG 个人首登 `registrationEstimate` 为 `one_time_estimate`，AL 年度豪车税 `annualLuxury` 为 `annual`。均单列本币与 USD，不再次加入 `total`。
- `assumptions`：运保未知未入税基、AM 电动车优惠假设、KG 电动车标准关税情景、RU 个人低系数/增程归类假设。UI 与复制摘要均显示，避免把未知输入当确定零费用或保证免税。
- KZ 的 400000 KZT 配套服务估算在其参考站合计内，标为市场估算而非法定收费。其他国家运保仅进入适用税基，运保本金不进入税费合计。
- 当前全部国家仅接受 2026 清关年；AM 原站把纯电零税延至未来年份的缺陷未照搬。AM 2026 配额/资格仍是显式情景假设，不是已认证豁免。

### 策略接口

`ReferencePolicyFacts` 显式包含输入、月龄及年份差。六个策略返回 `ReferencePolicyResult`（费用行与额外费用），GE 暂沿用独立行数组，由分发器包装。RU 回收费矩阵单独存费率事实文件；所有策略仅依赖十进制算术及显式事实，无网络、时钟或页面状态。

算例见 `core/seven-country.test.ts`、各国 `policies/*/reference.test.ts` 与 `tests/calculator.spec.ts`。冻结的独立参考实现输出只用于回归，不构成官方认证。

## 具体计算说明与代入公式（P1.5）

- `CalculationLine.method?: { key: string; params: Record<string, string | number> }` 是兼容追加字段。七国策略在实际命中分支时返回说明 key 和真实操作数，主费用及 `additionalCosts` 均覆盖；核心不返回译文，也不因展示再次计算税额。
- 各国 `policies/*/method-messages.ts` 是对应中英俄说明的唯一来源；`application/fee-display-messages.ts` 提供公式标签和折叠操作，`stamp-messages.ts` 提供印章文案，`copy-messages.ts` 提供复制参数文案。`application/calculator-messages.ts` 汇总新增命名空间，由 `i18n/request.ts` 与基础 JSON 合并。P1.9 增加 `showDetails`、`hideDetails`、`expandAll`、`collapseAll` 4 个 key 后，运行时各语言 420 个字符串 key，其中基础 JSON 各 248 个、新增 172 个；P1.11另由独立购车指南合并70个BuyingGuide key，全站合计490个，基础JSON仍248个。不要在 JSON 中重复维护新文案。
- `ui/fee-method.tsx` 展示实际年龄／税率档、税基、最低额取高比较、免税或零值原因、额外估算等说明，再展示代入公式。复制结果复用同一说明及公式格式化器。
- `application/fee-presentation.ts` 只格式化数学文本，不执行公式：本地化数字、替换 `max`／查表标签、隐藏 `round`／`round2` 等内部函数并追加本项结果。长金额或汇率在显示时缩短会带 `≈`，页尾说明这是显示精度；核心原始 `formula`、操作数、Decimal 舍入与税额不变。
- 新消息契约测试检查合并后的三语 key／占位符一致，并检查场景矩阵产生的超过 1,000 条主费用／额外费用都提供可翻译方法和参数。新增浏览器验收覆盖七国逐项说明、最低额比较、复制、参数切换与 360px 俄文布局。

`application/copy-quote.ts` 选择可复现的有效参数，不计算税款：车价／币种、动力／排量／功率、适用日期、UZ 登记状态、GE 舵位、已知／未知运保、实际汇率、USD 展示交叉汇率／来源日期及规则版本。UI 只翻译并与费用说明、公式和合计拼接。AL 制造日期、GE 隐藏车价等不会混入摘要。

## 费用详情折叠（P1.9）

- `ui/fee-line.tsx` 统一渲染主费用和 `additionalCosts`，接收费用、已格式化双币金额、详情 ID、展开状态及切换回调。费用标题、本币与 USD 金额在按钮中始终可见，只有具体说明和代入公式位于可隐藏面板；不在组件内复制税率或重算金额。
- `calculator-page.tsx` 用默认空的 `Set<string>` 管理已展开费用，ID 由目的国、主费用／额外费用及稳定费用 ID 组成。顶部按钮对当前全部主费用和额外费用统一展开／收起；单项按钮独立操作，部分展开时顶部提供全部展开。
- 费用详情使用原生按钮、`aria-expanded` 和 `aria-controls`；面板通过 `hidden` 及明确的 CSS `display:none` 隐藏，按钮有键盘焦点样式。折叠不改变金额、政策说明、动态印章或品牌水印。
- 改参数时已展开的同一费用继续显示最新说明和公式；恢复默认或切换国家清空展开状态，不将其存入草稿。更多设置仍按此前要求默认展开，与费用详情状态分离。
- 复制摘要直接读取结果费用行及同一说明／公式格式化器，不读取页面可见文本或展开状态。因此全部收起时仍复制全部费用说明和公式。
- P1.9 本机类型、5 项边界防护、626 项单元测试、export 构建及最终 101 项完整浏览器测试通过。首次仅一项 `innerText`／`textContent` 断言差异，修正后重新执行完整测试通过；实际公网发布与验收见 [开发进度](./开发进度.md) 和 [VPS-IP部署记录](./VPS-IP部署记录.md)。

## 动态印章与品牌水印（P1.5）

- `application/result-stamp.ts` 只根据显式输入及已有结果选印章文案，不计算税款或准入资格；豪车等标记读取实际收费行，避免 UI 另设门槛。`ui/result-stamp.tsx` 与 CSS 负责右上角圆环视觉、三语及可访问说明。
- 印章随国家税制、车辆年龄段、动力、KG 身份、环保税或豪车等条件改变。`incomplete`／`invalid`／`needs_review` 改为灰色待完善提示，清除旧年龄及年份；优惠假设明确标明，不表示官方批准或海关认证。
- `calculator-page.tsx` 的结果顶部使用 `siteConfig.brand.logo` 原始图片作装饰水印。CSS 绝对定位、低透明度、边缘淡出及禁止指针交互，不占布局宽度；`alt=""`、`aria-hidden` 避免重复朗读。手机缩至 140px；不修改用户提供的原始 Logo。
- 费用和政策说明仍是独立内容，不能只凭印章判断实际费用或优惠资格。税率版本与官方核验覆盖状态不因新增视觉标识而改变。

## 国家政策说明

- `application/reference-notes.ts` 根据国家、动力、有效日期的车龄、舵位及 KG 身份选择稳定语义 key，不计算应付税额。`ui/country-policy-notes.tsx` 负责三语翻译、列表与本国来源链接。
- 说明在结果合计或待完善状态下方始终展示。材料整理日期为 2026-10-23，不把参考站自报核验日期写为 HD 的官方核验日期。
- GE 的混动减免、右舵倍率、高龄与纯电提示互斥处理；非法或未来日期不触发年龄条款。KZ 区分关税月龄与首登年差；不用参考站“2年即最高档”的冲突措辞。
- UZ 现按用户选择的登记状态及月龄显示新车/二手提示；AL 最低估值、豪车税与 AM 环保税已经由策略实际计算，展示层不复制公式。
- 额度耗尽、免税期限等只作有条件参考提示，不保证清关日资格。完整观察、差异及来源见[政策复查记录](./参考站交互与政策说明.md)。官方核验完成项仍为 0。

## 构建时市场参考汇率快照

- `infrastructure/exchange-rates.ts`：快照类型、默认参考快照、跨币对换算及署名常量；纯函数，客户端可用。
- infrastructure/exchange-rates.server.ts仅在构建页面时读取open.er-api.com，3秒超时并校验币种／单位／时间戳；force-cache复用本轮构建请求。pnpm build预先清理.next/cache/fetch-cache，确保重建时重新获取，不使用ISR或后台计时器。
- fetchExchangeRates()的结果作为页面构建快照传给计算器供最终用途转换，**不提供公开汇率代理/下载端点**。依据：[服务条款](https://www.exchangerate-api.com/terms)、[免费服务与署名要求](https://www.exchangerate-api.com/docs/free)。使用页面保留提供方署名链接。
- 快照包含 `status`、`source`、`asOf` 与每 USD 兑换的各币数量。状态live兼容表示构建阶段成功读取市场数据，不表示访问时刷新、逐笔实时行情或法定海关汇率；三语页面和复制结果明确说明构建快照。
- 失败或错误响应返回 `status: reference`；UI明确显示“默认演示汇率”和资料日期。回退数据是演示假设，CNY/USD=6.9，其他币来源于最初参考站样例，并非该日完整市场定盘。
- 手动修改两项汇率后标为手动，语言切换保留；恢复默认或切交易币种后重新使用当前构建快照。更新快照必须重新构建并发布，不新增独立的公开汇率JSON或代理。

## 本币与 USD 展示

- `application/display-currency.ts` 负责 USD 参考展示，独立于税费内核与 API。费用明细、总额、手机底栏和复制摘要均保留原本币金额，并附 USD 金额及参考换算说明。
- 依赖车价的国家，使用实际输入的“本币/交易币”汇率乘快照的“交易币/USD”得到本币/USD，因此手工汇率覆盖会同步影响 USD 展示。交易币为 USD 时，直接使用输入汇率。
- GE 不使用隐藏的交易汇率字段，USD 展示使用快照 GEL/USD。各国结果页均保留汇率来源与日期署名。
- UZ CNY 输入时使用实际填写的 UZS/USD 展示，与税基换算一致；UZ USD 输入使用交易汇率。额外费用同样双币种展示，不能与已入合计的费用混加。
- USD 用 Decimal.js 换算到两位小数，非法或缺失汇率返回 `null`，显示未知而非 0。总额由本币合计独立换算，因此可能与逐项四舍五入后的 USD 相加相差 0.01；不反向修改本币结果。

## 静态构建、日期与部署

- next.config.ts使用output:export、trailingSlash:true、images.unoptimized:true。pnpm build生成整个out；scripts/prepare-static-build.mjs先清理旧out、旧fetch-cache及遗留standalone，防止过期输出／快照混用。源码、node_modules、.next和.env均不上传。
- 初始HTML的默认日期属于构建快照；浏览器挂载时用getClearanceDate(new Date())按Asia/Shanghai取得访问日并恢复草稿。显式保存的草稿日期保留，恢复默认再次取当日；核心仍只接受显式传入日期，未引入系统时钟。未来2027访问会明确超出2026参考范围。
- pnpm preview仅是本机验证out的静态文件服务，不是Next应用。Playwright直接测该目录，默认3100，E2E_BASE_URL仍可指向其他静态主机。服务提供目录索引、正确MIME与真实404，不做SPA兜底；测试不再依赖不存在的HTTP API。
- 原POST处理和流式大小防护移到server/，保留Vitest覆盖，不打入静态网站；进程健康接口取消。检查文件可达／静态页面状态替代Node进程健康检查。
- 全球静态404是独立HTML。global-not-found需要当前版本的experimental.globalNotFound，已锁定依赖并验证静态构建；未来Next升级须复查，不要未经验证删开关。
- 生产服务器只需Nginx等静态托管。Mac构建的out可直接上传Ubuntu22，不存在原生Node依赖跨平台问题。Node24／pnpm仅用于开发电脑构建与本地验收。
- 与用户已有s-ui／VPN共存必须先检查TCP／UDP监听；不能假定80／443空闲。同IP多域名不自动解决TCP443占用。端口冲突时先用已确认空闲高端口试跑或采用备用IP／服务器；不停止VPN、不覆盖其配置、不重置UFW。完整命令见[服务器部署](./服务器部署.md)。
- NEXT_PUBLIC_SITE_URL与SITE_INDEXABLE仅在本地构建配置；域名origin验证继续有效。修改域名／索引／快照需重建发布；默认noindex，不等于密码保护。
- P1.8 已实际部署到用户 Ubuntu22 VPS：IP HTTP 在空闲 TCP80 提供静态内容，原 s-ui 的 TCP443 和进程启动状态保持不变，防火墙规则未修改；没有域名或 HTTPS。P1.9 公网检查已复现复制失败的安全上下文原因，按用户选择保持标准 Clipboard API。后续网站更新继续使用独立静态 release、保留旧哈希资源和旧版本后原子切换，不更改 Nginx／VPN 配置或防火墙；具体发布目录、备份与公网验收以 [VPS-IP部署记录](./VPS-IP部署记录.md) 为准。
