# Claude Code 与其他 Agent 接手

所有工具共用同一套项目规则，不单独维护另一份版本或任务清单。

1. 读仓库 AGENTS.md、[接手导航](../README.md)、[当前进度](../开发进度.md)。
2. 确认实际分支、工作树及本轮任务，保留未提交修改；只读自己的角色和相关契约。
3. 加载项目开发Skill；不支持Skill时直接读对应SKILL.md。
4. 按当前流程本地开发、必要联调、用户验收，再提交检查及授权发布。具体规则见[测试与审查](测试与审查.md)。

历史私有任务交接不随clone传递；若当前任务指定了私有交接入口，先读取它，不从旧日志推断生产状态。
