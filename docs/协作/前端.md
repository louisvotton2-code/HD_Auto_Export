## 职责和入口

FE 自行运行 `pnpm dev:web` 查看热更新，普通修改不等待 OPS 打包；阶段交付才构建受影响成品。允许独立端口并在交付时报实际地址；开发连接及 `.next/` 隔离见 [本地开发分工](../README.md#本地开发与部署分工)。

维护现有官网 `apps/web/src/modules/home/`、`apps/web/src/modules/vehicles/`、`apps/web/src/app/[locale]/` 官网路由及公共展示；保留已认可的首页结构、黑金样式、动效、三语和手机适配。不要在组件里请求第三方、读取数据库或复制税率。

现有 `Vehicle` 只有演示用 `priceUsd`、`source:demo` 等字段，不能直接当真实 DTO；新增显式展示映射，区分待询价／参考价／售价、缺失日期、来源和库存状态。联系草稿扩展由本工作流负责，后端先提供稳定 ID 和公开价格语义。

## FE-00：官网工程迁移（G0 工程部分）

本轮将官网源码、public、测试、脚本与 Next／TS／Vitest／Playwright 配置迁入 `apps/web/`（`@hd/web`），根命令转发官网并增加 workspace 边界检查。保留静态导出及现有功能；本任务不建立后台、API、鉴权或数据库，不提取计算核心。实际检查结果由本轮集成人写入日志后更新状态。

后续 FE 自行维护官网依赖、配置与运行时；根脚本、锁文件、workspace 和 CI 改动交给当轮工程集成人。写 Next 代码前阅读实际安装位置的 Next 本地指南。

## FE-01：官网运行时与单车纵向联调（G1）

依赖：G0 公共契约、后端运行环境和 BE-02 公开接口；可先用同契约 fixtures 开发，注明尚未联调；自测后先交独立审查。

1. 在 `apps/web/` 独立完成从静态 export 到 Node 运行时／standalone 的迁移，复核构建／启动／测试、动态详情、metadata、sitemap、404、图片和汇率快照行为，保留静态回退说明。同回合更新实际架构、README 与 Skill 对当前运行方式的描述，CI／根命令由集成人协调；使用新生产成品验收。SSR 经 HTTP 请求 `apps/api` 的公开接口，浏览器经约定代理路径请求 API；都消费 `@hd/contracts`，不得 import API 源码、数据库或服务端业务实现。
2. 首页通过 API 查询层得到真实车源；替换车轨数据来源，保留布局和交互。首页两个区块使用后台配置标题和排序，不能标题写 Kia 而内容是其他品牌。
3. 无真实车或区块为空时给出合理空态／隐藏空区块，不能拿演示车填满当作现货；现有热门“车型家族”与具体车源区别展示，不制造无结果入口。
4. 新车发布后无需重建即可访问 `/{locale}/cars/{stableId}/`。迁移 `dynamicParams=false` 与 `generateStaticParams` 的假设，按安装的 Next 文档实现；未知／下架返回真实 404。
5. 详情以 SSR 输出核心事实、图片和基本联系方式；浏览器增强不成为阅读与联系的唯一途径。
6. 扩展 `apps/web/src/shared/lib/vehicle-contact.ts` 的结构化输入，真实车使用正式车号、正确车型、公开价格语义和详情 URL；演示入口保留演示文案。未知字段省略或说明，不能用旧 demo 默认值。
7. 更新发布、已售和下架后的首页／详情可见性，保证用户不会从缓存继续看到可购买的旧状态。

验收：同一辆真实测试车在三语首页、详情、WhatsApp／Telegram 草稿中 ID／链接一致；客户未发送前不能提示“询盘成功”。草稿编码、目标账号、键盘与手机交互通过。不要向真实客户发消息。

## FE-02：精选目录和真实内容替换（G2）

- 精选目录支持真实接口分页和该阶段约定的筛选；筛选变更回第一页，URL 可恢复筛选，加载／空结果／失败／重试分别显示。
- 不对一页数据做排序后声称全目录排序；G2 默认发布时间排序，跨币价格排序另按契约实现。
- 保留已售详情的准确状态与“咨询类似车辆”入口；下架／草稿不可访问。无价格显示待询价，绝不显示 0 USD。
- 三语文案 key 对齐；内容翻译未就绪按发布门槛处理，不悄悄展示空标题。语言、币种、目的国互相独立。
- 当前 demo 详情不直接重定向到无关实车；生产停用演示入口，过时 demo URL 返回 404 或另行明确的说明页，保持 noindex。
- 动态 sitemap 只包含符合发布和索引条件的真实精选详情；草稿、后台、预览和错误页不入索引。第三方重复目录首期默认 noindex，后续内容策略另评估。
- 保留现有计算器参考语义与七国回归；从车辆跳测算时只传真实已知事实，缺关键字段让用户补充。

验收：10–20 辆真实车的数据和图片人工核对；桌面及 320/390px 俄文布局、无 JS 基本内容、三语路由、元信息和联系方式检查。官网运行时成品与测试由 FE 准备，BE 提供 API 环境，QA 联合验证；不能用旧 `apps/web/out/` 验收。
