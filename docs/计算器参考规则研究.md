## 3. 每国合计并不是同一种“落地价”

所有国家的参考 `total` 都不包含购车款。某些费用进入计税基础，并不意味着该费用本身已经进入 `total`。

| 国家 | `total` 实际包含                                                               | 另列、不计合计      | 运费与其他排除项                                                      |
| ---- | ------------------------------------------------------------------------------ | ------------------- | --------------------------------------------------------------------- |
| RU   | 关税、报关手续费、回收费                                                       | 无                  | 无运费输入；韩国运输、保税仓、代理、注册不计                          |
| KZ   | 手续费、关税、排量消费税、豪车消费税、VAT、首登、牌证、回收费、40万KZT杂费估算 | 无                  | 无运费输入；运输不计；40万是市场估算，不是法定税费                    |
| UZ   | 手续费、关税、VAT、回收费、注册                                                | 无                  | 边境运费参与计税，但运费本金不计入total；仓储和代理不计               |
| KG   | 关税或个人综合税、消费税0、VAT、0.4%手续费                                     | 个人首登5%估算      | 运保费参与计税，运费本金、仓储、代理及注册不计total                   |
| AM   | 关税、消费税0、VAT、环保税                                                     | 无                  | 运保费参与计税，运费本金、仓储、码头、代理、注册不计total             |
| AL   | 关税0、消费税0、VAT、8,500ALL注册估算、一次豪车税                              | 21,000ALL年度豪车税 | 运保费参与计税，运输本金、港口、代理不计total                         |
| GE   | 消费税、进口税及五项固定手续/鉴定/申报/过境费                                  | 无                  | 没有购车价/运保费输入，不含车辆或运输本金；其他实际服务费用需单独明确 |

交接建议：结果中分离 `taxTotal`（税费）、`oneTimeFeeTotal`（一次行政/注册费）、`serviceEstimateTotal`（服务估算）、`recurringCosts`（年费）、`excludedCosts`、`grandTotal`（本次选定口径合计）。未来车辆详情的落地估算由上层组合函数计算：购车款 + 运保费 + 中国端已知出口费用 + 目的国税费 + 一次费 + 服务估算，并对已经计入的项目去重。首期计算器不可把参考 `total` 直接命名为“含车落地价”。

## 5. 俄罗斯（RU）参考公式

单位：RUB；排量 `cc`；`V` 为车价×交易币种兑RUB；`E` 为RUB/EUR；`VE=V/E`；车龄按 `(当前年-制造年)×12+当前月-制造月` 除以12。

- 纯电：关税=15%×V。此路线是否还需其他税费、何种马力口径，必须官方核验。
- 非纯电车龄<3：关税=`max(VE×百分比, cc×最低EUR/cc)×E`。
- 非纯电3≤车龄<5、车龄≥5：关税=`cc×分档EUR/cc×E`，不依赖车价；各行关税四舍五入到RUB。

| 小于3年车价上限 EUR（含上限） | 百分比 | 最低 EUR/cc |
| ----------------------------- | ------ | ----------- |
| 8,500                         | 54%    | 2.5         |
| 16,700                        | 48%    | 3.5         |
| 42,300                        | 48%    | 5.5         |
| 84,500                        | 48%    | 7.5         |
| 169,000                       | 48%    | 15          |
| 更高                          | 48%    | 20          |

| 排量上限cc（含） | 3≤车龄<5 EUR/cc | 车龄≥5 EUR/cc |
| ---------------- | --------------- | ------------- |
| 1,000            | 1.5             | 3             |
| 1,500            | 1.7             | 3.2           |
| 1,800            | 2.5             | 3.5           |
| 2,300            | 2.7             | 4.8           |
| 3,000            | 3               | 5             |
| 更高             | 3.6             | 5.7           |

手续费按RUB车价上限分档（均含上限）：200,000→1,231；450,000→2,462；1,200,000→4,924；2,700,000→13,541；4,200,000→18,465；5,500,000→21,344；10,000,000→49,240；更高→73,860。

回收费=`20,000×系数`。参考的非纯电≤3,000cc且≤160hp分支：车龄<3系数0.17，否则0.26。其他情况按排量组（≤1,000；≤2,000；≤3,000；≤3,500；更大；纯电独立组）、马力上限及车龄<3/≥3查矩阵。原包已含完整矩阵，但该优惠是否满足个人进口次数、持有期、车辆用途等条件未建模，不能仅凭马力和排量认定享受优惠。马力缺失时参考会选择估算系数并报警。

需核验边界：满3/5年到底适用哪个档；发动机功率或混动系统功率如何计；个人优惠资格；电动车相关税；估价是否包含运输；企业路线需要另外实现，不能套个人综合税和优惠回收费。

## 6. 哈萨克斯坦（KZ）参考公式

`V=车价×KZT/交易币种`；`E=KZT/EUR`；当月车龄月数用于>84个月界线；年份差用于注册。参考内常量MCI=4,325KZT。

- 手续费：6MCI=25,950。
- 燃油和普通混动关税：≤84个月为15%×V；>84个月为`max(15%×V, cc×EUR/cc×E)`。老车最低额：≤1,000cc为0.36；≤1,500为0.4；≤3,000及更大均0.6 EUR/cc。
- 纯电与EREV关税为0；原代码把两者视为同类用于部分回收/注册规则，但消费税分支仍可能受EREV排量影响，需针对具体车型分类核验。
- 排量消费税：排量>3,000cc时`100KZT×全部排量`；不是仅超出部分。
- 豪车消费税：V>77,850,000KZT时为10%×V。
- VAT：`16%×(V+未取整关税+排量消费税+豪车消费税+25,950)`，结果取整。
- 首登（按当前年份-制造年份）：普通车≤1年0.25MCI、≤2年50MCI、>2年500MCI；纯电/EREV对应0.25、25、250MCI。**页面提示“2年以上高档”，源码实际是>2进入最高档；这是需核对的文字/边界不一致。**
- 牌证费：4.05MCI=17,516.25，取整到17,516。
- 回收费：纯电/EREV为0；其他为50MCI×排量系数：≤1,000=1.5，≤2,000=3.5，≤3,000=5，其余11.5。
- 另计400,000KZT服务估算（证书、呼叫系统、代理、保税仓等）；进入原站合计。

缺口：没有身份参数、运保费输入、原产地和资格条件；MCI、VAT、优惠和估算年份均硬编码。生产规则需明确个人/企业、纯电与增程、进口配额/手续、运输估价口径。

## 7. 乌兹别克斯坦（UZ）参考公式

`P=车价×USD/交易币种`；`C=P+输入的边境运费USD`；`X=UZS/USD`；BRV=412,000UZS。车龄月数>36视为高回收费档；制造≤12个月且从未注册为`newUnder1`，更旧但从未注册为`newOver1`，曾注册车辆为`used`，不靠车龄判断新二手。

关税USD=`C×比例+cc×USD/cc`（此处是相加，不是取最大）。

| 动力/状态                 | 比例及每cc附加                                                       |
| ------------------------- | -------------------------------------------------------------------- |
| 纯电                      | 0                                                                    |
| 汽油新≤12个月             | 15%；排量≤1,000/1,500/1,800/3,000/更大对应0.4/0.6/0.8/1/1.25美元每cc |
| 汽油新>12个月             | 30%；相同排量档对应1.8/2/2.5/2.5/3                                   |
| 柴油新≤12个月             | 15%；≤1,500/2,500/更大对应0.6/0.8/1.25                               |
| 柴油新>12个月             | 30%；相同排量档对应2/2.5/3                                           |
| 汽油/柴油二手             | 40%+3美元每cc                                                        |
| 混动新≤12个月 / 新>12个月 | 15% / 30%，无每cc附加                                                |
| 混动二手≤36个月           | 30%+汽油新≤12个月表对应每cc附加                                      |
| 混动二手>36个月           | 40%+3美元每cc                                                        |

- 手续费：C上限10k/20k/40k/60k/100k/200k/500k/1m/更高美元，对应1/1.5/2.5/4/7/10/15/20/25BRV。
- VAT：`12%×(C+关税USD)×X`，不含手续费。
- 回收费按排量≤1,000/2,000/3,000/3,500/更大：≤36个月系数30/120/180/180/300BRV，>36个月90/210/330/390/480BRV。纯电≤36个月120BRV，>36个月210BRV。
- 注册：普通车13.04BRV，纯电7.7BRV。关税/VAT/注册取整至UZS，各项目相加。

缺口：参考未区分个人和企业；中国车辆已登记再出口的“零公里二手车”是否属于二手应由官方定义及具体文件判断，不能凭低里程或车龄设为新车；2,250USD是韩国路线运费示例，不能直接用于中国。保费及各段运输应明确是否已包括在运费字段。

## 8. 吉尔吉斯斯坦（KG）参考公式

`C=round2((车价+运保费)×EUR/交易币种)`，所有主要关税先按EUR算，再逐项换算KGS并保留两位。车龄=`当前年份-制造年份`，没有月份。

个人：

- 纯电/串联混动：15%×C（文案称优惠配额耗尽）；是否实时耗尽未动态获取。
- 非纯电车龄≤3：同俄罗斯新车六档（车价比例与排量最低额取大）。
- 3<车龄≤5：按俄罗斯中龄排量表；>5按老龄排量表。**与俄罗斯参考的 `<3 / <5` 边界不同，且KG只按年份差；不能共享一个含糊的年龄分档函数。**
- 不另加VAT；0.4%×C手续费用另计入total；个人首登估算5%×C单列extra，不进入total。

企业：

- 纯电/串联混动：15%×C；车龄≤5参考免VAT，>5加VAT。
- 非纯电车龄≤3：15%×C。
- 3<车龄≤7：`max(20%×C, cc×最低EUR/cc)`。
- > 7：`cc×老车EUR/cc`。
- 常规VAT=12%×(C+已取两位关税)；手续费=0.4%×C；消费税0。

| 汽油排量上限cc | 企业3<龄≤7最低EUR/cc | >7 EUR/cc |
| -------------- | -------------------- | --------- |
| 1,000          | 0.36                 | 1.4       |
| 1,500          | 0.4                  | 1.5       |
| 1,800          | 0.36                 | 1.6       |
| 3,000          | 0.44                 | 2.2       |
| 更大           | 0.8                  | 3.2       |

柴油表：≤1,500为0.32/1.5；≤2,500为0.4/2.2；更大为0.8/3.2（中龄/老龄）。

争议/缺口：页面明确承认其个人0.4%手续费展示与官方计算器口径不同；其5%首登拿完税价值估算，但官方可能用自己的市场估值；个人每年一辆的条件只有文字没有输入；串联/并联混动不能只按品牌判断；配额是否耗尽必须生效期化。参考链接为 https://www.customs.gov.kg/site/ru/master/customskg/kalkuljator-ats ，本次未完成官方逐项比对。

## 9. 亚美尼亚（AM）参考公式

`V=round((车价+运保费)×AMD/交易币种)`；E=AMD/EUR；车龄仅年份差。

- 纯电关税为0；参考对所有纯电VAT也置0（文字称至2026年）；环保税0。
- 非纯电<3年：一般15%×V；汽油且>2,800cc降为12.5%×V；混动仍15%。
- 3≤车龄<7：`max(20%×V, cc×最低EUR/cc×E)`。
- ≥7：`cc×老车EUR/cc×E`。汽油/柴油分档使用与上面KG企业相同的cc费率表，但年龄边界不同。
- 非纯电VAT：20%×(V+已取整关税)。消费税0。
- 环保税：纯电/混动0；普通车年龄≤5为0，≤10为2%×V，≤15为10%×V，更老20%×V。

关键缺陷：实际调用该公开函数，把纯电 `currentYear` 从2026改为2027，依然输出全部税费0；代码并未实现文案中的免税到期处理。因此我们必须把配额、资格、effectiveFrom/effectiveTo、清关日期加入规则，不能“复制公式然后提示仅供参考”就上线。边界3/7年只按年份估算也是页面自承的简化。进口公司和个人的法定处理仍需分别核验。

## 10. 阿尔巴尼亚（AL）参考公式

`C=round((车价+运保费)×ALL/交易币种)`；燃油/混动车按排量确定最低计税价；纯电不套排量最低价。`B=max(C,最低价)`。

| 排量上限cc（含） | 最低计税价ALL |
| ---------------- | ------------- |
| 1,400            | 162,500       |
| 1,900            | 250,000       |
| 2,500            | 406,000       |
| 3,000            | 500,000       |
| 4,500            | 625,000       |
| 更大             | 1,000,000     |

- 参考个人关税0、消费税0；VAT=20%×B，取整ALL。
- 注册估算8,500ALL，纳入total。
- 非纯电排量≥3,000cc，或B≥5,000,000ALL：纳入一次豪车税70,000ALL。
- 同条件年度豪车税21,000ALL列在extra，不纳入total。

缺口：只有针对个人的关税说明，无企业规则；没有车龄/环保准入输入；VAT最低估值表、豪车阈值、纯电适用性需官方核验。运保费进税基与运费本身未纳入合计要明确区分。市场汇率与阿尔巴尼亚海关官方汇率不可混用为同一确定结果。

## 11. 格鲁吉亚（GE）参考公式

参考函数完全不使用车价、运保费或原产国。车龄为当前年份减制造年份，最低0；燃油/混动排量向上取整至100cc（1,998→2,000；2,001→2,100），纯电计税排量置0。汇率仅用于将合计GEL展示成USD，不影响GEL税额。

- 消费税基础：车龄≤6年为1.5GEL/cc，>6年为4.5GEL/cc。
- 混动且≤6年且左舵：消费税再乘0.4（减免60%）；老混动不享优惠。
- 右舵：消费税基础乘3；右舵混动不叠加左舵混动优惠。
- 纯电消费税0。
- 进口税：`round((0.05+0.0025×车龄)×取整排量)`；纯电为0。
- 固定费用合计480GEL：customs service tax 150、processing 200、expert appraisal 30、declaration 50、internal transit 50；参考所有动力类型都计入。
- import duty另列0、VAT另列0；它同时显示进口税与进口关税两个不同项目，我们的翻译必须明确区分，避免“关税0”被读成“全部进口税0”。

参考警示：制造年份早于2013会提示Euro5要求；年龄>6、右舵、混动减免等分别提示。仅有警示并没有真的阻止不具备进口资格的车辆出结果。GE没有个人/企业分支、清关月份/日、环保实际等级或用途字段，不能因公式简单就认定适用于所有中国出口车辆。制造年份代理环保等级、排量100cc进位、6年阶梯、舵位倍率、纯电固定费均须官方逐项核验。页面自报来源 https://myauto.ge/ru/calculator 为第三方，核验日2026-08-09。

复算边界：默认1,998cc左舵混动，6年时合计1,810GEL，7年时合计9,615GEL（同时失去减免且基础率升档）；默认纯电合计480GEL。明显跳变应有解释并测阈值前/等于/后一档，不能用渐变动画掩盖真实变化。

## 13. 中国出口适配与上线前必须补齐的数据

1. **出口地≠原产地**：出口国固定中国不表示车辆原产地一定中国；中国境内转售的日韩车也可能出口。分别建模`exportCountry`、`originCountry`、`destinationCountry`、HS/车型类别、进口人角色，避免来源国税收优惠误判。
2. 币种首期至少支持CNY/USD，目的地本币作为结果币，EUR作为部分法规计算币；是否保留KRW是产品决定。不得只把Won标签改成人民币而沿用数值/汇率方向。汇率用显式base/quote，记录来源、日期、手填标记、预算汇率或海关汇率。
3. 删除韩国典型路线2,250USD/1,100USD的静默默认。中国运保费由用户或版本化路线报价给出，区分中国内陆、出口港、国际段、边境前、目的国内陆、保险；按当地完税价格规则选择计入项。
4. 个人自用优惠、进口次数/持有期、商业用途、车辆类别、登记状态、驱动类型、制造日期、发动机/总功率、环保准入、原产地凭证等，是否影响计算或进口资格，应逐国确定必填字段。
5. 规则需有来源URL、法规名称、条款、发布日期、生效起止日、适用国家/身份/车辆、核验人及核验日期、币种、舍入方式、估算标识。未到期规则才允许产出“可用估算”；配额/临时优惠需独立条件，不能无限期置零。
6. 同一车型得到0关税不代表0VAT、0回收、0服务费或可以合法进口；不满足准入应返回资格状态，不能靠税额解释资格。
7. 中国端采购价含税/出口服务费/国内运输/检测/退税归属等属于未来整车报价组成；本次工具与参考同类，仅算所展示的目的国税费/费用，不凭空从价格里扣退税。

## 14. 面向开发的独立引擎建议

下面是建议接口，不是竞品源码，最终命名可由主规划统一：

```ts
type QuoteInput = {
  exportCountry: 'CN'; originCountry?: string;
  destinationCountry: 'RU'|'KZ'|'UZ'|'KG'|'AM'|'AL'|'GE';
  importerType: 'individual'|'company';
  clearanceDate: string; // YYYY-MM-DD，明确时区/法律日期口径
  vehicle: { category: string; fuelType: string; manufactureDate: string;
    registeredBefore: boolean; engineCc?: number; powerKw?: number };
  price: Money;
  freight?: Money; insurance?: Money;
  qualifications: Record<string, boolean|string|number>;
};
calculateImportEstimate(input, ruleSet, fxSnapshot): CalculationResult;
```

引擎纯函数、无React、无网络、无当前日期隐式读取、无翻译依赖；返回费用`code`和计算参数，由UI用zh/en/ru翻译。用十进制定点/Decimal处理金额，规则声明每一步舍入，结果带ruleSetVersion、清关日期、汇率快照、warnings、assumptions、included/excluded。网络汇率和政策管理位于应用层。对非法输入、缺规则、过期规则、未核验身份、资格不满足、汇率缺失返回结构化状态，不返回NaN/Infinity或伪装为0。

建议测试两类分离：①reference fixtures复现竞争站用于研究对照；②official rule fixtures对官方/专业核验样例验收。第二类才是生产正确性标准。测试重点：阈值前/等于/后一单位；3/5/7年制造日；新旧注册状态；个人/企业；纯电/HEV/PHEV/EREV；排量与马力界线；优惠过期/配额；极低估值；运保计入与重复计入；双币转换和舍入；缺字段/非法值。

## 15. 可借鉴的布局线索

公开UI代码明确：输入与结果容器默认单列，≥780px双列；暗色面板、细边框、约10px圆角、红色强调、数字等宽字、实时计算、条件显示字段、费用明细与警示列表、国家导航自动换行。国家页面按路径独立，正文服务器已输出可抓取文字。适合借鉴信息层次与交互，但无需照搬其品牌、文本、图标或代码；中文字号和长俄文标签应独立校验，移动端需补充分步/粘性合计与键盘输入体验。

规则时效特别提醒：俄罗斯配置自报核验2026-08-11、AM 2026-08-10、KG/AL/GE 2026-08-09，KZ/UZ未见同类字段；原站过期提示只比较年份。不能把这些自报核验日期当官方生效日，也不能用“年份未变”判断政策没有变化。
