# EXT06：固定名单导入和数据保护

这是本轮执行边界及维护入口，不是已上线证明。准确 main、角色交付、供应商名单、备份恢复、离机副本、实际数量和资源证据以当轮 OPS 日志及私有交付索引为准。

## 发布与执行边界

- 保留当前生产数据库、媒体、账号、配置、费用确认、预算和审计。仅在已核最终 main、独立审查、门禁及 PR/CI 后发布；不得再次执行首次 schema4 清库工具，也不能把本机历史样本迁入生产。
- 本轮只运行固定约300去重车源的一次导入及同一名单增量追平；CSV完整暂存不等于全量业务入库。记录原档、来源、canonical、公开数量，来源记录可以多于车辆数。名单或数据不符合要求时暂停，不以扩大范围凑足数量。
- 供应商自动翻译关闭，不调用 Ali；正式照片保持供应商直链，不整批下载图片二进制，不爬报告原站。生产只执行正式批次，不为测试增加生产员工或车辆；双员工、删除恢复、伪造身份与故障测试使用隔离环境。
- Worker 与 API 独立，目标0.5 CPU/512 MiB、连接池2、网络并发1、入库批次200。数据库与缓存无公网端口；Worker连接私有数据库网络，出网身份与持久任务/lease/checkpoint依照 BE 最终交付。Redis不是持久任务账本。入口未交付前不猜 CLI 或自行绕过契约。
- 完成后持续调度保持关闭，保留可观测任务状态和手工入口；不能将未来5分钟增量、每日CSV或轮巡直接启用。
- 正式美元报价必须使用真实有效FX。手工 `run --rm --no-deps worker fx-refresh` 只映射BE的 `--formal-refresh`，不接受额外参数/合成seed；`fx-health`只检查健康。仅这两个显式入口在子进程设置精确当前库/production/release与FX网络门槛，普通导入不能继承FX刷新开关；沿用BE每天一次受控尝试与失效询价。Worker仍不调用Ali，不设定时器。不要为了执行FX使用全组up或重建现存PG。

## 容量与暂停

发布前测量当前磁盘、可用内存、数据库/索引、WAL、备份与暂存；将完整CSV、详情原档、300净增及构建/备份/加密暂存峰值纳入预算。峰值不超过全盘70%，磁盘达到75%暂停后台并保留checkpoint，资源紧张让后台任务让位。配置限额和本地压测不能代替实际现网测量，也不能将300容量结论外推全量。

## 备份、恢复和加密离机

1. 正式迁移/导入前，按当前真实生产配置停写并取最新数据库/媒体/控制配置快照；保持原数据，不覆盖用户新写入。对原始快照进行随机隔离库实际恢复，核对所有业务/审计/预算/迁移表与序列，实际恢复媒体和控制文件并核对内容、权限和所有权。
2. 完整证明保存为备份内 `routine-restore-proof.json`、`controls/proof.json`。新迁移按已审增量执行；迁移后核旧字段和历史记录保留，不能因新增列而略过保数据验证。未演练的全新集群角色/ACL重建明确单列，不能冒称已测。
3. 在独立离机位置生成并保留加密私钥和口令；只将对应公钥证书交给服务器。使用 `encrypted-backup.py encrypt --backup <绝对路径> --certificate <公钥证书> --output <新加密文件>` 打包数据库、媒体、控制原档及恢复证明，CMS AES-256-GCM认证加密；输入须24小时内、实际恢复证明匹配且所有校验相符。输出目录由当前用户独占且0700，文件0600；不覆盖现有文件。工具排除可由原档重建的控制恢复目录，不丢原始控制归档与证明。
4. 将加密文件复制到服务器以外的独立机器，核对传输前后SHA256。在离机位置执行 `encrypted-backup.py verify --ciphertext <加密副本> --certificate <证书> --key <加密私钥> --passphrase <独立口令文件> --temporary-root <0700临时根> --expected-sha256 <服务器加密证明中的SHA256>`。OpenSSL3认证解密成功后逐文件核对hash及mode/UID/GID，临时明文随验证清除；不会向生产恢复数据。私钥/口令不与加密副本同目录，不传入服务器或镜像层。
5. 离机副本、解密验证和最新备份实际恢复全部成功后才继续本轮发布/导入。用户电脑上的加密离机副本属于本次手工保护，不等于已建设自动异地备份、独立云存储、长期保留策略或已达成灾备SLA。新收费存储先报价，不采购。

## 写后失败

已有新员工写入或导入记录时，先停止本轮任务并保存最新数据、checkpoint、配置和费用账本，再修复。回退范围仅限本批新增记录，保留人工覆盖、后续编辑和其他批次；不得用旧快照覆盖当前生产，也不能依据超时、429、截断CSV或pilot扫描推断车源下架。任何失败保留原证据，未执行步骤不得记通过。
